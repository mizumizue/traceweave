## Content

### Contract
Web ダッシュボードにおいて、公式 `sonner` ライブラリの `<Toaster />` コンポーネントをルートに配置し、各画面操作（テスト実行、JSON整形、コピー等）で `toast.loading`, `toast.success`, `toast.error` を呼び出して視覚フィードバックを提供する。

### Inputs
- 操作イベント:
  - テスト実行トリガー: `testCaseId`, 入力パラメータ
  - JSON 整形トリガー: 入力 JSON 文字列
  - コピー操作トリガー: コピー対象テキスト
- トースト引数: メッセージ文字列、ローディング状態、完了コールバック

### Outputs
- 画面右下/上部へのトースト UI 描画（ダークモード対応、アニメーション表示）。
- 成功/エラー/進行中状態の動的切り替え。

### Errors
- テスト実行エラー時: `toast.error` による失敗理由のトースト表示。

### Constraints
- トースト表示がモーダルの背面に隠れないよう適切な z-index を確保すること。
- React 19 環境において警告や非推奨エラーを生じさせずに動作すること。
