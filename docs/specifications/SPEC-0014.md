## Content

### Contract
工程地層・ピラミッド診断ビューにおいて、単体・内結・外結・総合・受入の5大工程のテストケース件数、全体構成比率、および要件カバー率を立体層別ピラミッドコンポーネントとしてレンダリングし、各層クリックとマトリクス絞り込みを連動させる。

### Inputs
- `strata: StratumReport[]`: 各工程のテスト件数、要件カバー率、密度判定データ。
- `pyramid: PyramidHealthReport`: ピラミッド健全性（Healthy, InvertedIceCream等）および診断メッセージ。
- `onSelectPhase: (phase: string) => void`: 層クリック時の工程選択コールバック。

### Outputs
- 下層（Unit）から上層（Acceptance）に向かって幅が台形・立体的に変化する層別ピラミッドグラフィック。
- 各層内のテスト件数、構成比率パーセント、および円形ゲージ（CircularGauge）による要件カバー率表示。
- ピラミッド健全性診断ステータスおよび推奨アクションの表示。

### Errors
- テスト件数が全工程でゼロの場合は空ピラミッドのプレースホルダーを表示する。

### Constraints
- レスポンシブに対応し、幅の狭い画面でも各層のラベルおよび数値が視認可能であること。
- SVG または CSS ベクター描画により、外部チャートライブラリなしで軽量に描画すること。
