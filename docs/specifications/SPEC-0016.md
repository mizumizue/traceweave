## Content

### Contract
リポジトリルートには `node_modules` や `dist` を一切配置せず、`src/` 配下に `package.json`、`tsconfig.json`、`node_modules/`、`dist/` を集約する。リポジトリルート直下には実行用ラッパー `bin/traceweave`（POSIX bash）および `bin/traceweave.cmd` / `bin/traceweave.ps1`（Windows）を提供し、環境変数 `NODE_PATH` に `src/node_modules` を設定した上で CLI エントリポイントを呼び出す。

### Inputs
1. `src/package.json`: アプリケーションおよび Web UI の全依存関係・スクリプト定義。
2. `src/tsconfig.json`: TypeScript 設定（出力先 `outDir: "./dist"`）。
3. `bin/traceweave` 引数: CLI コマンドライン引数（`$@` / `%*`）。

### Outputs
1. `src/dist/`: コンパイル済み CLI / Core コード（`src/dist/cli/index.js` 等）。
2. `src/web/dist/`: ビルド済み静的 Web アセット（HTML, JS, CSS, `data.json`）。
3. クリーンなリポジトリルート: ルート直下に `node_modules`、`dist`、`dist-web` が存在しないディレクトリ構成。

### Errors
1. `src/node_modules` が存在しない状態で `bin/traceweave` が呼び出された場合、`"Dependencies not found. Please run 'npm --prefix src install' first."` という分かりやすいエラーメッセージを表示して終了コード 1 で終了する。
2. 不明なコマンド引数が渡された場合、Commander.js の標準ヘルプ/エラーメッセージを出力する。

### Constraints
1. ルート直下の `bin/traceweave` は POSIX（macOS/Linux/WSL/Git Bash）および Windows（cmd/PowerShell）の双方で動作しなければならない。
2. 既存の `tests/` スイートおよび `scripts/validate-docs.ts` は、`NODE_PATH` を介して `src/node_modules` を透過的に読み込めなければならない。
