## Content

### Contract
TraceWeave は品質保証の対象アプリケーションを `SubjectContext` として解決し、`TraceWeaveReport` のルートに `subject` フィールドとして同梱する。全コマンドおよび Web ダッシュボードは同一の `subject.displayName` を正本として参照し、利用者が「どのアプリの QA 文脈か」を一貫して識別できるようにする。

#### SubjectContext スキーマ
| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `displayName` | `string` | はい | 画面・レポート・CLI に表示する対象名。空文字不可 |
| `source` | `"config" \| "cli" \| "env" \| "package_json" \| "directory"` | はい | 解決に用いたソース（デバッグ・説明用。UI には出さない） |

#### 表示名解決順（上から優先）
1. グローバル CLI オプション `--subject <name>`（当該コマンド実行時のみ）
2. 環境変数 `TRACEWEAVE_SUBJECT`
3. リポジトリルートの `.traceweave/config.json` の `displayName`（UTF-8 JSON、オブジェクトルート）
4. パッケージマニフェストの `name`（リポジトリルートを優先し、なければクリーンルート規約に従うネスト配置を参照）
5. リポジトリルートディレクトリのベース名

#### 表示フォーマット
| 表面 | フォーマット | 例 |
|---|---|---|
| Web ヘッダー（ブランド行） | `TraceWeave` + 区切り + `for {displayName}` | `TraceWeave` `for my-shopping-app` |
| ブラウザ `document.title` | `TraceWeave — {displayName}` | `TraceWeave — my-shopping-app` |
| マークダウンレポート先頭 | 見出し1行: `# TraceWeave 品質レポート — {displayName}` | — |
| ローカルプレビュー起動案内 | 1 行に `for {displayName}` を含む | `Dashboard for my-shopping-app running at ...` |
| MCP トレーサビリティ要約 JSON | ルートに `subject` オブジェクトを同梱 | `{ "subject": { ... }, "summary": { ... } }` |

ローカル絶対パス・ホームディレクトリ・利用者名を表示名または UI 文言に含めてはならない。

### Inputs
- リポジトリルート（`resolveRepoRoot` 相当の探索結果）
- 任意: `.traceweave/config.json` — `{ "displayName": "My App" }`
- 任意: CLI `--subject <name>`
- 任意: 環境変数 `TRACEWEAVE_SUBJECT`
- 任意: パッケージマニフェスト（リポジトリルートまたはネスト配置）

### Outputs
- `TraceWeaveReport.subject: SubjectContext`（`generatedAt` と同列のルートメタデータ）
- 上表フォーマットに従った各表面の表示文字列

### Errors
- `.traceweave/config.json` が存在するが JSON パース不能、または `displayName` が空文字の場合: 当該ソースをスキップし次の解決段階へフォールバック（異常終了しない）
- 全段階で有効な表示名を得られない場合: `displayName: "unknown-project"`, `source: "directory"` を返却

### Constraints
- `subject` はレポート生成時に一度解決し、同一 `TraceWeaveReport` インスタンス内で表面間の不整合を生じないこと。
- 静的ビルド（`data.json` 同梱）ではビルド時点の `subject` を焼き込むこと（`SPEC-0005` 互換）。
- Web ヘッダー表示は `SPEC-0020` のロゴ・ルートナビゲーション契約と共存し、対象名はブランドタイトル直後の同一行に配置すること。
- モノレポ内の複数アプリを同一リポジトリで同時に区別する機能は本仕様の範囲外とする（単一 subject のみ）。
