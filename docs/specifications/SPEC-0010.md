## Content

### Contract
Web ダッシュボード（React アプリケーション）において、充足率（0〜100%）を SVG ベクター描画による円グラフ（Circular Gauge / Donut Chart）としてレンダリングする共通コンポーネントを提供する。CLI 向けの静的 HTML レポート出力は `traceweave build` によるダッシュボード生成に委譲する。

### Inputs
- `value: number`: 0から100までの充足率・カバー率パーセント数値。
- `size?: number`: 円グラフの直径（px。デフォルト: 40、大: 56〜64、小: 28〜32）。
- `strokeWidth?: number`: 円周ゲージの太さ（px。デフォルト: 4）。
- `showValue?: boolean`: 中央にパーセントテキストを表示するかどうか（デフォルト: true）。
- `color?: string`: ゲージ線のカスタム色（省略時はスコアに応じた閾値色）。
- `trackColor?: string`: 背景円トラックの色。
- `className?: string`: 外部スタイリング用追加クラス。

### Outputs
- 時計回り・12時位置起点で指定パーセンテージ分の弧が描画された SVG 円グラフ。
- スコアに応じた色分け（スコア80以上: Teal/Emerald、50以上80未満: Amber、50未満: Rose）。
- 中央揃えされた数値および単位（%）テキスト。

### Errors
- 負の値または100を超える値が入力された場合、0%〜100% の範囲内に自動クランプして安全に描画する。
- NaN または未定義の場合は 0% として描画する。

### Constraints
- 外部の重厚なチャートライブラリに依存せず、軽量なインライン SVG で高速・レスポンシブに描画すること。
- マトリクス表の大量行表示時にも再描画負荷を生じさせないこと。
