## Content

### Contract
`traceweave mcp` は MCP サーバーとして起動し、AI エージェント向けに TraceWeave 解析結果を JSON テキスト、V字モデル文書リソース、および再利用可能プロンプトを提供する。コアの `buildTraceWeaveReport` / `checkDocs` と同一ロジックを再利用する。

### Inputs
- 起動: `traceweave mcp [-d, --docs <dir>] [-t, --transport stdio|http] [--host <host>] [--port <port>]`
- トランスポート `stdio`（既定）: Cursor 等のプロセス起動連携
- トランスポート `http`: Streamable HTTP（`POST /mcp`、既定 `127.0.0.1:3100`）
- ツール `get_traceability_summary`: 引数なし
- ツール `get_stratum_density`: 引数なし
- ツール `get_requirement_status`:
  - `requirementId: string`（必須、例: `REQ-0001`）
- ツール `check_quality_gaps`:
  - `strict?: boolean`（省略時 `false`）
- ツール `get_traceability_matrix`: 引数なし
- ツール `get_catalog`:
  - `kind?`, `reqclass?`, `tag?`, `status?`, `query?`（CLI `catalog` と同等フィルタ）
- ツール `get_decisions`: 引数なし
- リソース URI: `traceweave-doc://<docs 相対パス>`（例: `traceweave-doc://needs/NEED-0001.md`）
- プロンプト `traceability_review`: `requirementId?`
- プロンプト `quality_gap_analysis`: `strict?`
- プロンプト `v_model_authoring`: `documentKind?`

### Outputs
- 各ツールは MCP `content[].type: "text"` に JSON 文字列を格納して返却する。
- `get_traceability_summary`: `{ subject, summary }`
- `get_stratum_density`: `{ strata, pyramid }`
- `get_requirement_status`（成功）: `{ matrixRow, sufficiency }`
- `get_requirement_status`（未検出）: `{ error: "ERR_REQUIREMENT_NOT_FOUND", requirementId, message }` かつ MCP 応答 `isError: true`
- `check_quality_gaps`: `{ passed, errors, warnings, gaps }`
- `get_traceability_matrix`: `{ matrix }`
- `get_catalog`: catalog JSON（`totalCount`, `filteredCount`, `items` 等）
- `get_decisions`: `{ adrs, dsns }`
- リソース読取: `contents[].text` に Markdown 本文、`mimeType: text/markdown`
- プロンプト取得: `messages[]` に user ロールのテキスト指示

### Errors
- 未知ツール名・未知プロンプト名: MCP プロトコルエラー
- docs ディレクトリ不在・解析失敗: ツール実行時に `isError: true` およびエラーメッセージ JSON
- `get_requirement_status` で要件未検出: `ERR_REQUIREMENT_NOT_FOUND`（`isError: true`）
- リソース URI 不正・未検出: ReadResource ハンドラがエラーを返却

### Constraints
- トランスポートは `stdio`（既定）および `http`（Streamable HTTP）をサポートする。
- MCP はオプショナル拡張であり、CLI `check` / `report` / Web ダッシュボードの動作に必須ではない（ADR-0002）。
- 出力は決定論的解析結果のみとし、AI 推論による充足度判定を行わないこと。
- TraceWeave リポジトリおよび adopt 適用先は `.cursor/mcp.json` で MCP 登録例を同梱する（未存在時のみ adopt が生成）。
