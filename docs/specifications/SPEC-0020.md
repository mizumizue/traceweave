## Content

### Contract
Web ダッシュボードのヘッダーにおけるブランドロゴ（アイコン `🕸️` および `TraceWeave` タイトル）は、ルート遷移アンカー `<a>` として動作する。
利用者の操作コンテキスト（通常クリック vs 修飾キー付きクリック）を判別し、SPA 状態リセットとブラウザネイティブ遷移の双方を契約どおり提供する。

| 項目 | 仕様 |
|---|---|
| HTML タグ | `<a href="..." ...>` |
| `href` 属性 | `window.location.pathname` または `'/'`（クエリパラメータを含まないパス） |
| 通常クリック (`e.button === 0` かつ修飾キーなし) | `e.preventDefault()` を実行し、親画面のルートリセットハンドラを呼び出し |
| 修飾キー付きクリック (`ctrlKey \| metaKey \| shiftKey \| altKey`) | イベントを抑止せずブラウザ標準のタブ/ウィンドウ新規オープン処理に委ねる |
| 復帰先状態 | `tab: 'matrix'`, `nodeId: null`, `searchQuery: ''`, `phaseFilter: 'all'`, `criticalityFilter: 'all'`, `requirementClassFilter: 'all'`, `scoreFilter: 'all'`, `catalogKind: 'all'`, `catalogTag: null`, `catalogStatus: 'all'`, `graphHighlight: 'all'` |
| 履歴制御 | クエリなしのルート URL への `history.pushState` |

### Inputs
1. **ロゴクリックイベント**:
   - `React.MouseEvent<HTMLAnchorElement>`: 左クリック、中クリック、修飾キー（`ctrlKey`, `metaKey`, `shiftKey`, `altKey`）の状態。
2. **現在のパス情報**:
   - `window.location.pathname`: 現在の配信ベースパス（サブディレクトリ配信にも耐性を持つルート基準）。

### Outputs
1. **SPA 状態リセット**:
   - 各 State の初期値への復元（`activeTab`, `selectedNodeId`, `searchQuery`, 各種フィルター）。
2. **ブラウザ履歴更新**:
   - `window.history.pushState(DEFAULT_URL_STATE, '', pathname)`。
3. **通知・視覚フィードバック**:
   - ホバー時のアニメーション・カーソル変化、必要に応じたトースト通知または自然な画面リセット。

### Errors
1. **すでにルート状態でのクリック**:
   - 状態変更がない場合でも例外を発生させず、モーダルが開いている場合は確実に閉じ、安全にノーオペレーションまたは初期画面維持とする。

### Constraints
1. **アクセシビリティ**:
   - キーボードフォーカス時の視認性（明瞭なフォーカスリング表示）、スクリーンリーダー向けの適切な `title` または `aria-label` の提供。
2. **サブパス配信互換性**:
   - ドメイン直下（`/`）のみならず、サブディレクトリ（例: `/docs/`）配下でホストされた場合でも正しく動作するよう `pathname` を尊重すること。
3. **レイアウト整合性と非干渉性**:
   - ロゴ要素の縮小を抑止し、隣接するバージョンバッジとの重複（overlap）を防止すること。
   - 対象アプリケーション表示名（`SPEC-0025` の `for {displayName}`）はブランドタイトル直後の同一行に配置し、バージョンバッジと重ならないこと。
   - 説明文は単一行への無理な省略を行わず、ロゴ・バージョン・対象名の独立行の下段として自然に折り返し、全画面幅で完全に視認できること。
