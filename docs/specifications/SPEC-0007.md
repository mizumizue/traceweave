## Content

### Contract
Web ダッシュボード（React アプリケーション）において、任意のノード（要求、要件、仕様、テストケース）がクリックされた際、全画面またはサイドドロワー/モーダルにて文書詳細を展開する。テストケース表示時には静的な仕様（Objective, Steps, Expected）と、テスト実行レポートから得られた動的実測値およびログ証跡（Actual, Log Evidence）を左右並列または上下対比のカードコンポーネントで配置し、実行ステータスに応じた視覚フィードバック（合格: 翠色, 不合格: 緋色, 保留・未実行: 琥珀色）を提供する。テスト未実行時は過去の固定値で偽装せず未実行状態を明示する。

### Inputs
- `selectedNode: DocNode`: 選択されたドキュメントノード。
- `allNodes: DocNode[]`: リンク・依存解決用の全ノード配列。

### Outputs
- レンダリングされたモーダル/ドロワーコンポーネント。
- テストケース時の対比カード（「何をテストするのか」「期待される動作」「スクリプト実行による実測結果・生ログ証跡」）。
- 依存ノードへのドリルダウン遷移リンク。

### Errors
- 存在しないノード ID が選択された場合は、フォールバックメッセージを表示し安全に閉じる。

### Constraints
- モーダルの開閉アニメーションは 150ms 以内に完了し、ESC キーまたは背景クリックで閉じられること。
- マークダウン本文内のリスト・コードブロックが整形されて表示されること。
