## Content

### Contract
Web ダッシュボード（React アプリケーション）において、任意のノード（要求、要件、仕様、テストケース）がクリックされた際、全画面またはサイドドロワー/モーダルにて文書詳細を展開する。テストケース表示時には「検証目的（Objective）」「テスト手順（Steps）」「期待値（Expected）」と「実測値（Actual）」を左右並列または上下対比のカードコンポーネントで配置し、実行ステータスに応じた視覚フィードバック（合格: 翠色, 不合格: 緋色, 保留: 琥珀色）を提供する。

### Inputs
- `selectedNode: DocNode`: 選択されたドキュメントノード。
- `allNodes: DocNode[]`: リンク・依存解決用の全ノード配列。

### Outputs
- レンダリングされたモーダル/ドロワーコンポーネント。
- テストケース時の対比カード（「何をテストするのか」「期待される動作」「実際の結果・ログ証跡」）。
- 依存ノードへのドリルダウン遷移リンク。

### Errors
- 存在しないノード ID が選択された場合は、フォールバックメッセージを表示し安全に閉じる。

### Constraints
- モーダルの開閉アニメーションは 150ms 以内に完了し、ESC キーまたは背景クリックで閉じられること。
- マークダウン本文内のリスト・コードブロックが整形されて表示されること。
