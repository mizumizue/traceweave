## Content

### Contract
`TraceWeaveReport` に `useCases` 配列およびサマリー内の `useCaseCount`・`useCaseAssignedCount`・`averageUseCaseSufficiencyScore` を含める。各 `useCases` 要素はユースケース ID、タイトル、ステータス（`unassigned` または `scored`）、参照要件数、充足要件数、未充足要件 ID リストを保持する。`scored` の場合のみ `score`（0〜100）と `isFullySatisfied` を含める。

### Inputs
- 解析済みドキュメントグラフ上の `use_case` ノード（`requirement_refs`）
- 既存の `RequirementSufficiency` 配列

### Outputs
- レポート JSON の `useCases` フィールド
- サマリーのユースケース件数および割当済みユースケースの平均充足度

### Errors
- ドキュメントディレクトリが存在しない場合は既存のレポート生成エラーと同様に失敗する。

### Constraints
- ユースケース充足度は新しい `verifies` エッジを生成しない。集計は `requirement_refs` と要件充足度の派生のみとする。
- スコアは参照要件 ID ごとに既存要件スコアを取得し、存在しない参照は 0 点として平均する。
