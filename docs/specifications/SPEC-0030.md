## Content

### Contract
SPEC-0028 の suite モデルを拡張し、**形式証跡（formal）** と **補助ハーネス（supplementary）** を宣言する。`evidenceTier: supplementary` の fragment は生成しても **集約 `testResults.aggregate` にマージしない**。

| フィールド | 型 | 意味 |
|---|---|---|
| `evidenceTier` | `formal` \| `supplementary` | 省略時 `formal`。 |
| `capture` | `node-test-tap` \| `fragment` \| `aggregate` | E2E は Playwright 実行後 `fragment`。 |
| `testsDir` | `string` | `node-test-tap` 専用。省略時 formal は `tests/support`・`tests/e2e` を走査除外。 |

#### 形式 TC 宣言行
- `node-test-tap` および Playwright 変換は、テストタイトルが **`TC-<STRATUM>-<NNNN>[-SS]:` で始まる**場合のみ `results` キーを生成する（ADR-0011、`formalTestCaseIdFromTitle`）。
- 補助ハーネスは `support:` 行頭を用い、タイトル本文中の `TC-` は証跡キーにならない。

#### TraceWeave リポジトリ既定 suites
`node`（formal）, `support`（supplementary, `tests/support`）, `e2e`（formal, Playwright）, `newman-api`（formal）。

### Inputs
- `.traceweave/config.json` の `suites[]`（`evidenceTier`, `testsDir` を含む）
- Node TAP または Playwright JSON（raw）および suite `run` コマンド

### Outputs
- formal suite: `reports/suites/<id>.json`（traceweave-v1）→ 集約へマージ
- supplementary suite: 同 fragment パスを書いても集約は変更しない

### Errors
- formal スイートが非 0 終了: CLI 終了コード非 0（supplementary も同様に失敗扱い）
- Playwright 未導入: プロジェクトは `TW_SKIP_E2E=1` で E2E のみスキップ可能（証跡は更新されない）

### Constraints
- 集約マージ対象は `evidenceTier === formal` の fragment に限定する。
- ブラウザ DOM をオラクルとする ST/UAT の形式自動化は `tests/e2e/` を正本とし、`tests/support/**` のみで passed としない。
- `npm --prefix src run lint` および dogfood `npm --prefix src test` が成功すること（E2E スキップ時は E2E 証跡未更新を許容）。
