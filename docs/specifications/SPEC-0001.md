## Content

### Contract
リポジトリ内の `docs/` 配下のすべての `.md` ファイルを走査し、YAML フロントマターおよび Markdown 本文の見出し構造を抽出・検証する。

### Inputs
- `docsDir`: 文書が格納されているルートディレクトリパス（デフォルト: `./docs`）

### Outputs
- パース済み文書オブジェクトのリスト（`id`, `kind`, `title`, `status`, `created`, `updated`, `scope`, `criticality`, `test_level`, `test_method`, `depends_on`, `verifies`, `tags`, `links`, `body`）
- スキーマ違反エラーメッセージの配列

### Errors
- フロントマター未定義または YAML 構文エラー
- 必須プロパティ（id, kind, title等）の欠落
- ID 接頭辞と格納ディレクトリの不一致
- 定義済み見出し（`### ...`）の順序・個数不一致

### Constraints
- 外部 DB 接続を必要とせず、pure TypeScript/Node.js のファイルシステム API でミリ秒単位で高速実行されること。
