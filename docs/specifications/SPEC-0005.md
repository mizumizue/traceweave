## Content

### Contract
React + Vite により構築される SPA ダッシュボードに対し、解析済みのトレーサビリティデータ・充足度レポートを JSON ペイロードとして供給し、クライアントサイドで高速描画・インタラクティブ操作を可能にする。

### Inputs
- `TraceWeaveDataPayload`:
  - `nodes`: 全文書ノードのマップ
  - `matrix`: 要求・要件・仕様・テストケースの階層テーブルデータ
  - `sufficiency`: 各要件のスコア・充足状態
  - `strata`: 工程別密度およびピラミッド診断結果
  - `generatedAt`: 生成日時

### Outputs
- 単一の HTML または静的 JS/CSS バンドル（`dist/web/`）
- ブラウザ画面:
  - Header: プロジェクト名、全体スコア、工程別バッジ
  - Main Tab 1: Traceability Matrix（縦ツリー×横工程のグリッド、セルホバー・クリック詳細モーダル）
  - Main Tab 2: Phase Stratum & Pyramid（地層ヒートマップおよびテストピラミッド形状）
  - Main Tab 3: Risk & Gap Explorer（未充足要件と改善アクション一覧）

### Errors
- データペイロード破損時のフォールバック UI 表示

### Constraints
- 外部 CDN や外部ネットワークへの接続を一切行わず、完全にローカル/オフラインで動作すること。
