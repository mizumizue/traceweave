## Content

### Contract
Web ダッシュボードに対し、解析済みの `TraceWeaveReport` JSON ペイロードを `/api/data`（開発サーバー）または同梱 `data.json`（静的ビルド）から供給し、ブラウザ上で高速描画およびインタラクティブな探索・対話操作を可能にする。

### Inputs
- `TraceWeaveReport`（`/api/data` および `data.json` のルートオブジェクト）:
  - `generatedAt: string`: ISO 8601 生成日時
  - `summary`: 全体集計（要件数、テスト件数、充足度スコア、FR/NFR 件数等）
  - `requirements: RequirementSufficiency[]`: 要件別充足度・工程別実行/文書件数
  - `matrix: MatrixRow[]`: トレーサビリティマトリクス行
  - `strata: StratumReport[]`: 工程地層密度
  - `pyramid: PyramidHealthReport`: ピラミッド/トロフィー健全性診断
  - `gaps`: 未テスト要件・結合欠落・仕様未テスト一覧
  - `nodes?: DocNode[]`: 全文書ノード（詳細モーダル・グラフ用）
  - `graph?: TraceabilityGraphData`: トレーサビリティグラフ描画データ
  - `catalog?: DecisionsCatalog`: 決め事カタログ（種別件数・タグ・相互参照）
  - `inputModifiability?: InputModifiabilitySummary`: UI 実行可否解析サマリ

### Outputs
- 自己完結する静的 Web アセット群（`index.html`, `data.json`, JS, CSS）
- ブラウザ画面（5 タブ構成）:
  - **Header**: プロジェクト名、データ更新操作
  - **QualityMetricsGrid**: 全体スコア、工程別バッジ、FR/NFR サマリ
  - **Tab: matrix** — Traceability Matrix（縦ツリー×横工程、多軸フィルタ、CSV/JSON エクスポート）
  - **Tab: graph** — Traceability Graph（有向グラフ、上流/下流ハイライト）
  - **Tab: stratum** — Phase Stratum & Pyramid（地層ヒートマップ、立体ピラミッド）
  - **Tab: decisions** — Decisions Catalog（種別・タグ・ステータス・FR/NFR フィルタ、横断検索）
  - **Tab: gaps** — Risk & Gap Explorer（未充足要件と改善アクション）
- 詳細モーダル: 任意ノードのドリルダウン、対話型テスト実行（`SPEC-0008`/`SPEC-0009`）

### Errors
- データペイロード取得失敗時の `ErrorScreen` フォールバック表示
- 存在しない URL ノード指定時のトースト通知

### Constraints
- 外部 CDN や外部ネットワークへの接続を一切行わず、完全にローカル/オフラインで動作すること。
- 静的ビルドは `data.json` を同梱し、`fetch('/api/data')` 失敗時に `data.json` へフォールバックすること。
- URL 状態同期は `SPEC-0019` に従い、検索クエリ `q` はマトリクスおよびカタログタブで共有すること。
