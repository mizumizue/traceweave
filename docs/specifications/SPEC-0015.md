## Content

### Contract
Web ダッシュボードにおいて、マトリクス表の多軸フィルター（重要度、工程、充足度状況）、クイックフィルターチップ、検索テキスト入力、および解析済みトレーサビリティデータの CSV / JSON / Markdown 形式によるクライアントサイドエクスポート機能を提供する。

### Inputs
- フィルター選択状態:
  - `keyword: string`: フリーテキスト検索
  - `criticalityFilter: 'all' | 'high' | 'medium' | 'low'`
  - `phaseFilter: 'all' | 'unit' | 'integration_internal' | 'integration_external' | 'system' | 'acceptance'`
  - `statusFilter: 'all' | 'satisfied' | 'partial' | 'unsatisfied'`
- エクスポート要求: CSV、JSON、Markdown サマリー形式

### Outputs
- フィルタリング条件に合致した行のみでリアルタイム再描画されるトレーサビリティマトリクス。
- アクティブな条件を表示するクイックチップ（ワンクリック解除可能）。
- ブラウザ側で生成された CSV / JSON ファイルのダウンロード、または Markdown テキストのクリップボード書き込み。

### Errors
- エクスポート対象データが存在しない場合は空ファイルではなく警告通知を表示する。

### Constraints
- フィルター変更時のテーブル再描画は 50ms 未満で完了し、UI の応答性を維持すること。
- エクスポート処理はすべてクライアントサイドで完結し、外部サーバー通信を要しないこと。
