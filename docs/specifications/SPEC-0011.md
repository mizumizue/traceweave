## Content

### Contract
Web フロントエンドのソースコードおよび設定資材は `src/web/` に配置され、Vite によるビルドは `src/web/vite.config.ts` を設定ファイルとして起動する。成果物は `dist/web/` に出力され、CLI は静的配信・ビルド時のデフォルト出力先・解決パスとして `dist/web/` を使用する。

### Inputs
1. `src/web/index.html`: Web ダッシュボードの起点 HTML（相対パス `./src/main.tsx` を参照）。
2. `src/web/vite.config.ts`: Vite 設定（ルートディレクトリ `src/web`、出力先 `../../dist/web`、Tailwind/PostCSS連携）。
3. `src/web/tailwind.config.js` および `src/web/postcss.config.js`: Web フロントエンド用スタイル設定。
4. CLI オプション: `traceweave build` の `--out`（デフォルト `./dist/web`）。

### Outputs
1. `dist/web/index.html`: バンドル済み HTML アセット。
2. `dist/web/assets/*.js`, `dist/web/assets/*.css`: バンドル済み JS/CSS。
3. `dist/web/data.json`: トレーサビリティレポート JSON データ。
4. クリーンなリポジトリルート: ルート直下に `index.html`, `vite.config.ts`, `tailwind.config.js`, `postcss.config.js`, `dist-web` が存在しない状態。

### Errors
1. `dist/web/index.html` が存在せず、かつ `dist/web` がビルドされていない状態で `traceweave serve` が呼ばれた場合は、既存のフォールバック HTML（`generateFallbackHtml`）により動的レポート HTML を配信する。
2. 指定されたビルド出力パスが存在しない場合は自動でディレクトリを再帰作成（`mkdirSync(outDir, { recursive: true })`）する。

### Constraints
1. ルート直下の `package.json` のスクリプト（`build:web`, `test` 等）は `--config src/web/vite.config.ts` を明示して透過的に実行可能でなければならない。
2. 既存の Core・Application・Infrastructure・CLI 単体テストがすべてそのまま成功しなければならない。
