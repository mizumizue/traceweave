## Content

### Contract
コマンドラインインターフェース（CLI）エントリーポイント `traceweave` を提供し、引数・オプションフラグに応じて文書検証、マトリクス出力、レポート生成、テスト入力解析、決め事カタログ出力、静的ダッシュボードビルド、プレビューサーバー起動、MCP サーバー起動、および外部プロジェクト適用を実行する。全コマンドはグローバルオプション `-d, --docs <dir>` で文書ルートを指定できる。docs ディレクトリが存在しない、または解析不能な場合は終了コード 1 で異常終了する。`serve` 実行時、同一ポートで前プロセスが実行中の場合は既存プロセスを安全に終了してポートを解放し、新規サーバーを起動する。

### Inputs
- グローバルオプション（全コマンド共通）:
  - `-d, --docs <dir>`: 文書ルートディレクトリ（省略時は自動探索）
- `check`:
  - `-s, --strict`: テスト未充足でも exit 1
- `report`:
  - `-f, --format <text|json|markdown>`: 出力形式（デフォルト: `text`）
  - `-o, --out <file>`: 出力ファイル（省略時は標準出力）
- `matrix`:
  - `-f, --format <text|json|markdown|csv>`: 出力形式（デフォルト: `text`）
  - `-o, --out <file>`: 出力ファイル（省略時は標準出力）
- `test-inputs`（別名 `inputs`）:
  - `-f, --format <text|json|markdown>`: 出力形式（デフォルト: `text`）
  - `-o, --out <file>`: 出力ファイル（省略時は標準出力）
- `catalog`:
  - `-k, --kind <kind>`: 文書種別フィルタ（`all` または各 `DocKind`、デフォルト: `all`）
  - `--reqclass <class>`: 要件クラスフィルタ（`functional`, `non_functional`, `all`、デフォルト: `all`）
  - `--status <status>`: ステータスフィルタ（`draft`, `proposed`, `accepted`, `rejected`, `superseded`, `deprecated`, `all`、デフォルト: `all`）
  - `-t, --tag <tag>`: タグフィルタ
  - `-q, --query <query>`: タイトル・ID・本文・セクション横断検索
  - `-f, --format <text|json|markdown>`: 出力形式（デフォルト: `text`）
  - `-o, --out <file>`: 出力ファイル
- `decisions`:
  - `-f, --format <text|json>`: 出力形式（デフォルト: `text`）
  - `-o, --out <file>`: 出力ファイル
- `build`:
  - `-o, --out <dir>`: 静的ダッシュボード出力先（デフォルト: `./src/web/dist`）
- `serve`:
  - `-p, --port <number>`: ローカルプレビュー用ポート（デフォルト: `3000`）
  - `-r, --restart`: ポート占有プロセスを強制終了して再起動
- `mcp`: 追加オプションなし（stdio MCP サーバーを起動）
- `adopt [targetDir]`:
  - `-m, --mode <overlay|restructure>`: 適用モード（デフォルト: `overlay`）
  - `-b, --backup-dir <dir>`: バックアップ先
  - `--no-backup`: バックアップをスキップ（非推奨）
  - `-d, --dry-run`: 変更を行わず手順のみ表示
  - `-r, --rollback <backupDir>`: 指定バックアップからロールバック
  - `-p, --project-name <name>`: 生成文書のプロジェクト名
  - `-f, --force`: 未コミット変更がある Git 作業ツリーでも再構成を続行

### Outputs
- 各コマンドの標準出力、または `-o` 指定時のファイル出力
- `build`: 静的 Web アセット群（`index.html`, `data.json`, JS/CSS）
- `serve`: HTTP サーバー（`/api/data`, `POST /api/test/run`、静的ファイル配信）
- `mcp`: stdio 上の MCP JSON-RPC ツール応答
- プロセス終了コード（0: 成功、1: 検証失敗またはエラー）

### Errors
- 不正な引数・オプション
- docs ディレクトリが存在しない、またはディレクトリでない場合の異常終了（exit 1）
- 文書解析・レポート生成の例外（exit 1）
- `adopt --rollback` 失敗時（exit 1）

### Constraints
- Node.js 18+ 環境で即座に動作し、`npx traceweave <cmd>` で外部事前準備なしに実行可能であること。
- `test-inputs` は `TestCaseInputAnalyzer` による決定論的な UI 実行可否分類を出力すること（ADR-0003）。
- `adopt` は開発・導入ツールであり、実行時品質分析のコア契約ではない（ADR-0007）。
- `serve` 実行時、指定ポートが既に専有されている場合は先行プロセスを検知・終了し、ポート解放後にサーバーを自動再起動すること。
