## Content

### Contract
コマンドラインインターフェース（CLI）エントリーポイントを提供し、引数・オプションフラグに応じて文書検証、マトリクス出力、レポート生成、静的ダッシュボードビルド、およびプレビューサーバー起動を実行する。

### Inputs
- コマンドライン引数:
  - `check`: `--strict` オプション（テスト未充足でも exit 1）
  - `matrix`: `--format <text|markdown|json|csv>`
  - `report`: `--format <text|json>`
  - `build`: `--out <dir>`（静的ダッシュボードの出力先）
  - `serve`: `--port <number>`（ローカルプレビュー用ポート番号、デフォルト: 3000）

### Outputs
- 各種フォーマットによる標準出力、または指定ディレクトリへの静的ファイル群出力
- プロセス終了コード（0: 成功、1: 検証失敗またはエラー）

### Errors
- 不正な引数・オプション
- docs ディレクトリが存在しない場合の異常終了

### Constraints
- Node.js 18+ 環境で即座に動作し、`npx traceweave <cmd>` で外部事前準備なしに実行可能であること。
