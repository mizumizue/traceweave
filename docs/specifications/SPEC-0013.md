## Content

### Contract
ノード詳細モーダルにおいて、依存関係リンク（depends_on, verifies等）をクリックして別ノードへ遷移した際の閲覧履歴スタックを管理し、戻る・進むナビゲーション、ESCキーによるクローズ、および文書情報（ID・ファイルパス・Markdown）のクリップボードコピー機能を提供する。

### Inputs
- ユーザー操作イベント:
  - `history: string[]`: 閲覧したノード ID のスタック配列
  - `historyIndex: number`: 現在表示中の履歴インデックス
  - `onBack()` / `onForward()`: 履歴遷移トリガー
  - キーボードイベント: `Escape` キー
  - コピーボタン押下: コピー対象（ID、パス、Markdown本文）

### Outputs
- モーダルヘッダーでの「戻る（<）」「進む（>）」ボタンの活性・非活性制御。
- 履歴遷移に応じたモーダル内コンテンツの即時差し替え。
- クリップボードへの対象テキスト書き込みおよび完了フィードバック。

### Errors
- クリップボード API が未対応または拒否された場合はエラー通知を表示して安全にフォールバックする。

### Constraints
- 履歴スタックはメモリ上に保持し、モーダルを閉じた際に安全にリセットすること。
- モーダル外側の背景クリックおよび ESC キー押下で即座に閉じられること。
