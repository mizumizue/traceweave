## Content

### Contract
TraceWeave レポート JSON に `unitCoverage` オブジェクトを含め、単体テスト品質を REQ/SPEC トレーサビリティとは独立した実装カバレッジ軸として提供する。Web ダッシュボードは `tab=unit` で専用ビューを表示する。

### Inputs
- `reports/coverage-summary.json`（テストスイート実行時に Node `--experimental-test-coverage` 出力から生成）
- `src/` 配下 TypeScript ソース（エクスポート関数・クラスメソッドのインベントリ）

### Outputs
- `unitCoverage.status`: `available` | `pending`
- `unitCoverage.functionCoverage`, `branchCoverage`, `lineCoverage`: 0.0〜1.0
- `unitCoverage.modules[]`: ファイル単位の関数数・カバレッジ
- `strata[level=unit]`: `metricSource: code_coverage`, `branchCoverage` を含む

### Errors
- カバレッジファイル欠落時は `status: pending` とし、レポート構築全体を失敗させない。

### Constraints
- 単体カバレッジは V字トレーサビリティグラフの `verifies` エッジを生成しない（unit TC の verifies は空または DSN のみ）。
- 充足度スコア（REQ-0002）は内結・外結・ST・UAT の実行合格 TC のみを入力とする。
