## Content

### Contract
Web ダッシュボードのトレーサビリティグラフタブは、Core レイヤーが算出したグラフバウンディングボックスに基づき、ワイドコンテナ展開、ネイティブスクロールによる下方向閲覧、Sticky 列ヘッダー、全幅収容（Fit Width）、全画面（フルウィンドウ）表示、および種別トグル除外・全表示リセット操作を提供する。ズーム・パン・ノード選択・詳細インスペクター連動は既存のグラフコンポーネント契約に従う。

### Inputs
- `bounds`: `TraceabilityGraphData.bounds`（Core 算出の描画矩形）。
- `graphTabActive: boolean`: グラフタブがアクティブかどうか。
- ユーザー操作: Fit Width、フルウィンドウ、種別トグル、リセット、スクロール。

### Outputs
- グラフ SVG キャンバスがコンテナ内でスクロール可能に表示される。
- Fit Width 操作後、バウンディングボックス全体がコンテナ幅に収まる。
- 種別トグル除外後、選択種別以外のノードと接続エッジが非表示になる。
- リセット操作後、種別フィルターとハイライトが初期状態に戻る。

### Errors
- `bounds` が空または非正の場合、空状態メッセージを表示しクラッシュしない。
- 詳細インスペクター連動先ノードが存在しない場合、モーダルを開かずトーストまたは無操作で安全に無視する。

### Constraints
- ビューポート操作はブラウザネイティブスクロールと CSS 変換を優先し、重厚な Canvas ライブラリを追加しない。
- Core のレイアウト座標計算（SPEC-0018）と UI シェル操作（本仕様）の責務を分離し、座標アルゴリズムを UI 層に漏らさない。
