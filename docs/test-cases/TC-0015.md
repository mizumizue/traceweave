## Content

### Objective
Web ダッシュボードにおける工程層定義、ゲージ閾値、モーダル/エクスポートの公開データ契約が一貫して連携することを検証する。ブラウザ上の通知描画は本ケースの対象外とする。

### Preconditions
- Web フロントエンド資材がビルド可能であり、必要なコンポーネントが配置されていること。

### Steps
1. 5大工程の層定義とゲージ閾値の公開計算結果を確認する。
2. レポートのマトリクスを CSV/JSON へ変換できることを確認する。

### Expected Results
- 5工程、閾値色、およびエクスポート出力の契約が整合すること。
