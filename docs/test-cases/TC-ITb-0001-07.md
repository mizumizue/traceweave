## Content

### Objective
単体工程はコードカバレッジに基づき `heavy`、トレース上外部結合が未充足の工程は `missing` と区分されることを、公開レポートの地層一覧から検証する。

### Preconditions
トレーサビリティ集計レポートが生成可能であること。

### Steps
1. 高重要度要件に単体実行合格のみが紐づき、外部結合が未充足の集計データを用意する。
2. レポートの工程地層一覧で単体と外部結合の密度区分を確認する。

### Expected Results
- 単体工程のカバレッジ率が 1.0 で密度が `heavy` であること。
- 外部結合工程のカバレッジ率が 0.0 で密度が `missing` であること。
