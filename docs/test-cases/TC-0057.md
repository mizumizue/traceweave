## Content

### Objective
CLI・設定・パッケージマニフェスト・ディレクトリ名の優先順で対象アプリケーション表示名が決定論的に解決されることを検証する。

### Preconditions
テスト用の一時ディレクトリとパッケージマニフェストを用意できること。

### Steps
1. 各優先順（CLI、環境変数、設定ファイル、パッケージ名、ディレクトリ名）の入力を与え、解決関数を呼び出す。
2. 返却された `displayName` と `source` を検査する。

### Expected Results
- 高優先度の入力が低優先度より常に優先されること。
- 全段階で有効名が得られない場合、`unknown-project` がフォールバックとして返ること。
