## Content

### Objective
`traceability_review` プロンプトが要件 ID を含む user ロールメッセージを返すことを検証する。

### Preconditions
MCP プロンプトハンドラが起動可能であること。

### Steps
1. 要件 ID パラメータを指定して `traceability_review` プロンプトを取得する。
2. メッセージ配列のロールと本文を確認する。

### Expected Results
- メッセージが 1 件であること。
- ロールが `user` で、本文に指定要件 ID が含まれること。
