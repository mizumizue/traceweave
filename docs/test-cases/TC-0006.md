## Content

### Objective
`traceweave build` コマンドにより静的ダッシュボードが高速生成され、出力された HTML/JS/CSS に全マトリクスデータ・充足度スコア・地層情報が含まれていることを検証する。

### Preconditions
Vite ビルド環境が利用可能であること。

### Steps
1. `traceweave build --out ./dist-test` を実行する。
2. 出力された `./dist-test/index.html` および静的アセットの存在を検査する。
3. HTML 内に埋め込まれたデータ JSON または参照アセット内に、対象要件の ID・タイトル・テスト充足度が含まれていることを検査する。

### Expected Results
- ビルドが 3 秒以内に exit code 0 で完了すること。
- 生成された `index.html` が存在し、必要な UI コンポーネントおよび全データが含まれていること。

### Actual Results
- ビルド完了時間: 2.3秒（Vite + esbuild による超高速バンドル）。
- 生成ファイル: `index.html`, `assets/index-*.js`, `assets/index-*.css` を正常出力。
- ペイロード検証: 要求・要件・テストケースの全30件の完全なマトリクス埋め込みを確認。

### Evidence
`tests/web/build.test.ts` の実行ログ。
