## Content

### Objective
静的ビルドで生成されたダッシュボード成果物の出力契約を検証する。CLI のビルド実行およびブラウザでの描画やユーザー操作は本ケースの対象外とし、生成物と `data.json` の構造だけを確認する。

### Preconditions
Vite ビルド環境が利用可能であること。

### Steps
1. 既存の静的ビルド出力ディレクトリを検査する。
2. `index.html`、`data.json` および静的アセットの存在を検査する。
3. HTML 内に埋め込まれたデータ JSON または参照アセット内に、対象要件の ID・タイトル・テスト充足度が含まれていることを検査する。

### Expected Results
- `index.html` と `data.json` が存在し、データ JSON に summary、matrix、nodes が含まれること。

### Actual Results
- `index.html`、`data.json`、静的アセットが存在した。
- `data.json` を JSON として読み込み、summary、matrix、nodes と要件スコアを確認した。

### Evidence
`tests/web/build.test.ts` の実行ログ。
