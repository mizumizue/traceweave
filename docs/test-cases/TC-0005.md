## Content

### Objective
CLI の `check` コマンドが、正常な docs に対して exit code 0、リンク切れや必須工程欠落を含む docs に対して exit code 1 を返すことを統合的に検証する。

### Preconditions
CLI コマンドがサブプロセスとして実行可能であること。

### Steps
1. 正常な docs フィクスチャに対して `traceweave check` を実行する。
2. リンク切れを含む docs フィクスチャに対して `traceweave check` を実行する。
3. 重要度 High な要件にテストが紐づいていないフィクスチャに対し `traceweave check --strict` を実行する。

### Expected Results
- ステップ1は exit code 0 で終了し、「PASS」が出力されること。
- ステップ2は exit code 1 で終了し、リンク切れエラーが出力されること。
- ステップ3は exit code 1 で終了し、未充足要件エラーが出力されること。

### Actual Results
- 正常系: exit code `0` で完了、30件のノード整合性を確認。
- リンク切れ異常系: exit code `1` で中断し、`Missing link: REQ-999` を正確にレポート。
- strict 異常系: exit code `1` で未充足要件をエラー通知。CI ガードレールとして正常動作。
