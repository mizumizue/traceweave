## Content

### Objective
存在しない要件 ID に対する MCP 照会が決定論的な未検出エラーを返すことを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 存在しない要件 ID を指定して `get_requirement_status` を呼び出す。
2. エラーフラグとエラーコードを確認する。

### Expected Results
- 応答がエラーとしてマークされること。
- エラーコードが `ERR_REQUIREMENT_NOT_FOUND` であること。
