## Content

### Objective
実プロジェクトの `docs/` を入力として `buildTraceWeaveReport` が matrix・requirements・strata・pyramid・catalog・graph を一括生成し、ダッシュボードが要求する `TraceWeaveReport` 契約を満たすことをシステムレベルで検証する。

### Preconditions
- リポジトリの `docs/` が validate-docs を通過していること。

### Steps
1. `buildTraceWeaveReport({ docsDir: 'docs' })` を実行する。
2. 返却 `report` の必須フィールド存在と件数整合を検査する。
3. `matrix` 行と `requirements` の ID 集合が一致することを確認する。

### Expected Results
- `summary.totalRequirements > 0` かつ `matrix.length === requirements.length`。
- `strata` が 5 工程、`catalog` と `graph` が非空であること。
