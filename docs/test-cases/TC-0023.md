## Content

### Objective
マトリクスデータの各フィルター軸と CSV / JSON / Markdown シリアライズの公開契約が正確に実行されることを単体レベルで検証する。軸を組み合わせたブラウザ上のチップ操作は対象外とする。

### Preconditions
マトリクスデータ（MatrixRow[]）およびエクスポートユーティリティが利用可能であること。

### Steps
1. 重要度（high）、工程（integration_internal）、充足度（unsatisfied）、キーワードの各条件を個別にマトリクス行へ適用し、抽出行を検査する。
2. 各フィルター条件を変更し、抽出集合を再計算する。
3. マトリクスデータを CSV、JSON、Markdown 形式に変換し、ヘッダー行および各カラムのデータ整合性を検査する。

### Expected Results
- ステップ1で各条件に合致する要件行のみが厳格に抽出されること。
- ステップ2で条件の変更により対象集合が再計算されること。
- ステップ3で CSV の列ヘッダーとデータ行、JSON の行オブジェクト、Markdown の表ヘッダーとデータ行が入力データと一致すること。

### Actual Results
- 各フィルター軸と CSV/JSON/Markdown 出力生成の単体アサーションが成功した。複合チップ操作は未検証である。
