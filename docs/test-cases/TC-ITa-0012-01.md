## Content

### Objective
合成グラフ上で `UseCaseSufficiencyScorer` が未割当 UC と参照要件付き UC のスコア・ステータスを正しく返すことを検証する。

### Preconditions
`TraceGraph` と要件充足度リストが構築できること。

### Steps
1. 未割当 UC と `requirement_refs` 付き UC を含むグラフでスコアを算出する。

### Expected Results
- 未割当 UC は `status: unassigned` でスコアを持たないこと。
- 割当 UC は参照要件充足度の平均が 0〜100 の `score` として返ること。
