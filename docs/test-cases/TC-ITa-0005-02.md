## Content

### Objective
テスト実行レポートが存在し対象 TC が passed のとき、統合レポートノードの `execution_status` が passed と整合することを検証する。

### Preconditions
実 `docs/` と（存在する場合）集約テスト実行レポートが利用可能であること。

### Steps
1. テスト実行レポートを読み込み統合レポートを生成する。
2. レポート上で passed の TC ノードの `execution_status` を検査する。

### Expected Results
- 実行レポートで passed の TC は、統合レポート上も `execution_status: passed` となること。
