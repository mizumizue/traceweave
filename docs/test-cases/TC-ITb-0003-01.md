## Content

### Objective
有効な文書ツリーに対して文書整合性検証コマンドが成功し、終了コード 0 となることを検証する。

### Preconditions
リポジトリに検証対象の文書ディレクトリが存在すること。

### Steps
1. リポジトリルートから文書整合性検証コマンドを実行する。
2. 標準出力と終了コードを確認する。

### Expected Results
- 終了コードが 0 であること。
- 成功を示すメッセージが出力されること。
