## Content

### Objective
`DocParser` が `test_case` ドキュメントをパースした際、`execution_status` および `### Actual Results` セクションを含む全セクションが欠損なく抽出され、`DocNode` オブジェクトに保持されることを検証する。

### Preconditions
- 実行ステータス `passed` および `### Actual Results` を含むテストケース Markdown が存在すること。

### Steps
1. `DocParser.parseFile()` にテストケース Markdown ファイルを渡す。
2. 返却された `DocNode` の `execution_status`、`sections`、`actual_result` をアサートする。

### Expected Results
- `node.execution_status` が `'passed'` であること。
- `node.sections['Actual Results']` に実測テキストが格納されていること。
- `node.sections['Objective']` および `node.sections['Expected Results']` が正常に取得できること。

### Actual Results
- 一時 Markdown の `execution_status`、`actual_result`、Objective、Expected Results、Actual Results が抽出され、パース結果が合格した。

### Evidence
- `tests/infrastructure/storage.test.ts` の test_case セクション・実測値アサーション全件グリーン。
