## Content

### Objective
Web ダッシュボードのビルド（`npm run build:web`）を実行した際、リポジトリルート直下に `dist-web` が生成されず、`dist/web/` 配下に `index.html`、CSS/JS アセット、および `data.json` が生成されること、ならびにリポジトリルート直下に個別の Web 開発資材（`index.html`, `vite.config.ts`, `tailwind.config.js`, `postcss.config.js`）が存在しないことを検証する。

### Preconditions
- プロジェクトの依存関係がインストールされていること。
- `src/web/` 配下に Web 開発資材が集約されていること。

### Steps
1. リポジトリルート直下のファイル一覧を取得し、`index.html`, `vite.config.ts`, `tailwind.config.js`, `postcss.config.js`, `dist-web` が存在しないことを検証する。
2. `src/web/` 配下に `index.html`, `vite.config.ts`, `tailwind.config.js`, `postcss.config.js` が存在することを検証する。
3. `npm run build:web` を実行する。
4. `dist/web/` ディレクトリが存在し、配下に `index.html`, `data.json`, `assets/` が生成されていることを確認する。

### Expected Results
- ルート直下にはガバナンス文書（README, ARCHITECTURE, DEVELOPER_GUIDE）、定義ファイル（package.json, tsconfig.json, .gitignore）等のみが存在し、Web 開発資材が存在しないこと。
- `dist/web/index.html` および `dist/web/data.json` が正常に生成されていること。

### Actual Results
- ルート直下を検査し、Web 開発資材および `dist-web` の完全排除を確認。
- `dist/web/` 配下に HTML、JS、CSS、`data.json` が正常に出力されたことを自動テストにて実測検証。

### Evidence
- `tests/web/clean-root.test.ts` による自動検証およびビルド出力アサーションの成功ログ。
