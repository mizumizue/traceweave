## Content

### Objective
本ケースは実行時システム要件ではなく、リポジトリ構成に関する ADR/Chore の確認である。Web 開発資材の配置とビルド出力を、開発環境上で確認する。

### Preconditions
- プロジェクトの依存関係がインストールされていること。
- `src/web/` 配下に Web 開発資材が集約されていること。

### Steps
1. リポジトリルート直下に `index.html`, `vite.config.ts`, `tailwind.config.js`, `postcss.config.js`, `dist-web` が存在しないことを検証する。
2. `src/web/` 配下に `index.html`, `vite.config.ts`, `tailwind.config.js`, `postcss.config.js` が存在することを検証する。
3. `src/web/dist/` 配下に `index.html` と `data.json` が存在することを確認する。

### Expected Results
- ルート直下に個別の Web 開発資材が存在せず、Web 資材が `src/web/` に配置されていること。
- `src/web/dist/index.html` および `src/web/dist/data.json` が存在すること。
