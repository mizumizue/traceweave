## Content

### Objective
本ケースは実行時システム要件ではなく、リポジトリ構成とラッパー配置に関する ADR/Chore の確認である。ラッパーの存在と配置だけを確認し、実行結果は CLI 契約テストで扱う。

### Preconditions
`bin/` 配下のラッパースクリプト群および `src/cli/index.ts` が利用可能であること。

### Steps
1. リポジトリルートを検査し、ルート直下に `node_modules`, `dist`, `dist-web` が存在しないことを確認する。
2. `bin/traceweave`, `bin/traceweave.cmd`, `bin/traceweave.ps1` の配置を確認する。
3. 各 OS 用ラッパーのファイルが配置されていることを確認する。ラッパーの実行契約は CLI テストで検証する。

### Expected Results
- ステップ1および2で、ルートの禁止資材がなく、ラッパーと `src/` の構成資材が配置されていること。
- ステップ3で、各 OS 用ラッパーのファイルが存在すること。ラッパー実行結果は本ケースの判定対象に含めないこと。
