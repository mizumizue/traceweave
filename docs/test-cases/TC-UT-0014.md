## Content

### Objective
TraceabilityGraphBuilder が選択ノードのハイライトを単体で算出する。

### Preconditions
最小 NEED–REQ–SPEC 連鎖と孤立 NEED ノードを含む合成グラフが定義されていること。

### Steps
1. 選択ノード `REQ-0020`・ハイライトモード `all` で `TraceabilityGraphBuilder.buildGraph` を実行する。
2. 選択ノードの `isHighlighted` と孤立ノード `NEED-9999` の `isDimmed` を検査する。

### Expected Results
- 選択ノードがハイライト対象となること。
- 連鎖外の孤立ノードがディム（非強調）となること。
