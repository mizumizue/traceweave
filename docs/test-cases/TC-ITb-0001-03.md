## Content

### Objective
システム・受入テストに偏重した逆ピラミッド分布で、診断が `inverted_ice_cream` となり逆ピラミッド警告が出ることを検証する。

### Preconditions
対話型テスト実行 API が利用可能であること。

### Steps
1. 単体・結合が少なくシステム・受入が多い配分を入力とする実行要求を送信する。
2. 返却 JSON の診断ステータスと警告一覧を確認する。

### Expected Results
- 診断ステータスが `inverted_ice_cream` であること。
- 逆ピラミッドに関する警告が含まれること。
