## Content

### Objective
レポート生成時に `subjectOverride` を指定した場合、自動解決より優先され `subject.source` が CLI 由来となることを検証する。

### Preconditions
有効な docs ディレクトリが存在すること。

### Steps
1. 件名の手動指定オプションを与えて統合レポートを生成する。
2. レポート件名の表示名と取得元を検査する。

### Expected Results
- 表示名が手動指定値と一致すること。
- 取得元がコマンドライン指定であること。
