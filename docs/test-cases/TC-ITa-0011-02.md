## Content

### Objective
レポート生成時に `subjectOverride` を指定した場合、自動解決より優先され `subject.source` が CLI 由来となることを検証する。

### Preconditions
有効な docs ディレクトリが存在すること。

### Steps
1. `subjectOverride` を指定して統合レポートを生成する。
2. `subject.displayName` と `subject.source` を検査する。

### Expected Results
- `displayName` が override 値と一致すること。
- `source` が `cli` であること。
