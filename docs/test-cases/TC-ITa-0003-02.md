## Content

### Objective
HTTP 対話型テスト実行エンドポイントが、未登録 TC ID に 404、UI 実行除外 TC に 400 を返す契約を検証する。

### Preconditions
対話型テスト実行 API が起動可能であること。

### Steps
1. 存在しない TC ID で実行要求を送信する。
2. UI 実行除外対象（例: TC-ITb-0007）で実行要求を送信する。

### Expected Results
- 未登録 ID は HTTP 404 かつ `ERR_UNKNOWN_TEST_CASE` となること。
- UI 除外 ID は HTTP 400 かつ `ERR_NOT_UI_EXECUTABLE` となること。
