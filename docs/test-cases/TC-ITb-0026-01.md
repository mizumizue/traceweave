## Content

### Objective
MCP サーバーが契約どおり 7 件のツール名を公開することを検証する。

### Preconditions
MCP ツールハンドラが起動可能であること。

### Steps
1. MCP ツール一覧 API を呼び出す。
2. 返却されたツール名の件数と並びを確認する。

### Expected Results
- ツール数が 7 件であること。
- 公開名が仕様で定義された固定集合と一致すること。
