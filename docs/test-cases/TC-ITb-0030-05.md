## Content

### Objective
MCP 拡張ツール `get_catalog` が種別フィルタ付きカタログ JSON を返すことを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 種別 `requirement` を指定して `get_catalog` を呼び出す。
2. 返却 JSON の件数フィールドと items 配列を確認する。

### Expected Results
- `filteredCount` が 0 以上であること。
- `items` が配列であること。
