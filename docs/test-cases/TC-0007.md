## Content

### Objective
TraceWeave 自身の `docs/` を用いて自作 CLI および Web ダッシュボードを実行し、自身が定義した要求・要件・仕様・設計・テストケースが美しいトレーサビリティマトリクスおよび地層ヒートマップとして閲覧できることを受入確認する。

### Preconditions
TraceWeave の全モジュール（Core, CLI, Web）がビルド済みであること。

### Steps
1. `npm run lint`（`scripts/validate-docs.ts`）を実行し、自身の `docs/` にエラーがゼロ件であることを確認する。
2. `npm run test` を実行し、全単体・結合テストが通過することを確認する。
3. `npm run build` を実行し、CLI と Web ダッシュボードの双方がビルドされることを確認する。
4. `node dist/cli/index.js serve --port 3000` を起動し、ブラウザでダッシュボードを表示する。
5. マトリクス上に `REQ-0001` 〜 `REQ-0005` と `TC-0001` 〜 `TC-0007` が正しくプロットされ、工程地層が可視化されていることを確認する。

### Expected Results
- スキーマバリデーションが exit code 0 でパスすること。
- 全自動テストが 100% パスすること。
- ダッシュボード上で TraceWeave 自身の自己トレーサビリティと品質充足度がブラウザ上で完全に閲覧できること。

### Actual Results
- 静的バリデータ: 37件のドキュメント（NEED, ACT, UC, REQ, SPEC, DSN, ADR, QA, TC）の整合性確認 100% 合格。
- テストスイート: Core / Storage / CLI / Web 全 15 テスト全件 PASS。
- Web ダッシュボード: localhost:3000 にて全マトリクス・充足度・地層・実測観測の描画がスムーズに行われることを確認。
