## Content

### Objective
REQ-0002 AC-004 および AC-005 に基づき、テストケース文書が要件に紐づいていても、実行ステータスが未実行・失敗・スキップである場合に充足度スコアと工程密度へ加算されないことを検証する。実行合格したテストケースのみがスコアに寄与し、文書件数と実行合格件数が分離して観測できることを固定入力で確認する。

### Preconditions
充足度スコア計算の公開計算面が利用可能であること。

### Steps
1. 重要度 High の要件に、単体・内部結合・外部結合・受入のテストケース文書を紐づけ、すべての実行ステータスを未実行（`pending`）のままスコアを算出する。
2. 同一の文書構成で、単体テストのみ実行合格（`passed`）、残りは未実行・失敗・スキップとしてスコアを算出する。
3. 失敗ステータスの単体テストのみが紐づく要件のスコアを算出する。

### Expected Results
- ステップ1の充足度スコアが 0% であり、文書として紐づくテストケース ID および文書工程件数は保持されるが、実行合格 ID および実行工程件数はすべて 0 であること。
- ステップ2の充足度スコアが 30%（High 重要度で単体工程のみ実行合格）であり、文書件数と実行合格件数が異なる値として観測できること。
- ステップ3の充足度スコアが 0% であること。
