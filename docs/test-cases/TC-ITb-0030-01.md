## Content

### Objective
文書ディレクトリ内の Markdown が MCP リソース URI として列挙され、本文が読み取れることを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 文書リソース一覧 API を呼び出す。
2. 代表リソース（需要文書 NEED-0001）の URI を特定し、読取 API で本文を取得する。

### Expected Results
- リソースが 1 件以上列挙されること。
- 読取本文に `NEED-0001` が含まれること。
