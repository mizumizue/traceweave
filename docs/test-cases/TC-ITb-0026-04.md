## Content

### Objective
MCP ツール `check_quality_gaps` が品質ギャップ検証結果を構造化 JSON で返すことを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 非 strict モードで `check_quality_gaps` を呼び出す。
2. 返却 JSON のトップレベルフィールドを確認する。

### Expected Results
- `passed` が boolean であること。
- `errors` と `warnings` が配列であること。
