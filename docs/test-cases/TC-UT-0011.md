## Content

### Objective
`DocParser` がテストケース文書から Objective / Steps / Expected Results セクションを単体で抽出することを検証する。

### Preconditions
代表テストケース文書 `TC-UT-0001.md` が存在すること。

### Steps
1. `DocParser.parseFile` で当該文書をパースする。
2. 返却ノードの `sections.Objective`、`sections.Steps`、`sections['Expected Results']` を検査する。

### Expected Results
- 3 セクションすべてが非空文字列として抽出されること。
