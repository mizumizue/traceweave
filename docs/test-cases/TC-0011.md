## Content

### Objective
対話型テスト実行APIにおいて、外部パラメータパターン相当の入力を受け取り、実測値、合否、差分情報を含む応答を返す契約を検証する。ブラウザ上のフォーム操作や描画は対象外とする。

### Preconditions
- TraceWeave のテスト実行エンドポイントが起動可能であること。

### Steps
1. テスト実行エンドポイントを起動する。
2. パターン入力および期待値を含む実行要求を送信する。
3. 返却された JSON の実測値、合否、差分情報を検査する。

### Expected Results
- 実行要求に対して HTTP 200 と JSON の `status`、`actual`、`isMatch` を返すこと。
- 期待値一致時の `status` が `passed` となり、診断結果が入力に対応すること。
