## Content

### Objective
Web ダッシュボードの対話型ランナーにおいて、外部パラメータパターンの選択、手動入力変更、および「テスト実行」ボタン押下によるリアルタイム実測値の取得・UI反映（合格バッジ、期待値/実測値Diff表示、実行時間）の一連のシナリオを検証する。

### Preconditions
- TraceWeave サーバーまたはアイソモーフィック実行エンジンが稼働しており、テストエンドポイントが有効であること。

### Steps
1. テストケース詳細モーダルを展開し、対話型ランナーを表示する。
2. 事前定義パターンから「境界値パターン」を選択し、入力値がフォームに反映されることを確認する。
3. 入力値の一部を変更し、「テストを実行 (Run Test)」ボタンを押下する。
4. 返却された実測値（Actual Results）および所要時間（durationMs）がモーダル上に即座に描画されることを確認する。

### Expected Results
- 実行後 200ms 以内に実測結果が画面上に描画されること。
- ステータスバッジ（PASSED または FAILED）が正しく切り替わること。
- 実測値と期待値が対比カードにリアルタイム表示されること。

### Actual Results
- 実行レイテンシ: 4.8ms（ローカルAPI）。
- パラメータ変更後の手動実行において、実測値・合否バッジ・実行時間が即時更新されることをブラウザおよび統合テストにて確認。

### Evidence
- `tests/cli/interactive-api.test.ts` および Vite ビルド検証ログ。
