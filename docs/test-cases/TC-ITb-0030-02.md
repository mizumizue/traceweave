## Content

### Objective
MCP サーバーが契約どおり 3 件のプロンプト名を公開することを検証する。

### Preconditions
MCP プロンプトハンドラが起動可能であること。

### Steps
1. MCP プロンプト一覧 API を呼び出す。
2. 返却件数と名前集合を確認する。

### Expected Results
- プロンプト数が 3 件であること。
- 公開名が仕様で定義された固定集合と一致すること。
