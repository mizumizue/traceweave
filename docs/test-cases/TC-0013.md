## Content

### Objective
生成されたダッシュボードデータおよびコンポーネントにおいて、全体品質充足度、重要要件充足率、マトリクス行の充足度、各工程地層のカバー率の全箇所で円グラフ用データおよび SVG レンダリング構造が正しく統合されていることを検証する。

### Preconditions
- `buildTraceWeaveReport` によって生成された `TraceWeaveReport` が存在すること。

### Steps
1. `buildTraceWeaveReport()` を実行し、レポートデータを取得する。
2. ヘッダーの全体充足度・High要件充足率が円グラフコンポーネントに入力可能であることを検証する。
3. マトリクスの全要件行のスコアが 0〜100% の範囲で円グラフにマッピングされることを検証する。
4. 全工程（unit, integration_internal, integration_external, system, acceptance）のカバー率が円グラフ表示に対応していることを検証する。

### Expected Results
- 全ての率表示項目において、円グラフ表示用のパーセント値が欠損なく揃っていること。
- 各行・各カードで円グラフゲージが破綻なく描画されること。

### Actual Results
- レポートに含まれる全要件および 5 工程の数値が正確に円グラフに反映され、描画テストに合格した。

### Evidence
- `tests/web/circular-gauge.test.ts` および `tests/web/build.test.ts` の実行結果。
