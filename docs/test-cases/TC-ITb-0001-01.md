## Content

### Objective
工程別テスト件数が単体多・上位少の健全ピラミッド配分であるとき、ピラミッド診断結果が `healthy` となり警告が出ないことを検証する。

### Preconditions
対話型テスト実行 API が利用可能であること。

### Steps
1. 健全ピラミッド配分（単体が最多、受入が最少）を入力とする実行要求を送信する。
2. 返却 JSON の診断ステータスと警告一覧を確認する。

### Expected Results
- 診断ステータスが `healthy` であること。
- 警告メッセージが空であること。
