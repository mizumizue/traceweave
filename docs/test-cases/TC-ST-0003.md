## Content

### Objective
ビルド済み Web ダッシュボードを実ブラウザで開き、トレーサビリティ UI とマトリクス上の要件行が利用者に観測できることをシステムレベルで確認する。

### Preconditions
静的ビルド成果物が生成済みであり、プレビュー用 HTTP サーバーが利用可能であること。

### Steps
1. ブラウザでダッシュボードのルート URL を開く。
2. ページタイトルおよびトレーサビリティ関連の見出し・ラベルが表示されることを確認する。
3. マトリクス領域に要件 ID（`REQ-` 形式）を含む行が 1 件以上表示されることを確認する。

### Expected Results
- ダッシュボードがエラーなく読み込まれ、トレーサビリティ UI が表示されること。
- マトリクス上で少なくとも 1 件の要件行が観測できること。
