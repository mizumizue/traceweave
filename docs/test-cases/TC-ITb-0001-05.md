## Content

### Objective
外部結合偏重かつシステムテスト欠落・単体僅少の分布で、診断が `unbalanced` となり工程欠落・偏重警告が出ることを検証する。

### Preconditions
対話型テスト実行 API が利用可能であること。

### Steps
1. 外部結合が過多でシステムがゼロ、単体が少ない配分を入力とする実行要求を送信する。
2. 返却 JSON の診断ステータスと警告一覧を確認する。

### Expected Results
- 診断ステータスが `unbalanced` であること。
- システムテスト欠落および偏重に関する警告が含まれること。
