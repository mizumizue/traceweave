## Content

### Objective
MCP 拡張ツール `get_decisions` が ADR と DSN の配列を返すことを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 文書ディレクトリを入力として `get_decisions` を呼び出す。
2. 返却 JSON の `adrs` と `dsns` を確認する。

### Expected Results
- `adrs` と `dsns` がいずれも配列であること。
