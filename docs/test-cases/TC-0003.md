## Content

### Objective
`BalanceAnalyzer` が各工程のテストケース分布から地層密度（Heavy, Adequate, Thin, Missing）を判定し、「逆ピラミッド」「中間空洞化」等のアンチパターンを正しく警告することを、外部パラメータセットと合成入力の両方で検証する。

### Preconditions
`BalanceAnalyzer` モジュールがロードされていること。

### Steps
1. 外部パラメータセットの正常分布を入力して診断する。
2. 逆ピラミッド分布（UT: 2件, ITa: 2件, ITb: 1件, ST: 10件, UAT: 25件）を合成入力して診断する。
3. 中間空洞化分布（UT: 10件, ITa: 0件, ITb: 0件, ST: 5件, UAT: 2件）を合成入力して診断する。
4. `fixtures/test-cases/TC-0011.json` を読み込み、定義された3パターンを同じ診断処理へ渡す。

### Expected Results
- ステップ1で `healthy` と判定され、警告がないこと。
- ステップ2で `InvertedIceCream`（逆ピラミッド警告）が報告されること。
- ステップ3で `HollowHourglass`（中間空洞化警告）が報告されること。
- ステップ4で3パターンすべてが期待ステータス（`healthy`, `inverted_ice_cream`, `hollow_hourglass`）と一致し、失敗が0件であること。
- unit のカバレッジ率が `1.0` で `heavy`、integration_external のカバレッジ率が `0.0` で `missing` と判定されること。

### Actual Results
- 合成入力で `Healthy`、`InvertedIceCream`、`HollowHourglass` を検出し、unit=`heavy`、integration_external=`missing` を確認した。
- 外部パラメータセットの3パターンがすべて期待ステータスと一致し、失敗は0件だった。
