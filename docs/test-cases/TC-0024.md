## Content

### Objective
Web ダッシュボードで共有されるモーダル履歴、工程層選択、マトリクスフィルター、エクスポートの公開データ契約が一貫することを検証する。実ブラウザの連続操作は対象外とする。

### Preconditions
レポートデータと公開された UI 契約関数が利用可能であること。

### Steps
1. 公開されたモーダル履歴契約でノード遷移と戻る操作を実行する。
2. ピラミッド層メトリクス契約と重要度フィルターを同じレポートデータへ適用し、対象重要度の行だけが残ることを検証する。
3. フィルター結果を CSV / JSON へシリアライズし、出力データが生成されることを検証する。
4. トレーサビリティグラフにおいて REQ-0013, REQ-0014, REQ-0015 および SPEC-0013, SPEC-0014, SPEC-0015 の追跡関係が正しく成立していることを確認する。

### Expected Results
- モーダル履歴、ピラミッド層メトリクス、重要度フィルター、エクスポート出力の公開契約が一貫して成立すること。
- トレーサビリティグラフにおいて対象要件および仕様が本テストケースによって検証対象として追跡されること。
