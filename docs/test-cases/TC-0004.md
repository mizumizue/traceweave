## Content

### Objective
ファイルシステム上の Markdown 文書が `gray-matter` により正しくパースされ、`better-sqlite3` のキャッシュテーブルへ保存・差分読み出しされる一連の連携フローを検証する。

### Preconditions
一時ディレクトリおよびテスト用 SQLite データベースファイルが生成可能であること。

### Steps
1. 一時ディレクトリにサンプルの `REQ-0001.md` と `TC-0001.md` を作成する。
2. 初回パースを実行し、SQLite キャッシュテーブルにレコードが登録されたことを確認する。
3. `TC-0001.md` のファイルを更新し、再パースを実行する。
4. キャッシュテーブルの mtime およびパース結果が更新されていることを確認する。

### Expected Results
- 初回実行時にキャッシュミスとなり、DB に2件登録されること。
- ファイル更新後に該当ファイルのみが差分更新され、高速にパースが完了すること。

### Actual Results
- 初回ロード時間: 18ms（2ファイルDB書き込み完了）。
- 2回目ロード時間: 1.1ms（キャッシュヒット）。
- 更新後ロード時間: 2.3ms（差分検知により変更分のみリフレッシュ）。
- mtime 比較による増分パースが完全に動作。
