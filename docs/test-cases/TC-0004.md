## Content

### Objective
一時ディレクトリの Markdown 文書をパースし、SQLite キャッシュへの保存と同一ファイル再読込時のキャッシュヒットを検証する。

### Preconditions
一時ディレクトリおよびテスト用 SQLite データベースファイルが生成可能であること。

### Steps
1. 一時ディレクトリにサンプルの `NEED-0001.md` を作成する。
2. 初回パースを実行し、SQLite キャッシュに1件登録されたことを確認する。
3. 同じパーサーで再パースを実行し、同一ノードがキャッシュから復元されたことを確認する。

### Expected Results
- 初回実行時にキャッシュミスとなり、DB に1件登録されること。
- 2回目のパースで同じノードがキャッシュから復元されること。
