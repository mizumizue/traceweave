## Content

### Objective
要件区分の許容値判定、未設定の扱い、および FR / NFR ラベル契約が決定論的に守られることを検証する。

### Preconditions
- 区分判定モジュールがメモリ内で呼び出せること。
- 機能要件と非機能要件、未設定、不正値の入力を与えられること。

### Steps
1. `functional` および `non_functional` を判定関数へ渡し、それぞれが許容値として受理されることを確認する。
2. 欠落および許容値外の文字列を判定関数へ渡し、未分類として扱われ、別の区分へ置換されないことを確認する。
3. 機能要件と非機能要件の短ラベル／見出し語が `FR` / `機能要件` および `NFR` / `非機能要件` であることを確認する。
4. 混在する要件ノード配列から件数集計を行い、機能件数・非機能件数・未分類件数が入力と一致することを確認する。

### Expected Results
- 許容値のみが区分として確定し、不正値は未分類のまま残る。
- ラベルが契約どおりであり、重要度ラベルと入れ替わらない。
- 同一入力に対する件数が繰り返し計算しても一致する。
