## Content

### Objective
Web ダッシュボードにおいて、HTML5 History API と URL クエリパラメータの双方向同期が正しく機能し、ブラウザバック・進む操作による画面復元、URL による現在地・フィルター状態表現、および共有機能が仕様（SPEC-0019）を満たしていることを検証する。

### Preconditions
1. `urlState.ts` モジュールにおいてクエリパラメータのパースおよびシリアライズ機能が提供されていること。
2. `App.tsx` において History API（`pushState`, `replaceState`, `popstate` イベント）との双方向同期が統合されていること。

### Steps
1. 各種クエリ文字列（正常値、異常値、デフォルト値混在、欠損パターン）を `parseUrlState` に投入し、パース結果およびフォールバック動作を検証する。
2. アプリケーション状態オブジェクトを `serializeUrlState` に投入し、不要なデフォルト値が適切に省略されたクリーンなクエリ文字列が生成されることを検証する。
3. タブ切り替え、ノード詳細モーダル開閉、ノード間遷移において `pushState` が正しく発行されることを検証する。
4. 検索テキスト入力において履歴を汚さず `replaceState` が発行されることを検証する。
5. `popstate` イベント発火時に同期ガードが機能し、二重 `pushState` によるループが発生することなく状態が復元されることを検証する。
6. ヘッダーの共有リンクボタン押下時に完全な URL が取得・コピーされることを検証する。

### Expected Results
1. クエリパラメータ（`tab`, `node`, `q`, `phase`, `criticality`, `score`, `kind`, `tag`, `status`, `highlight`）が仕様通り相互変換されること。
2. 不正な値（不正なタブ名や重要度等）が渡された場合、デフォルト値に安全にフォールバックすること。
3. ブラウザバック時にモーダルが閉じたり直前ノードに戻る履歴遷移が成立すること。
4. テストスイートが全件パスし、退行がないこと。

### Actual Results
全自動テスト（`tests/web/history-url-navigation.test.ts`）において、パース・シリアライズ・履歴更新判定・異常系フォールバック・UI統合コードの全アサーションが成功した。
