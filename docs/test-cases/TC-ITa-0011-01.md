## Content

### Objective
レポート生成結果の JSON に `subject.displayName` が含まれ、マークダウン出力先頭に同一名称が反映されることを検証する（UI ヘッダー・ブラウザタイトルは別 TC）。

### Preconditions
有効な docs ディレクトリが存在すること。

### Steps
1. 統合レポートを生成し `subject` フィールドを検査する。
2. マークダウンレポーターで出力し、先頭見出しを検査する。

### Expected Results
- `subject.displayName` が空でないこと。
- マークダウン先頭に対象アプリケーション名が含まれること。
