## Content

### Objective
ノード詳細モーダルが利用する閲覧履歴、離脱判定、およびコピー対象文字列の公開契約を単体レベルで検証する。実 DOM イベント dispatch、クリップボード書き込み、および完了フィードバックはブラウザテストの対象外とする。

### Preconditions
モーダルの公開ナビゲーション契約が利用可能であること。

### Steps
1. 閲覧履歴スタック配列に初期ノード REQ-0001、遷移ノード SPEC-0002、TC-0001 を順次プッシュし、戻る（back）操作および進む（forward）操作時のインデックスとアクティブノードの変化を検査する。
2. Escape キーとオーバーレイクリックの値を離脱判定契約へ渡し、クローズ対象かを検査する。
3. ノード情報（ID、パス、Markdown本文）からコピー対象文字列を生成し、値を検査する。クリップボード書き込みは実行しない。

### Expected Results
- ステップ1で戻る操作によりインデックスが正しく減算され、進む操作により元のノードへ復帰できること。
- ステップ2で Escape とオーバーレイ自身のクリックだけがクローズ対象として判定されること。
- ステップ3で ID、パス、Markdown 本文のコピー対象文字列が正しく生成されること。クリップボード書き込みや完了フィードバックは判定対象に含めないこと。
