## Content

### Objective
区分フィルターが URL クエリ `reqclass` と双方向に同期し、不正値は安全に全体表示へ戻り、ホーム状態では区分フィルターが初期化されることを検証する。

### Preconditions
- URL 状態のパース／シリアライズ関数がメモリ内で呼び出せること。

### Steps
1. `reqclass=functional` および `reqclass=non_functional` をパースし、対応する区分フィルターになることを確認する。
2. `reqclass` 欠落時は `all` になり、シリアライズ時に `reqclass` が省略されることを確認する。
3. `reqclass=quality` など不正値は例外なく `all` へフォールバックすることを確認する。
4. ホーム状態オブジェクトの区分フィルターが `all` であることを確認する。

### Expected Results
- 正常値は相互変換され、デフォルトは URL に現れない。
- 不正値は `all` に落ち、ホーム状態は区分フィルターを持たない（全体表示）。
