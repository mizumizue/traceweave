## Content

### Objective
単体とシステムはあるが内部・外部結合が欠落した砂時計型分布で、診断が `hollow_hourglass` となることを検証する。

### Preconditions
対話型テスト実行 API が利用可能であること。

### Steps
1. 結合工程がゼロで単体とシステムのみが厚い配分を入力とする実行要求を送信する。
2. 返却 JSON の診断ステータスと警告一覧を確認する。

### Expected Results
- 診断ステータスが `hollow_hourglass` であること。
- 中間空洞化に関する警告が含まれること。
