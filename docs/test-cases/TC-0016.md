## Content

### Objective
リポジトリルート直下に `node_modules/` および `dist/` が存在しないこと、`src/` 配下に `package.json`、`tsconfig.json`、`node_modules/`、`dist/` がカプセル化されていること、およびルートの `bin/traceweave` ラッパーが `NODE_PATH` を自動解決して正常に機能することを検証する。

### Preconditions
- `src/` 配下に `package.json` および `tsconfig.json` が配置され、依存関係が解決されていること。
- `bin/traceweave`（POSIX bash / Windows cmd / ps1）が配置され、実行可能であること。

### Steps
1. リポジトリルート直下のディレクトリエントリを検査し、`node_modules` および `dist` が存在しないことを検証する。
2. `src/` 配下に `package.json`, `tsconfig.json` が存在することを確認する。
3. `bin/` 配下に `traceweave` ラッパースクリプトが存在することを確認する。
4. `./bin/traceweave check`（または Windows 用スクリプト）を実行し、終了コード 0 で正常終了することを確認する。

### Expected Results
- ルート直下には `node_modules`、`dist`、`dist-web` が一切存在せず、ガバナンス文書、定義文書、および `bin/` のみが配置されていること。
- `./bin/traceweave check` が `src/node_modules` を自動認識して正常にパスすること。

### Actual Results
- ルート直下のエントリ検査により、`node_modules` と `dist` の完全排除を確認。
- `bin/traceweave check` の実行により、ドキュメント検証およびトレーサビリティチェックが正常にパスしたことを実測検証。

### Evidence
- `tests/web/clean-root.test.ts` での自動アサーション成功ログおよび `./bin/traceweave check` の実行出力。
