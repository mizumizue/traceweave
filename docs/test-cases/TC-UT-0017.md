## Content

### Objective
Web ヘッダー用の `for {displayName}` 文言とブラウザタイトル形式が契約どおり生成されることを検証する。

### Preconditions
表示名フォーマット関数が公開されていること。

### Steps
1. 表示名を与え、ヘッダー接尾辞とドキュメントタイトル生成関数を呼び出す。
2. 返却文字列を検査する。

### Expected Results
- ヘッダー接尾辞が `for {displayName}` 形式であること。
- ドキュメントタイトルが `TraceWeave — {displayName}` 形式であること。
