## Content

### Objective
MCP 拡張ツール `get_traceability_matrix` がトレーサビリティマトリクス配列を返すことを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 文書ディレクトリを入力として `get_traceability_matrix` を呼び出す。
2. 返却 JSON の `matrix` フィールドを確認する。

### Expected Results
- `matrix` が配列であること。
- 配列長が 1 以上であること。
