## Content

### Objective
MCP ツール `get_traceability_summary` が文書ツリー向けのサマリ JSON を返すことを検証する。

### Preconditions
リポジトリに有効な文書ディレクトリが存在すること。

### Steps
1. 文書ディレクトリを入力として `get_traceability_summary` を呼び出す。
2. 返却 JSON の `subject` と `summary` を確認する。

### Expected Results
- エラー応答ではないこと。
- `summary.totalRequirements` が 1 以上であること。
- `summary.overallSufficiencyScore` が 0 以上であること。
