## Content

### Objective
`TestCaseInputAnalyzer` が TC-ITb-0007 および TC-ITb-0002 を UI 実行対象外と判定し、`TestRunnerRegistry` が当該 ID を実行可能として登録しないことを検証する。

### Preconditions
当該テストケース文書が `docs/test-cases/` に存在すること。

### Steps
1. 文書をパースし `ui_executable` を確認する。
2. `TestCaseInputAnalyzer.analyze` の理由コードを確認する。
3. `TestRunnerRegistry` が両 ID で未登録であることを確認する。

### Expected Results
- 両 TC で `ui_executable: false` かつ `external_environment_dependency` となること。
- `TestRunnerRegistry.has` が両 ID で `false` となること。
