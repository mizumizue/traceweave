## Content

### Objective
内部・外部結合が厚く全工程が揃ったトロフィー型分布のとき、診断が `healthy_trophy` となることを検証する。

### Preconditions
対話型テスト実行 API が利用可能であること。

### Expected Results
- 診断ステータスが `healthy_trophy` であること。
- 警告メッセージが空であること。
