## Content

### Objective
ノード間の依存関係を正しく接続し、循環参照（A -> B -> C -> A）および孤立ノードを検出できることを単体テストで検証する。

### Preconditions
テストランナー（`tsx --test`）が利用可能であり、Core モジュールがインポートできること。

### Steps
1. 合成ノードを `TraceGraph.addNode` で登録し、上流・下流および要件に紐づくテストケースを探索する。
2. `graph.detectCycles()` の戻り値を検査する。
3. 接続されていない `REQ-9999` と未存在 ID を参照する `SPEC-9999` を追加し、孤立ノードと欠落参照を検査する。

### Expected Results
- ステップ1で `NEED-0001`、`REQ-0001`、`SPEC-0001`、`TC-0001` の関係が探索できること。
- ステップ2で `REQ-0001`、`SPEC-0001`、`DSN-0001` の循環が検出されること。
- ステップ3で `REQ-9999` が孤立ノード、`DOES_NOT_EXIST` が欠落参照として特定されること。
