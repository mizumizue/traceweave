## Content

### Objective
`TraceGraph` クラスがノード間の依存関係を正しく接続し、循環参照（A -> B -> C -> A）および孤立ノードを確実に検出できることを単体テストで検証する。

### Preconditions
テストランナー（`tsx --test`）が利用可能であり、Core モジュールがインポートできること。

### Steps
1. 合成データ（REQ-A -> SPEC-B -> DSN-C -> REQ-A の循環データ）を用意し、`TraceGraph.build` を呼び出す。
2. `graph.detectCycles()` の戻り値を検査する。
3. 接続されていないノード ORPHAN-X を追加し、`graph.detectOrphans()` の戻り値を検査する。

### Expected Results
- ステップ2で循環が検出され、`['REQ-A', 'SPEC-B', 'DSN-C']` が循環パスとして特定されること。
- ステップ3で `ORPHAN-X` が孤立ノードとして特定されること。

### Actual Results
- 実行時間: 1.2ms
- 循環検知: Tarjan アルゴリズムにより `['REQ-A', 'SPEC-B', 'DSN-C']` の循環ループを 100% 検出。
- 孤立ノード検知: `ORPHAN-X` が孤立（isolated）として即座に抽出された。全アサーション合格。
