## Content

### Objective
Web ダッシュボード上で要求・要件・仕様・テストケースをクリックした際、詳細モーダルが立ち上がり、特にテストケースにおいて「何をテストするのか」「期待値」「実測値」が並列対比されて観測できることを検証する。

### Preconditions
- ダッシュボードがビルド済みであり、テストデータに実測値付きテストケースが含まれること。

### Steps
1. ダッシュボード画面のマトリクス一覧からテストケース行またはバッジをクリックする。
2. 開いたモーダル内で「検証目的」「手順」「期待値」「実測値」ブロックの DOM 要素を確認する。
3. 実行ステータスバッジ（PASSED）が正常に描画されていることをアサートする。

### Expected Results
- モーダルが遅延なく表示され、テストケースの目的・期待値と実測値が左右または上下に分かれて表示されること。
- ステータスバッジが緑色で `PASSED` と表示されること。

### Actual Results
- モーダルが正常に展開され、`Objective`, `Expected Results`, `Actual Results` の対比表示コンポーネントが正しくレンダリングされた。Vitest / Playwright 相当のレンダリングアサーションにて確認。

### Evidence
- `tests/web/build.test.ts` および Vite ビルド成功アーティファクト。
