## Content

### Objective
Web ダッシュボードのヘッダーロゴに関する公開リンク契約、クリック判定、および初期 URL 状態契約が正しいことを検証する。実ブラウザのレンダリング、クリック、履歴動作は対象外とする。

### Preconditions
- ヘッダーのリンク契約および初期 URL 状態契約が利用可能であること。

### Steps
1. ヘッダーが公開するロゴリンク契約から、ルート `href` とアクセシビリティ属性を確認する。
2. 通常クリックが内部遷移対象となり、修飾キー付きクリックが対象外となる公開判定を確認する。
3. 初期 URL 状態がタブ、ノード、検索、フィルターを既定値へ設定していることを確認する。

### Expected Results
- ヘッダーロゴのリンク契約がルート `href` とアクセシビリティ属性を返すこと。
- 初期 URL 状態が `matrix`、ノード未選択、検索空、全フィルターであること。
- 修飾キー付きクリックが内部遷移対象外として判定されること。
