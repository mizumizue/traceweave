## Content

### Objective
フロントマターで宣言したパラメータパターンセットを用い、各パターンの診断ステータスが期待と一致し失敗がゼロであることを検証する。

### Preconditions
対話型テスト実行 API が利用可能であること。

### Steps
1. パラメータセットに含まれる全パターンを順に実行要求として送信する。
2. 各パターンの合否と診断ステータスを集計する。

### Expected Results
- 全パターンが合格であること。
- 失敗件数が 0 であること。
- 各パターンの診断ステータスが定義された期待値と一致すること。
