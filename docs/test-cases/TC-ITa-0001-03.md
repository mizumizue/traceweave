## Content

### Objective
`BalanceAnalyzer.diagnosePyramid` がグラフ・地層・充足度を入力として、診断ステータスと警告・提案配列を返すことを検証する。

### Preconditions
合成グラフと `analyzeStrata` の結果が利用可能であること。

### Steps
1. `diagnosePyramid` を実行する。
2. 返却オブジェクトの `status`・`warnings`・`suggestions` を検査する。

### Expected Results
- 診断結果に有効な `status` が含まれること。
- `warnings` と `suggestions` が配列として返ること。
