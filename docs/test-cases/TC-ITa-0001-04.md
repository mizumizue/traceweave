## Content

### Objective
テストケース 0 件の要件、逆ピラミッド、中間空洞化の入力に対し、充足度 0%・未充足およびピラミッド警告が返ることを検証する。

### Preconditions
要件充足度算出とピラミッド静的診断が利用可能であること。

### Steps
1. TC を持たない要件をグラフに追加し、充足度を算出する。
2. 逆ピラミッドおよび中間空洞化の工程件数を入力し、診断ステータスと警告を検査する。

### Expected Results
- 未テスト要件はスコア 0%・未充足となること。
- 逆ピラミッドは逆転アイスクリーム型の警告付きステータスとなること。
- 中間空洞化は砂時計型の警告付きステータスとなること。
