## Content

### Role
プルリクエスト時やブランチプッシュ時に自動検証と静的アセット生成を行う自動化実行基盤。

### Responsibilities
- プルリクエスト時に `traceweave check` を実行し、リンク切れや重要要件のテスト欠落を検出して異常終了（exit code 1）する。
- main マージ時に `traceweave build` を実行し、静的ダッシュボード成果物をビルド・デプロイする。

### Interactions
- リポジトリの GitHub Actions 等のワークフローから CLI を非対話で実行する。
