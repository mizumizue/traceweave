## Content

### Role
IDE やチャット環境に組み込まれた自動化エージェント。人間の開発者に代わり、または補助として、トレーサビリティ解析・品質ギャップ確認・文書参照を機械可読な API で実行する。

### Responsibilities
- 起動済みの MCP サーバー経由で、トレーサビリティ要約・マトリクス・カタログ・品質ギャップ・V字モデル文書を取得する。
- 再利用可能プロンプトを用いて、レビュー・起票・ギャップ分析のたたき台を生成し、人間が最終判断する。
- 取得結果を根拠としてコードや文書の改定案を提示するが、マージや本番反映の決定権は人間アクターが持つ。

### Interactions
- MCP（stdio または HTTP トランスポート）でツール呼び出し・リソース読取・プロンプト取得を行う。
- 開発者（ACT-0001）がエディタ連携設定を整備した環境でのみ有効に動作する。
