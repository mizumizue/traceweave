## Content

### Objective
オプション起動の MCP サーバーが 4 ツールを契約どおり公開し、正常応答と要件未検出エラーが決定論的な JSON テキストで返ることを保証する。

### Quality Criteria
- ツール一覧が 4 件（get_traceability_summary, get_stratum_density, get_requirement_status, check_quality_gaps）であること。
- `get_traceability_summary` が summary フィールドを含む JSON を返すこと。
- 存在しない要件 ID に対し `get_requirement_status` が ERR_REQUIREMENT_NOT_FOUND を返すこと。
- `check_quality_gaps` が passed フィールドを含む gaps 情報を返すこと。

### Verification
- API 契約テスト（test_level: integration_external, test_method: api_contract）でハンドラを直接呼び出し、入出力スキーマを検証する。
- コア CLI/Web とは独立して MCP 単体で検証可能であること。

### Evidence
- テスト実行レポートに TC-0042 の passed ステータスが記録されること。

### Exit Criteria
- 上記 Quality Criteria を満たす TC-0042 が passed であること。
