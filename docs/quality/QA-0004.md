## Content

### Objective
CLI エントリーポイントが仕様どおりのサブコマンド・出力形式・終了コードを提供し、正常系と異常系の振る舞いが決定論的であることを保証する。

### Quality Criteria
- 正常な docs/ に対する `check` は終了コード 0 かつ PASS 表示を返すこと。
- 欠落リンクを含む docs/ に対する `check --strict` は終了コード 1 で失敗すること。
- `catalog --format json` は kindCounts と requirementClassCounts を含む有効な JSON を返すこと。
- 存在しない docs ディレクトリ指定時は終了コード 1 で異常終了すること。

### Verification
- 外部結合テスト（test_level: integration_external）で CLI を子プロセス実行し、stdout と exit code を検証する。
- 正常系・strict 失敗系・catalog JSON 出力を TC で網羅する。

### Evidence
- テスト実行レポート（reports/test-results.json）に TC-ITb-0003-01、TC-ITb-0003-02、TC-ITb-0027 の passed ステータスが記録されること。

### Exit Criteria
- 上記 Quality Criteria を満たす TC がすべて passed であること。
