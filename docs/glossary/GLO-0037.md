## Content

### Definition
コンポーネント間の相互作用を規定する境界。署名、メッセージ、イベント、画面操作などの形を取る。

### Context
TraceWeave の SPEC はモジュール境界のインターフェース契約を記述する層である。

### Synonyms
Interface、IF、境界

### Related Terms
契約（GLO-0038）がインターフェースの検証可能な記述。API（GLO-0036）はその一形態。
