## Content

### Definition
プロジェクト関係者が共通理解のもとで使うドメイン用語とその定義の集合。文書・会話・コードで一貫して用いる。

### Context
docs/glossary/ 配下の GLO 文書がプロジェクトのユビキタス言語の正本である。TraceWeave 固有の概念（トレーサビリティ、工程地層など）と、一般的なシステム開発用語（要件、CI/CD、単体テストなど）を同居させる。境界はフロントマターの glossary_scope（platform / general）と glossary_domain（テスト、プログラミング、データ・DB など）で機械的に分類し、決め事カタログ UI でフィルタする。新規用語は GLO-xxxx として追加する。

### Synonyms
Ubiquitous Language、共通語彙、ドメイン用語集
