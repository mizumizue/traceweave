## Content

### Definition
要求から設計・テストに至る成果物間の追跡関係を双方向に辿れる状態。変更の影響範囲特定と検証漏れの防止を目的とする。

### Context
TraceWeave では NEED / REQ / SPEC / DSN / TC などの決め事文書間の依存・検証関係をグラフとマトリクスとして可視化する中核概念である。

### Synonyms
追跡性、トレース可能性、Traceability

### Related Terms
V字モデル（GLO-0004）上の縦糸として整理される。充足度スコア（GLO-0005）はトレーサビリティに加え工程地層の検証密度を評価する。
