## Content

### Definition
作業項目をカードとして列（待機・進行中・完了など）に配置し、WIP 制限で流れを制御して継続的に届けるアジャイル手法。

### Context
カンバン上の項目は REQ や TC ID とリンクして、列の滞留がテスト・レビュー待ちのボトルネックを示す。

### Synonyms
Kanban、かんばん方式

### Related Terms
アジャイル（GLO-0021）の代表的なフロー管理。スクラム（GLO-0022）と併用も可能。
