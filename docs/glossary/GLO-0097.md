## Content

### Definition
イベント発生時に、登録済み HTTP エンドポイントへコールバックを送るプッシュ型の連携方式。

### Context
署名検証と再送は SPEC の契約とセキュリティ要件に含める。

### Synonyms
Webhook、HTTP コールバック

### Related Terms
API（GLO-0036）の一形態。再送時は冪等性（GLO-0063）が必要。
