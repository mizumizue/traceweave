## Content

### Definition
利用者価値を短い一文で表し、受入基準とともにイテレーション計画の単位とする要求の記述形式。

### Context
TraceWeave では NEED/REQ へ分解し、UC や TC へトレースする。

### Synonyms
User Story、ストーリー

### Related Terms
