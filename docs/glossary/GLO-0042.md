## Content

### Definition
プレゼンテーション、ユースケース、ドメイン、インフラなどの層に責務を分け、依存方向を一方向に制限する構造パターン。

### Context
TraceWeave 本体も application / core / infrastructure などの層で責務を分離している。

### Synonyms
Layered Architecture、N 層アーキテクチャ

### Related Terms
高凝集・疎結合（GLO-0076）を層単位で実現する。アーキテクチャ（GLO-0039）の具体パターン。
