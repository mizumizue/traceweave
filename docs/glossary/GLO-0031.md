## Content

### Definition
ユーザーの操作経路を UI や公開 API から再現し、複数サブシステムを跨いながら業務シナリオ全体を検証するテスト。

### Context
TraceWeave は E2E 偏重をテストピラミッド（GLO-0003）の不健全パターンとして警告する。

### Synonyms
End-to-End Test、エンドツーエンドテスト

### Related Terms
システムテスト（GLO-0028）と重なるが、ユーザー経路の再現に焦点を置く。
