## Content

### Definition
実行時に機能のオン・オフや対象ユーザー割当を切り替え、デプロイと機能公開を分離する制御機構。

### Context
フラグの状態と要件の対応は SPEC または設定契約に記述する。

### Synonyms
Feature Flag、機能トグル

### Related Terms
継続的デプロイ（GLO-0058）とリスク低減を両立させる。
