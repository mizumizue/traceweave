## Content

### Definition
負荷・ストレス・耐久など、想定トラフィック下での応答時間、スループット、リソース使用率を測定する試験。

### Context
TraceWeave の test_method=performance_load に相当する TC で記述する。

### Synonyms
Performance Test、負荷試験、ストレステスト

### Related Terms
非機能要件（GLO-0010）とスケーラビリティ（GLO-0048）の検証手段。
