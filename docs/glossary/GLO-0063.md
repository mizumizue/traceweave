## Content

### Definition
同一の操作を複数回実行しても、追加の副作用なく結果が最初の成功実行と同等に収束する性質。

### Context
リトライやメッセージ再送が起きる API は SPEC の契約で冪等性を明示する。

### Synonyms
Idempotency、イデンポテンス

### Related Terms
契約（GLO-0038）と分散システムの信頼性設計の基本要件。
