## Content

### Definition
複数サービスを跨ぐリクエストに共通 ID を付与し、呼び出しチェーンとレイテンシを一端末で追跡する手法。

### Context
マイクロサービス（GLO-0040）ではトレースが性能・障害分析の必須手段となる。

### Synonyms
Distributed Tracing、トレーシング

### Related Terms
