## Content

### Definition
一定時間あたりのリクエスト数を制限し、過負荷・悪用・コスト暴走を防ぐ制御。

### Context
公開 API の SPEC に制限値とエラー応答（例: 429）を契約として含める。

### Synonyms
Rate Limiting、スロットリング、流量制御

### Related Terms
API（GLO-0036）の運用要件。セキュリティ要件（GLO-0061）の可用性保護。
