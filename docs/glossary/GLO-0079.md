## Content

### Definition
サーバー、ネットワーク、権限などのインフラ構成をコードで宣言し、レビューと CI で変更を管理する手法。

### Context
環境差分はコード差分としてトレースし、本番変更も PR レビューの対象とする。

### Synonyms
IaC、Infrastructure as Code

### Related Terms
DevOps（GLO-0023）と CI（GLO-0024）の拡張。
