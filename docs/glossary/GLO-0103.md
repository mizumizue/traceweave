## Content

### Definition
計算や I/O の結果を一時保存し、同一要求への応答を高速化する層。整合性と失効戦略が設計の要点となる。

### Context
キャッシュの振る舞いは SPEC の契約（ヒット・ミス・失効）としてテスト可能に書く。

### Synonyms
Cache、インメモリキャッシュ、CDN キャッシュ

### Related Terms
スケーラビリティ（GLO-0048）向上の手段。整合性トレードオフに注意する。
