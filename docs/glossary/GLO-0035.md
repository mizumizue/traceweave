## Content

### Definition
テスト実行結果が正しいか否かを判定する基準。期待値、仕様上の契約、受入基準などから導かれる。

### Context
TraceWeave の TC Expected Results は、REQ/SPEC から辿れるオラクルである必要がある。

### Synonyms
Test Oracle、期待結果の根拠

### Related Terms
受入基準（GLO-0019）と仕様（GLO-0016）がオラクルの正本となる。
