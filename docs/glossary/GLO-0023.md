## Content

### Definition
開発（Development）と運用（Operations）の協働と自動化により、変更のリードタイム短縮と安定運用を両立させる文化・手法・ツールチェーンの総称。

### Context
CI/CD パイプラインの品質ゲートに TraceWeave の lint/check を組み込む運用が典型例である。

### Synonyms
DevOps 文化、DevSecOps（セキュリティ統合）

### Related Terms
継続的インテグレーション（GLO-0024）と継続的デリバリー（GLO-0025）が DevOps の技術基盤となる。
