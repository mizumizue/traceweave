## Content

### Definition
下層に単体・契約テストを厚く、上層の E2E を薄く保つことを推奨するテスト構成の理想形。

### Context
TraceWeave は E2E 偏重（アイスクリームコーン）や中間結合欠落（ひょうたん型）などの不健全パターンを警告する。

### Synonyms
Test Pyramid、テストピラミッドモデル
