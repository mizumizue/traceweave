## Content

### Definition
入力ドメインの境界とその直近の値にテストを集中させ、オフバイワンや範囲判定の欠陥を検出する技法。

### Context
TC の Steps に境界値を明示し、SPEC の Constraints と対応させる。

### Synonyms
Boundary Value Analysis、BVA

### Related Terms
同値分割と併用される。テストオラクル（GLO-0035）は境界での期待値を固定する。
