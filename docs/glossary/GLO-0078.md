## Content

### Definition
HTTP のメソッドとステータスコード、リソース指向の URI を用いてリモート操作を表現するアーキテクチャスタイル。

### Context
OpenAPI 等で SPEC に契約化し、契約テストで検証する。

### Synonyms
RESTful API、Representational State Transfer

### Related Terms
API（GLO-0036）の代表的スタイル。バージョニング（GLO-0065）が URL またはヘッダで行われる。
