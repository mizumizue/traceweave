## Content

### Definition
システムの外部境界またはモジュール間における入出力・振る舞い・エラー条件を、検証可能な粒度で固定した文書化された契約。

### Context
TraceWeave では kind=specification の SPEC 文書が仕様を表し、REQ からの depends_on でトレーサビリティを張る。

### Synonyms
Specification、仕様書、外部仕様

### Related Terms
要件（GLO-0015）の精緻化成果。契約（GLO-0038）として実装・テストのオラクルになる。
