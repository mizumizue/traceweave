## Content

### Definition
開発者の変更を頻繁に共有リポジトリへ統合し、自動ビルド・自動テストで統合欠陥を早期に検出する実践。

### Context
TraceWeave プロジェクトでは npm run lint / test および traceweave check を CI 上で実行するのが標準的である。

### Synonyms
CI、Continuous Integration

### Related Terms
DevOps（GLO-0023）の中核。回帰テスト（GLO-0030）を毎コミットで走らせる。
