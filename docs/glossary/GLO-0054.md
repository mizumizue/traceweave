## Content

### Definition
変更がマージされる前に、他の開発者が正しさ・可読性・セキュリティ・設計整合を検査する品質ゲート。

### Context
レビューでは関連 REQ/SPEC/ADR へのリンクが変更と一致しているかも確認する。

### Synonyms
Code Review、ピアレビュー、PR レビュー

### Related Terms
トレーサビリティ（GLO-0001）の人的検証層。
