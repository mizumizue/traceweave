## Content

### Definition
機密性・完全性・可用性、認証・認可、監査、コンプライアンスなど、攻撃や誤用からシステムを守るための要件。

### Context
非機能要件（GLO-0010）のサブセットとして扱い、専用のテスト手法で検証する。

### Synonyms
Security Requirement、セキュリティ非機能要件

### Related Terms
脆弱性（GLO-0062）管理とペアで運用する。
