## Content

### Definition
ステークホルダーがシステムに期待する振る舞い・制約・品質を、実装に依存しない形で記述した合意事項。

### Context
TraceWeave では kind=requirement の REQ 文書が要件の正本となり、機能要件・非機能要件の区分と重要度属性を持つ。

### Synonyms
Requirement、要求仕様、システム要件

### Related Terms
機能要件（GLO-0009）と非機能要件（GLO-0010）は要件の下位区分。V字モデル（GLO-0004）の REQ 層に位置する。
