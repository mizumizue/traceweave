## Content

### Definition
受入基準を実行可能な仕様（例: Gherkin）として記述し、ステークホルダーと開発者の共有言語で振る舞いを先に固定する開発手法。

### Context
TraceWeave の AC 形式（Given-When-Then）と相性が良く、TC の Expected へ自然に接続できる。

### Synonyms
BDD、Behavior-Driven Development

### Related Terms
受入基準（GLO-0019）が中心。テスト駆動開発（GLO-0053）と補完関係。
