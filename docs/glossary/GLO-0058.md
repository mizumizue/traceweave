## Content

### Definition
main 等のトランクへマージされた変更を、人手承認なしに自動で本番へデプロイするまでの自動化パイプライン。

### Context
強いテスト・監視・ロールバックが前提となる。文書ゲートを CI に組み込むこともある。

### Synonyms
Continuous Deployment

### Related Terms
継続的デリバリー（GLO-0025）より一段進んだ自動化。デプロイ（GLO-0057）を連続化する。
