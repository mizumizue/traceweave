## Content

### Definition
新しいバージョンの提供者が、既存の利用者を変更なし、または許容範囲の変更のみで引き続きサポートできる性質。

### Context
破壊的変更は ADR と SPEC のバージョン方針に記録し、移行 TC を用意する。

### Synonyms
Backward Compatibility、下位互換

### Related Terms
バージョニング（GLO-0065）と契約（GLO-0038）で管理する。
