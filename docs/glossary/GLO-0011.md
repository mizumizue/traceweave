## Content

### Definition
リポジトリ内の決め事文書を種別横断で一覧・検索・相互参照できる Web / CLI ビュー。

### Context
ダッシュボードの「決め事カタログ」タブおよび traceweave catalog コマンドがこれに相当する。用語（GLO）も同カタログ内で種別フィルタにより閲覧できる。

### Synonyms
Decisions Catalog、Decisions Browser、アーキテクチャカタログ

### Related Terms
決め事（GLO-0006）の探索 UI。用語集は kind=glossary フィルタまたは「用語集」ボタンで絞り込む。
