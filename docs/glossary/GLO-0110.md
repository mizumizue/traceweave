## Content

### Definition
プログラムを実行せずにソースや文書を解析し、規約違反・型不整合・セキュリティパターンを検出する手法。

### Context
TraceWeave の validate-docs や lint は決め事文書の静的解析に相当する。

### Synonyms
Static Analysis、SAST（セキュリティ文脈）
