## Content

### Definition
ソフトウェアコンポーネントが外部または他コンポーネントに提供する操作・データアクセスの公開面。プロトコルとデータ形式を伴う。

### Context
TraceWeave では CLI や MCP ツールも API として SPEC に契約化する。

### Synonyms
Application Programming Interface、公開インターフェース

### Related Terms
インターフェース（GLO-0037）の運用面。契約（GLO-0038）でバージョンと互換性を固定する。
