## Content

### Definition
要求定義から設計・実装・テストへ左側が詳細化し、右側で検証が対応する開発ライフサイクルモデル。

### Context
TraceWeave の文書種別（NEED / REQ / SPEC / DSN / QA / TC）と依存方向は V字モデルに沿って整理される。

### Synonyms
V-Model、ブイ字モデル

### Related Terms
トレーサビリティ（GLO-0001）は V字モデル上の縦の追跡関係を指す。決め事（GLO-0006）は同モデル上の成果物総称である。
