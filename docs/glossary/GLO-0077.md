## Content

### Definition
状態変化をイベントとして公開し、購読者が非同期に反応する。コンポーネント間の時間的・空間的な疎結合を高めるスタイル。

### Context
イベントスキーマは SPEC の契約として版管理する。

### Synonyms
Event-Driven Architecture、EDA

### Related Terms
マイクロサービス（GLO-0040）と併用されやすい。冪等性（GLO-0063）が消費側の要件となる。
