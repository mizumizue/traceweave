## Content

### Decision
`Header.tsx` におけるブランドロゴ（アイコン `🕸️` および `TraceWeave` タイトル）を、単なる静的見出しや `<button>` 要素ではなく、セマンティックかつアクセシブルなルートリンクアンカー `<a href="...">` として設計する。
利用者のクリック操作コンテキストに応じた二重動作（修飾キーによるブラウザ標準挙動 vs 通常クリックによる SPA 状態リセット）を判定する純粋関数 `shouldUseInternalNavigation` をシーム（Seam）として分離し、UI ロジックを完全に単体テスト可能とする。さらに、レスポンシブ表示時にタイトルとバージョンバッジが重なる問題を解消するため、ロゴ領域に縮小抑止（`shrink-0`）と独立行折り返しレイアウトを適用する。

### Structure
1. **純粋契約ヘルパー**:
   - `shouldUseInternalNavigation(event)`: 修飾キー（`metaKey`, `ctrlKey`, `shiftKey`, `altKey`）および主ボタン（`button === 0`）を検査し、SPA 内ルーティングを行うべきか標準リンク動作に委譲すべきかを二値判定。
   - `getHeaderLinkContract(pathname)`: サブディレクトリ配信を考慮した `href` パス、アクセシビリティ用の `ariaLabel`、`title` を提供。
2. **コンポーネント構造**:
   - `src/web/src/components/Header.tsx`:
     - アンカータグ `<a href={contract.href} onClick={handleClick} ...>`
     - ブランドロゴブロック: `shrink-0` を適用し、隣接するバージョンタグ（v0.1.0）との衝突を防止。
   - `src/web/src/App.tsx`:
     - `handleNavigateHome`: `activeTab: 'matrix'`, `selectedNodeId: null`, 検索クエリ消去、フィルターリセットを一括適用し、`syncBrowserHistory(getHomeUrlState())` を実行。

### Data Flow
1. ユーザーがヘッダーのロゴ領域をクリック。
2. `handleClick` イベントハンドラーが `shouldUseInternalNavigation(e)` を呼び出し。
3. **修飾キーあり（Ctrl/Cmd/Shift等押下時）**:
   - `preventDefault()` を呼び出さずそのまま終了。
   - ブラウザが標準リンク動作として新しいタブやウィンドウでベースパスを開く。
4. **通常クリック時**:
   - `e.preventDefault()` を実行し、ブラウザの完全リロードを抑止。
   - `onNavigateHome()` コールバックが発火。
   - `App.tsx` が全タブ・フィルター・モーダル状態をデフォルト値へリセットし、ブラウザ履歴にルート URL を `pushState`。

### Trade-offs
- **`<button>` タグ vs `<a>` アンカータグ**:
  - `<button>` を用いた場合、ユーザーが「右クリックして新しいタブで開く」や「Cmd+クリックで別タブで開く」といった Web 標準のブラウジング体験が損なわれる。
  - `<a>` タグを採用し、通常クリック時のみイベントを横取り（intercept）して SPA リセットを行う設計にすることで、アクセシビリティ・標準操作性と SPA の軽快さを両立できる。
- **ハードリロード（`window.location.href = '/'`）vs SPA 状態リセット**:
  - 完全リロードは全リソースの再取得・再パースが発生し数秒の遅延が生じる。メモリ上の React State リセットであればミリ秒で初期画面へ復帰できるため、SPA 状態リセットを採用。
