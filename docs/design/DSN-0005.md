## Content

### Decision
1. **外部パラメータファイル形式**:
   - `fixtures/test-cases/<TC-ID>.json` に配置。
   - `DocParser` が `parameter_file` メタデータを検知した際、JSON を読み込み `node.parameters` にインメモリ保持して API や静的ビルド JSON に含める。
2. **実行エンジンの二重化（Isomorphic Test Runner）**:
   - サーバーサイド: CLI `serve` コマンド内に `TestRunner` レジストリを配置し、`POST /api/test/run` を通じて Node.js ランタイム上で実行。
   - クライアントサイド: 静的ビルド時やサーバー未接続時でも動作するよう、純粋関数ロジック（スコア計算、ピラミッド診断等）をフロントエンド側でも同一エンジンで実行可能とするアイソモーフィック構成。
3. **スクリプトによるテスト入力変更可否の静的解析と自動分類**:
   - UI上の入力値が変更できるか否かは AI の力業による推論・手動属性付与ではなく、決定論的スクリプト `TestCaseInputAnalyzer` で解析する。
   - テスト手法（`e2e`, `scenario`, `manual` 等）や工程（`system`, `acceptance`）、パラメータ定義ファイルの有無、純粋ハンドラ登録状況から機械的に分類・理由導出を行う。
   - いつでも CLI（`traceweave test-inputs`）および Web ダッシュボード上で分類結果・除外理由を表示できる。
4. **単純入出力テストへのUI実行限定と複雑テストの除外方針（無理に要件を満たさない）**:
   - UI上から実行可能なテストは、副作用がなく決定論的な純粋関数ロジック（充足度計算、ピラミッド診断等）に限定する。
   - ファイルI/O、SQLite、CLIサブプロセス、静的ビルド、ブラウザレンダリングを要するテストは、無理なモックや偽のUIエミュレーションを行わず、「UI実行対象外」として除外する。

### Structure
1. `src/core/analyzer/TestCaseInputAnalyzer.ts`:
   - テストケースの入力値変更可否を決定論的に解析・分類・サマリー化・テキスト整形。
2. `src/core/testing/TestRunnerRegistry.ts`:
   - 実行可能なテストハンドラ（例: `TC-0002` スコア計算、`TC-0003` ピラミッド診断、`TC-0010` 汎用計算）の登録・ディスパッチ。
3. `src/core/models/types.ts`:
   - `TestCasePattern`, `TestRunRequest`, `TestRunResult`, `TestCaseInputAnalysis`
4. `src/cli/index.ts`:
   - `/api/test/run` ルーティング追加、および `test-inputs` コマンド追加。
5. `src/web/src/components/InteractiveRunner.tsx`:
   - スクリプト解析結果に基づく状態表示、入力編集、プリセット選択、手動実行、リアルタイム結果表示。

### Data Flow
1. ユーザーがモーダルを開く → `node.parameters` から事前定義パターン一覧を表示。
2. ユーザーがパターンを選択または入力 JSON を編集 → ステート `currentInputs` 更新。
3. 「テストを実行」クリック → `POST /api/test/run`（またはクライアントランナー）へリクエスト送信。
4. 実行エンジンがターゲット関数を実行、`actual` を取得し `expected` と比較。所要時間を計測。
5. レスポンスを受け取り、モーダル上の「実測値」「合否」「実行ログ」を即座に更新。

### Trade-offs
- メリット: ドキュメントを見るだけでなく、その場で「もしこの入力ならどうなるか？」の境界値検証がブラウザ上で完結する。
- デメリット: 任意コード実行によるセキュリティリスクが生じうるため、実行可能なテスト関数はホワイトリスト化（事前登録されたハンドラのみ）し、安全性を担保する。
- 設計方針: 単純な入出力で完結しないテストを無理にUI実行させると、人工的なダミーモックが混入しテスト自体の信憑性を毀損する。UI実行対象外として除外することで、テストの誠実性とシステムのク潔性を維持できる。
