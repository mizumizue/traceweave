## Content

### Decision
`UseCaseSufficiencyScorer` を `SufficiencyScorer.calculateAll` の直後に実行し、結果を `MatrixBuilder.buildReport` が `TraceWeaveReport.useCases` に載せる。Web の決め事カタログ（ユースケースマップ）とノード詳細モーダルは同配列を参照してゲージ表示する。

### Structure
- `src/core/sufficiency/UseCaseSufficiencyScorer.ts` — `requirement_refs` のロールアップ
- `src/core/matrix/MatrixBuilder.ts` — レポートへのマージとサマリー集計
- `src/web/src/components/DecisionsBrowser.tsx` / `NodeDetailModal.tsx` — 表示

### Data Flow
1. `TraceGraph` 構築
2. `RequirementSufficiency[]` 算出
3. `UseCaseSufficiency[]` 算出（UC ごとに参照 REQ のスコア平均、未知参照は 0 点）
4. レポート JSON 出力 → ダッシュボード API

### Trade-offs
- UC 単位の工程別ピラミッドは行わず、REQ 側の既存指標を再利用する（二重管理を避ける）。
- `links` による UC↔TC 関連は本集計では使わない。
