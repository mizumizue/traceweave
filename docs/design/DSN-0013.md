## Content

### Decision
Web ダッシュボードにおける品質充足率・テストカバー率の可視化コンポーネントとして、外部チャートライブラリ（Chart.js, Recharts, D3 等）を追加せず、純粋な SVG ベクター描画による `CircularGauge` を独自設計する。
円周オフセットの幾何学計算（`calculateGaugeGeometry`）および品質ステータス色分け（`getScoreColor`）を純粋関数として分離し、トレーサビリティマトリクスなどの大量行（数百件）に同時レンダリングされた場合でも、再描画負荷を生じさせずミリ秒未満で表示可能な超軽量設計とする。

### Structure
1. **純粋計算モジュール**:
   - `src/web/src/components/CircularGauge.tsx`:
     - `calculateGaugeGeometry(value, size, strokeWidth, color?, trackColor?)`:
       - クランプ処理: $0 \le \text{percentage} \le 100$
       - 半径: $r = (\text{size} - \text{strokeWidth}) / 2$
       - 円周長: $C = 2 \pi r$
       - 弧長オフセット: $\text{offset} = C \times (1 - \text{percentage} / 100)$
     - `getScoreColor(score)`:
       - 80%以上: Teal（翠色: `#2dd4bf`）
       - 50%〜79%: Amber（琥珀色: `#fbbf24`）
       - 50%未満: Rose（紅緋色: `#fb7185`）
2. **SVG コンポーネント構造**:
   - `<svg viewBox="0 0 {size} {size}">`:
     - 背景円トラック: `<circle stroke={trackColor} ... />`
     - 進捗円弧ゲージ: `<circle stroke={strokeColor} strokeDasharray={C} strokeDashoffset={offset} transform="rotate(-90 {center} {center})" ... />`
     - 中央パーセント表示: `<text x="50%" y="50%" ...>`

### Data Flow
1. 親コンポーネント（`MatrixView`, `QualityMetricsGrid`, `VisualTestPyramid` 等）から `value`（充足度スコア 0〜100）および任意の `size`, `strokeWidth` が渡される。
2. `calculateGaugeGeometry` が即座に入力値を評価し、描画に必要な幾何パラメータと閾値色オブジェクトを算出。
3. 12時位置を起点（$-90^\circ$ 回転）とする時計回りの円弧として SVG が軽量にレンダリングされる。
4. 値の変更時には CSS トランジション（`transition-all duration-500 ease-out`）により滑らかなゲージ伸縮アニメーションが適用される。

### Trade-offs
- **外部チャートライブラリ不採用の根拠**:
  - Recharts や Chart.js を導入すると、数十〜数百 KB のバンドル肥大化を招き、Vite の高速ビルド特性を損なう。
  - 本システムの円形ゲージは単一指標のドーナツチャートであり、標準 SVG の `<circle strokeDashoffset>` のみで完全に充足するため、ゼロ依存のインライン SVG が最も軽量で安全。
- **Canvas vs SVG**:
  - Canvas 描画は高 DPI 画面（Retina 等）でのぼやけ対策や CSS スタイリング連携が煩雑になる。SVG であれば拡大・縮小に対して常に鮮明なベクター品質を維持でき、レスポンシブなサイズ調整が容易。
