## Content

### Decision
`NodeDetailModal` において、ノード間の依存関係（`depends_on`, `verifies`, `links`）を連続して探索するユーザー体験を向上させるため、ブラウザ履歴とは独立したモーダル内メモリ履歴スタック（`historyStack: string[]`, `historyIndex: number`）を導入する。
探索中の「戻る」「進む」状態遷移、キーボードショートカット（`Escape` キー）、外側クリック判定、およびノード情報（ID、ファイルパス、Markdown 全文）のクリップボード抽出ロジックを純粋関数モジュール `modalNavigation.ts` としてコンポーネントから分離し、100% 決定論的なテスト可能性を確保する。

### Structure
1. **純粋ナビゲーションヘルパー**: `src/web/src/components/modalNavigation.ts`
   - `appendModalHistory(history, currentIndex, nextId)`: 現在インデックス以降の「進む」履歴を切り捨て、新しいノード ID をスタック末尾に追加。同一ノードの場合は二重追加を抑止。
   - `moveModalHistory(history, currentIndex, direction)`: `direction === 'back'` または `'forward'` に応じて境界値（$0 \le \text{nextIndex} < \text{history.length}$）を保護しながらインデックスを移動。
   - `isModalEscapeKey(key)`: `key === 'Escape'` の判定。
   - `isModalOverlayClick(target, currentTarget)`: モーダル背景オーバーレイとモーダル内部ダイアログのクリック境界判定。
   - `getNodeCopyText(node, format)`: `'id'`（ノードID）、`'path'`（ファイルパス）、`'markdown'`（フロントマター付き完全Markdown本文）の抽出シリアライザ。
2. **モーダルコンポーネント**: `src/web/src/components/NodeDetailModal.tsx`
   - ヘッダーツールバー: 戻るボタン（`<`）、進むボタン（`>`）、履歴件数表示、コピーボタングループ、クローズボタン。
   - ボディ領域: ノード種別に応じたメタデータ、受入条件/仕様契約カード、テスト実測対比ビュー、Markdown 本文ビューア。

### Data Flow
1. **リンク遷移**: モーダル内で関連ノード（例: `SPEC-0002`）がクリックされると、`appendModalHistory` によりスタックが更新され、新ノードが表示される。
2. **履歴移動**: 「戻る」ボタン押下により `moveModalHistory(..., 'back')` が実行され、1つ前の閲覧ノードが瞬時に再表示される。
3. **クリップボードコピー**: ユーザーが「Markdown コピー」をクリックすると、`getNodeCopyText` でフォーマットされた文字列が `navigator.clipboard.writeText` で書き込まれ、`toast.success` が発行される。
4. **安全なクローズ**: `Escape` キー押下または背景オーバーレイのクリックを検知すると、履歴スタックがメモリ上で破棄され、モーダルが閉じられる。

### Trade-offs
- **ブラウザ History API 統合 vs モーダル内ローカルスタック**:
  - モーダル内でのドリルダウン（例: REQ → SPEC → TC → DSN と5回連続ジャンプ）のたびにブラウザ URL の `pushState` を発行すると、ブラウザの「戻る」ボタンを押した際にモーダル内の1ステップ戻る動作となり、ユーザーが画面全体を前のページに戻したいときにブラウザバックが壊れる感覚を与える。
  - 最適な UX として、モーダル自体の開閉（`?node=REQ-0001`）のみをブラウザ URL と同期させ、モーダル内部の連続ドリルダウンはモーダル内の独立したメモリスタックで制御するハイブリッド構造を採用した。
