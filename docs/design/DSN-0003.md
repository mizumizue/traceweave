## Content

### Decision
Web ダッシュボードの基盤として Next.js ではなく Vite + React + Tailwind CSS を採用し、ビルド時間 1〜3 秒の爆速静的エクスポートを実現する。生成される成果物は静的アセット（HTML/JS/CSS）として CLI パッケージに内包または配布可能とする。また、ローカル開発サーバー起動時（serve）に指定ポートが既に専有されている場合、プラットフォームに応じたプロセス終了（Windows: netstat/taskkill, POSIX: lsof/kill）を実行し、ポート解放待機後にクリーンに再起動するプロセス管理機構を設ける。

### Structure
- `src/web/`: React SPA プロジェクトルート
- `src/web/src/components/`:
  - `Header`: プロジェクト全体の品質ステータス表示
  - `MatrixView`: 階層ツリーとテストケースマトリクス
  - `StratumView`: 単体〜受入の地層ヒートマップとピラミッドチャート
  - `GapRiskView`: テスト不足・工程欠落リスク一覧
  - `TestCaseModal`: テストケース詳細ポップアップ
- データ連携: ビルド時に `window.__TRACEWEAVE_DATA__` またはローカルプレビュー時の `fetch('/api/data')` の双方に対応するハイブリッドローダーを採用。

### Data Flow
1. 静的ビルド時: CLI が `traceweave build` を実行すると、Core で解析したデータ JSON を HTML 内にインライン注入し、完全自己完結する単一ディレクトリを出力。
2. ローカル開発時: `traceweave serve` が Vite ビルド済みアセットを配信し、`/api/data` エンドポイント経由で常に最新のリポジトリ状態を反映。

### Trade-offs
- メリット: Next.js のような巨大なビルドプロセスや Node ランタイム依存が一切なく、GitHub Pages や社内サーバーに置くだけで誰でも閲覧できる。ビルド時間も極小。
- デメリット: サーバーサイドレンダリング（SSR）は行わないが、ダッシュボードは社内・チーム内でのデータ閲覧ツールであるため、SPA 静的エクスポートで機能的・性能的に完全に充足する。
