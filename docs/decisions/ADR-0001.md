## Content

### Context
TraceWeave の Web ダッシュボードの技術選定において、Next.js（App Router）と Vite + React が比較対象となった。Next.js はフルスタック Web 開発のデファクトスタンダードであるが、ビルド時間（10〜30秒以上）が長く、CI パイプラインでのオーバーヘッドが大きいこと、および静的配布において `.next/` の構造が複雑になるという課題があった。

### Decision
Web ダッシュボードの構築には Vite + React + Tailwind CSS を採用する。静的アセット生成（`vite build`）を 1〜3 秒で完了させ、完全な単一静的ディレクトリとしてエクスポートする。

### Consequences
- CI 上でのダッシュボード生成が数秒で完了し、開発者体験と CI 実行コストが大幅に改善される。
- 生成された静的成果物は、GitHub Pages、AWS S3、あるいはローカルのブラウザ直接表示で容易に共有可能となる。
- SSR（サーバーサイドレンダリング）は利用しないが、分析ダッシュボードのユースケースとしては不要であり、デメリットはない。
