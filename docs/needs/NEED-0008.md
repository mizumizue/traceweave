## Content

### Background
TraceWeave の Web ダッシュボードは、マトリクス（Matrix）、トレーサビリティグラフ（Graph）、地層・ピラミッド診断（Stratum）、決め事カタログ（Decisions）、ギャップ分析（Gaps）といった多彩なタブ画面を提供し、各画面において詳細インスペクションモーダルや豊富な絞り込みフィルタ（検索クエリ、テスト工程、重要度、充足度スコア、カタログ種別、タグ、グラフハイライト等）を備えた Single Page Application (SPA) として構成されている。

### Problem
1. **ブラウザバック / 進むナビゲーションの不能**:
   SPA 内でタブを切り替えたり、ドキュメントのノード詳細インスペクションモーダルを開いて階層を辿った後、ブラウザの「戻る」ボタン（またはマウスの戻るボタン、ショートカットキー）を押すと、SPA 内の直前画面やモーダル前の状態に戻るのではなく、Web ダッシュボード自体から離脱（ブラウザの外部履歴へ遷移）してしまう。
2. **URL による状態の不透明性と再現性の喪失**:
   現在どのタブを開いているのか、どのノードの詳細をインスペクトしているのか、どのようなフィルタ条件（検索クエリやフェーズ、重要度など）で絞り込んでいるのかがブラウザの URL（クエリパラメータ）に一切反映されない。そのため、特定の不充足要件やグラフ上の影響パスを調査した画面を同僚に URL 共有したり、ブラウザのブックマークに保存したり、ページをリロード（F5）した際に、元の作業状態・現在地へ復帰することができない。

### Desired Outcome
SPA であっても HTML5 History API（`pushState`, `replaceState`, `popstate` イベント）を適切に活用してブラウザの履歴スタックを制御し、ブラウザバックや進む操作によって直前の画面・モーダル状態・タブ・フィルタへ自然に戻れるようにする。また、アクティブタブ、選択ノードID、検索キーワード、および各フィルタ条件を URL クエリパラメータと双方向同期させ、URL を見るだけで現在地と絞り込み条件が明確に分かり、URL の直接アクセス・リロード・共有によって同一の状態が完全に復元される表現力豊かな URL 管理を実現する。
