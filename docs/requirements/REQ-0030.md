## Content

### Statement
利用者は、TraceWeave がホストアプリケーション向けに提供する品質保証情報について、対象アプリケーションの表示名を Web ダッシュボード、レポート出力、およびローカルプレビュー起動時の案内から一貫して識別できなければならない。表示名は利用者が明示設定で上書きでき、未設定時はリポジトリから決定論的に解決される。

### Acceptance Criteria
- AC-001: Given 有効な文書セットを読み込んだ Web ダッシュボード When 画面を表示したとき Then ヘッダー領域に対象アプリケーションの表示名が含まれ、空欄にならないこと。
- AC-002: Given 有効な文書セット When ブラウザでダッシュボードを表示したとき Then ブラウザタイトルに対象アプリケーションの表示名が含まれること。
- AC-003: Given 利用者が表示名を明示設定したとき When レポートを生成したとき Then 設定値が自動解決より優先され、出力に反映されること。
- AC-004: Given 有効な文書セット When マークダウン形式の品質レポートを出力したとき Then 出力先頭に対象アプリケーションの表示名が含まれること。
- AC-005: Given ローカルプレビューを起動したとき When 起動完了メッセージが表示されたとき Then 対象アプリケーションの表示名が案内文に含まれること。
- AC-006: Given 表示名の解決に失敗したとき When いずれの主要表面を表示したとき Then フォールバック表示名が用いられ、表示が欠落しないこと。
