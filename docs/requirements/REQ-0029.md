## Content

### Statement
Cursor 等の AI エージェントが Model Context Protocol（MCP）経由で TraceWeave のトレーサビリティ要約、工程地層密度、要件ステータス、品質ギャップ、マトリクス、カタログ、意思決定一覧、V字モデル文書リソース、および再利用可能プロンプトを取得できなければならない。MCP はコア CLI/Web とは独立したオプショナル拡張として提供し、未使用環境でもコア機能が動作すること。

### Acceptance Criteria
- AC-001: Given MCP サーバーを起動したとき When エージェントがツール一覧を要求したとき Then トレーサビリティ要約・地層密度・要件ステータス・品質ギャップ・マトリクス・カタログ・意思決定の 7 種類のツールが公開されること。
- AC-002: Given 有効な docs ディレクトリ When トレーサビリティ要約ツールを呼び出したとき Then 全体サマリ JSON が返却されること。
- AC-003: Given 存在しない要件 ID When 要件ステータスツールを呼び出したとき Then 構造化エラー内容が返却され、正常データと区別できること。
- AC-004: Given strict フラグ When 品質ギャップ確認ツールを呼び出したとき Then 文書検証結果とギャップ一覧が JSON で返却されること。
- AC-005: Given 有効な docs ディレクトリ When リソース一覧を要求したとき Then `traceweave-doc://` スキームの Markdown 文書が列挙され、読取で本文が取得できること。
- AC-006: Given MCP サーバーを起動したとき When プロンプト一覧を要求したとき Then トレーサビリティレビュー・品質ギャップ分析・V字モデル起票の 3 プロンプトが公開されること。
- AC-007: Given 外部プロジェクトへの overlay 適用を実行したとき When 対象プロジェクトにエージェント連携設定ファイルが未存在であるとき Then 連携設定の登録例が生成されること。
