## Content

### Statement
Cursor 等の AI エージェントが Model Context Protocol（MCP）経由で TraceWeave のトレーサビリティ要約、工程地層密度、要件ステータス、品質ギャップを取得できなければならない。MCP はコア CLI/Web とは独立したオプショナル拡張として提供し、未使用環境でもコア機能が動作すること。

### Acceptance Criteria
- AC-001: Given `traceweave mcp` を起動したとき When エージェントがツール一覧を要求したとき Then 4 つのツール（`get_traceability_summary`, `get_stratum_density`, `get_requirement_status`, `check_quality_gaps`）が公開されること。
- AC-002: Given 有効な docs ディレクトリ When `get_traceability_summary` を呼び出したとき Then 全体サマリ JSON が返却されること。
- AC-003: Given 存在しない要件 ID When `get_requirement_status` を呼び出したとき Then 構造化エラー内容が返却され、正常データと区別できること。
- AC-004: Given `strict` フラグ When `check_quality_gaps` を呼び出したとき Then 文書検証結果とギャップ一覧が JSON で返却されること。
