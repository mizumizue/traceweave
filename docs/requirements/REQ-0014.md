## Content

### Statement
Web ダッシュボードの工程地層・ピラミッド診断ビューにおいて、単体・内結・外結・総合・受入の5大工程のボリュームと要件カバー率を視覚的な立体層別ピラミッドとしてグラフィカルに表示し、各層のクリック操作によりマトリクスを対象工程へ即座に絞り込めるようにしなければならない。

### Acceptance Criteria
- AC-001: Given 工程地層・ピラミッド診断タブ When 閲覧したとき Then 単体・内結・外結・総合・受入の5大工程が階層的な幅を持つ立体ピラミッド形状としてグラフィカルに描画されること。
- AC-002: Given 各工程のピラミッド層 When 描画されるとき Then テストケース件数、全体構成比率、および要件カバー率（円形ゲージ）が各層に統合表示されること。
- AC-003: Given ピラミッドの任意の工程層 When ユーザーがクリックしたとき Then トレーサビリティマトリクス表が該当工程のテストケースを含む要件・仕様に即座にフィルタリングされること。
