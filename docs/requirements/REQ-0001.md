## Content

### Statement
システムは、リポジトリの `docs/` 配下の文書群を解析し、要求（NEED）から要件（REQ）、仕様（SPEC）、設計（DSN）、テストケース（TC）に至る双方向の有向グラフをインメモリに構築し、循環参照や孤立ノードを検出できなければならない。

### Acceptance Criteria
- AC-001: Given 有効な docs ディレクトリ When グラフを構築したとき Then 全文書がノードとして登録され、depends_on および verifies によるエッジが双方向（フォワード・バックワード）に探索可能であること。
- AC-002: Given 文書間に循環参照が存在する When グラフを検証したとき Then 循環を検知し、関与するノードIDの一覧をエラーとして報告すること。
- AC-003: Given 上流または下流のどこにも接続されていない孤立ノードが存在する When グラフを検証したとき Then 孤立警告として検知できること。
