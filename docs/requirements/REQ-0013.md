## Content

### Statement
Web ダッシュボードのノード詳細モーダルにおいて、依存関係リンクの探索履歴（進む・戻る）のスタックナビゲーション、キーボードショートカット（ESC による離脱）、外側クリックによる安全なクローズ、および文書情報（ID・パス・Markdown）のワンクリックコピーを提供しなければならない。

### Acceptance Criteria
- AC-001: Given ノード詳細モーダル When 依存関係リンクをクリックして別ノードへ遷移したとき Then 閲覧履歴スタックが記録され、戻る・進むボタンで履歴間を双方向に遷移できること。
- AC-002: Given ノード詳細モーダルが開いている状態 When ESC キーを押下するか、またはモーダル外側の背景をクリックしたとき Then モーダルが安全に閉じること。
- AC-003: Given ノード詳細モーダルのヘッダー When コピー操作を実行したとき Then 対象文書の ID、ファイルパス、または Markdown 本文がクリップボードにコピーされ、完了フィードバックが得られること。
