## Content

### Statement
システムは、各要件の重要度（High, Medium, Low）および紐づく仕様・テストケースの工程（内結・外結・ST・UAT）と手法に基づき、0%〜100% の契約トレーサビリティ充足度スコアを決定的に算出できなければならない。単体テスト（UT）は実装カバレッジ軸（REQ-0031）で測定し、本スコアには含めない。充足の判定に用いるのは実行に合格したテストケースのみであり、文書として存在するだけの未実行・失敗したテストケースはスコアと工程密度に加算してはならない。

### Acceptance Criteria
- AC-001: Given 重要度 High の要件 When 内部結合・外部結合または総合・受入の各工程に実行合格したテストが揃っている Then 契約充足度スコアが 100% と判定されること。
- AC-002: Given 重要度 High の要件 When 実行合格したトレーサビリティテストが存在しない、または単体テストのみが実行合格している Then 契約充足度スコアが 0% と判定されること。
- AC-003: Given テストケースが1件も紐づいていない要件 When スコアを算出したとき Then 契約充足度スコアは 0% となり、未テストリスクとして特定されること。
- AC-004: Given 要件にテストケース文書が紐づくが実行ステータスが未実行または失敗であるとき When スコアを算出したとき Then それらの文書は充足度スコアおよび工程密度に加算されず、スコアは未実行と同様に扱われること。
- AC-005: Given 文書として存在するテスト件数と実行合格件数が異なるとき When レポートまたはダッシュボードを観測した Then 文書件数と実行合格件数は別の値として観測でき、表示される充足度スコアは実行合格件数のみに基づくこと。
