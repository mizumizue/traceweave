## Content

### Statement
テストケース（TC）において、「何をテストするのか（目的: Objective、手順: Steps）」「期待値（Expected Results）」に加え、テスト実行による「実測値（Actual Results）」および「実行ステータス（execution_status: passed | failed | pending | skipped）」を記録・パースし、ダッシュボード上で対比して観測できなければならない。

### Acceptance Criteria
- AC-001: Given テストケース文書 When execution_status および Actual Results セクションが含まれるとき Then パース時に構造化データとして正しく抽出・保持されること。
- AC-002: Given テストケースの詳細ビュー When 展開されたとき Then 検証目的・前提、テスト手順、期待値、および実測値が明確にセクション分けされて対比表示されること。
- AC-003: Given テストケースの実行結果 When 観測されたとき Then 実行ステータス（passed, failed, pending, skipped）に応じた視覚的バッジと実測証跡（ログ・差分）が確認できること。
- AC-004: Given トレーサビリティマトリクスおよびテスト一覧画面 When 閲覧したとき Then 各テストケースの合否ステータスが一目で判別できるバッジまたはアイコンが表示されること。
