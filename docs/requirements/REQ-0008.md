## Content

### Statement
テストケース（TC）は外部パラメータデータファイル（JSON形式）を `parameter_file` メタデータとして参照でき、テスト実行エンジンはそのファイル内に定義された複数パターンの入力値（inputs）と期待値（expected）の組み合わせを順次実行し、全件の合否および実測結果を自動評価できなければならない。

### Acceptance Criteria
- AC-001: Given テストケースのフロントマターに parameter_file が指定されているとき When テスト定義がロードされたとき Then 指定ファイルから複数パターンの入力値と期待値が構造化データとして読み込まれること。
- AC-002: Given 外部パラメータファイルを持つテストケース When バッチ実行を実行したとき Then テスト実行エンジンが全パターンに対して順次テストを実行し、各パターンの実測値・合否判定・実行時間を集計できること。
- AC-003: Given バッチ実行において1件でも期待値と不一致のパターンが存在する When 結果を集計したとき Then テストケース全体のステータスが failed となり、差分詳細が特定できること。
