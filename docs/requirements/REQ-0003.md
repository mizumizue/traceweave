## Content

### Statement
システムは、全工程（単体、内結、外結、ST、UAT）におけるテスト密度を「Heavy（厚い）」「Adequate（適正）」「Thin（薄い）」「Missing（欠落）」の4段階で評価し、クラシック・ピラミッド型（単体中心）およびテストトロフィー型（結合中心）の多元モデルを認識した上で、逆ピラミッド、中間空洞化、工程欠落・不均衡などのアンチパターンを客観的に自動診断できなければならない。

### Acceptance Criteria
- AC-001: Given 各工程のテストケース分布 When 全体密度を分析したとき Then 各工程のカバー要件率に応じた4段階（Heavy/Adequate/Thin/Missing）の評価が返されること。
- AC-002: Given 単体テストが最大で上位工程に進むほど絞り込まれ全工程にテストが存在する分布 When テスト構成を診断したとき Then 健全ピラミッド（healthy）が返されること。
- AC-003: Given 結合テスト層が最も厚く全工程にテストが存在する分布 When テスト構成を診断したとき Then 健全トロフィー（healthy_trophy）が返されること。
- AC-004: Given 単体テストが薄く（Thin以下）システム・受入テストが突出して多い分布 When ピラミッド健全性を診断したとき Then 逆ピラミッド（inverted_ice_cream）警告が報告されること。
- AC-005: Given 単体と上位テストは存在するが中間結合テスト（内結・外結）が欠落（Missing）している分布 When ピラミッド健全性を診断したとき Then 中間空洞化（hollow_hourglass）警告が報告されること。
- AC-006: Given 特定のテスト工程が欠落（0件）しているか、または一部工程のみが突出して他工程が欠落・僅少である不均衡な分布 When ピラミッド健全性を診断したとき Then 不均衡・工程欠落（unbalanced）警告および具体的な欠落・偏重リスクが報告されること。
