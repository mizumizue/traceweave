## Content

### Statement
Web ダッシュボードおよびレポートにおいて、任意の要求（NEED）、要件（REQ）、仕様（SPEC）、テストケース（TC）を選択した際、対象文書のフロントマターメタデータおよび Markdown セクション（背景、課題、Statement、受入条件、Contract、目的、手順等）を即座に展開し、ドリルダウン閲覧できなければならない。

### Acceptance Criteria
- AC-001: Given ダッシュボードのマトリクス画面 When 任意の要求・要件・仕様・テストケースをクリックしたとき Then 該当ノードの詳細モーダルまたはドロワーが表示されること。
- AC-002: Given ノード詳細ビュー When 展開されたとき Then 文書の ID、タイトル、種別、ステータス、重要度、タグ、および Markdown 本文のセクション別構造化内容が含まれること。
- AC-003: Given ノード詳細ビュー When 関連文書を表示したとき Then 依存先（depends_on）、被依存元（dependents）、検証先（verifies）、および関連リンク（links）がクリック可能なバッジとして表示され、相互遷移できること。
