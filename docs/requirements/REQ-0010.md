## Content

### Statement
Web ダッシュボードおよびレポートにおいて、パーセンテージ（率）で表現される項目（全体品質充足度、重要要件充足率、マトリクス各要件の品質充足度、各工程の要件カバー率など）について、円グラフ（円形プログレス/ゲージ）を用いて充足率を一目で直感的に観測できなければならない。

### Acceptance Criteria
- AC-001: Given ダッシュボードヘッダー When 全体品質充足度および重要要件充足率を表示するとき Then 円グラフとパーセント数値の組み合わせで視覚的に表示されること。
- AC-002: Given トレーサビリティマトリクス表 When 各要件行を表示するとき Then 要件ごとの品質充足度に応じた円グラフが表示されること。
- AC-003: Given 工程地層密度分析ビュー When 各工程カードを表示するとき Then 各工程の要件カバー率が円グラフで表示されること。
- AC-004: Given 充足率の数値 When 円グラフを描画するとき Then 数値帯（80%以上で高/翠色、50%以上80%未満で中/琥珀色、50%未満で低/緋色）に応じたアクセントカラーが自動的に識別・適用されること。
