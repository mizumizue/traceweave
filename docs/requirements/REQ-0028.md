## Content

### Statement
機能要件と非機能要件の区分は、重要度やタグと並ぶ補助情報ではなく、要件を識別する際の第一の手がかりとして視覚的に強調されなければならない。利用者は一覧・詳細・グラフ上で、ラベルとまとまりの違いから両区分を混同せずに見分けられなければならない。

### Acceptance Criteria
- AC-001: Given 機能要件と非機能要件が同一画面に並ぶとき When 利用者が一覧を目視した Then 両区分は異なる短い識別ラベル（FR と NFR）と異なる見出し語（機能要件と非機能要件）で区別され、重要度ラベルより先に識別できること。
- AC-002: Given 決め事カタログに要件が含まれるとき When カタログを表示した Then 要件は機能要件群と非機能要件群に分かれたまとまりとして表示され、各群の件数が見出しとして示されること。
- AC-003: Given 要件の詳細を開いたとき When ヘッダー領域を確認した Then 区分ラベルが文書種別バッジの直後に表示され、メタデータ表の奥に隠れていないこと。
