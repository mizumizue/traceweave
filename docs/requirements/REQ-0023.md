## Content

### Statement
Web ダッシュボード（SPA）は、HTML5 History API を統合し、タブの切り替えや詳細モーダルの開閉・ノード遷移などの主要ナビゲーションをブラウザ履歴スタックに記録し、ブラウザの「戻る」「進む」操作（`popstate` イベント）に同期して画面状態およびモーダル表示を忠実に復元しなければならない (SHALL)。

### Acceptance Criteria
1. 利用者がアクティブタブを切り替えた際（例: Matrix -> Graph）、ブラウザの履歴スタックに新たなエントリーが追加（`pushState`）されること。
2. 利用者が任意のドキュメントノードをクリックして詳細インスペクションモーダルを開いた際、およびモーダル内の関連ノードリンクを辿って別のノードへ遷移した際、ブラウザの履歴スタックに新規エントリーが追加（`pushState`）されること。
3. 詳細モーダルを開いた状態でブラウザの「戻る」ボタンを実行した際、Web ダッシュボードから離脱することなく、直前に閲覧していたノードへ戻るか、または詳細モーダルが自然に閉じて元の画面状態へ復帰すること。
4. 履歴を戻った後にブラウザの「進む」ボタンを実行した際、進む先のタブや選択ノード・モーダル表示が正しく再表示されること。
5. 検索テキストの入力などの高頻度な連続操作においては、履歴スタックの無用な肥大化を防止するため、履歴を追加せず現在のエントリーを置換（`replaceState`）すること。
