## Content

### Statement
Web ダッシュボードは、タブの切り替えや詳細モーダルの開閉・ノード遷移などの主要な画面ナビゲーションをブラウザの履歴と同期させ、ブラウザの「戻る」「進む」操作に応じて画面の選択タブ、表示ノード、およびモーダル状態を忠実に復元できなければならない。

### Acceptance Criteria
- AC-001: Given 画面表示中 When 利用者がアクティブタブを切り替えたとき（例: Matrix -> Graph） Then ブラウザの閲覧履歴に新たな状態が記録されること。
- AC-002: Given 画面表示中 When 利用者がドキュメントノードを選択して詳細モーダルを開く、または関連ノードへ遷移したとき Then 閲覧履歴に新たな状態が記録されること。
- AC-003: Given 詳細モーダルが開いている状態 When 利用者がブラウザの「戻る」ボタンを操作したとき Then Web ダッシュボードから外部へ離脱することなく、直前に閲覧していたノードへ戻るか、または詳細モーダルが閉じて直前の画面状態へ復帰すること。
- AC-004: Given 履歴を戻った状態 When 利用者がブラウザの「進む」ボタンを操作したとき Then 進む先のタブ選択やノード詳細モーダル表示が正しく復元されること。
- AC-005: Given 検索テキスト入力などの連続操作時 When 状態が更新されたとき Then 履歴スタックを過剰に肥大化させず、現在の履歴状態が安全に更新されること。
