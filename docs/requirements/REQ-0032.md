## Content

### Statement
各ユースケース文書の `requirement_refs` に列挙された要件について、既存の契約トレーサビリティ充足度をロールアップし、ユースケース単位の充足率および未充足要件一覧をレポートおよび決め事カタログから観測できなければならない。`requirement_refs` が空のユースケースは未割当として区別し、0% と混同して表示してはならない。

### Acceptance Criteria
- AC-001: Given ユースケースが 1 件以上の `requirement_refs` を持つとき When トレーサビリティレポートを生成した Then 当該ユースケース ID に対応する充足度エントリが含まれ、0〜100 のスコアが観測できること。
- AC-002: Given ユースケースの `requirement_refs` が空であるとき When レポートを生成した Then 当該ユースケースは未割当ステータスとして表示され、スコアは表示されないこと。
- AC-003: Given ユースケースに未充足の参照要件が含まれるとき When 詳細ビューを表示した Then 未充足要件 ID の一覧が観測できること。
