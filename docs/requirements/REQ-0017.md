## Content

### Statement
Web ダッシュボードにおいて、要求（NEED）・アクター（ACT）・ユースケース（UC）・要件（REQ）・仕様（SPEC）・設計（DSN）・意思決定（ADR）・品質保証（QA）・テストケース（TC）の全種別の決め事ドキュメントを一覧化し、種別バッジ、ステータスタグ、キーワード検索、タグフィルターによって瞬時に絞り込み・閲覧できる横断カタログビューを提供しなければならない。

### Acceptance Criteria
- AC-001: Given Web ダッシュボードのナビゲーション When 「決め事カタログ（Decisions & Architecture）」タブを選択したとき Then リポジトリ内の全種別（ACT, UC, REQ, SPEC, DSN, ADR, QA, NEED, TC）の文書が体系的なカタログカードまたはテーブルとして網羅表示されること。
- AC-002: Given 決め事カタログ画面 When 種別フィルター（All, Actor, UseCase, Requirement, Specification, Design, ADR, Quality, Need, TestCase）を選択したとき Then 該当する種別のドキュメントのみが即座に絞り込まれること。
- AC-003: Given 検索バーまたはタグフィルター When 任意のキーワード（例: "キャッシュ", "CLI", "Pure" 等）やタグを入力・選択したとき Then タイトル・本文・セクション・タグに合致するドキュメントがリアルタイムにハイライトおよび絞り込み表示されること。
