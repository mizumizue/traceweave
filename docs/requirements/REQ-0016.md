## Content

### Statement
リポジトリのトップレベル（Root）から `node_modules` および `dist` を含む開発・依存・ビルド成果物資産を完全に排除し、`src/` 配下に完全カプセル化しなければならない。また、ルート直下に実行用ラッパー（`bin/traceweave`）を提供し、ルートから直接 CLI コマンドや各種タスクをシームレスに実行可能にしなければならない。

### Acceptance Criteria
- [x] AC-1: Given リポジトリのトップレベル Root When ルートディレクトリを検査する Then `node_modules/` および `dist/` が存在せず、製品概要・アーキテクチャ・開発者ガイド等のガバナンス文書、定義文書、および実行ラッパー（`bin/`）のみが配置されていること。
- [x] AC-2: Given アプリケーションの依存関係および設定 When `src/` 配下を参照する Then `src/package.json`、`src/tsconfig.json`、および `src/node_modules/` としてカプセル化されていること。
- [x] AC-3: Given プロジェクトのビルド処理 When ビルドを実行する Then ビルド成果物がルート直下ではなく `src/dist/`（Web アセットは `src/web/dist/`）に出力されること。
- [x] AC-4: Given 利用者がリポジトリルートから CLI を実行する When `./bin/traceweave <command>`（または Windows 用スクリプト）を呼び出す Then `src/node_modules` が自動的に解決され、正常にコマンド（check, matrix, report, serve 等）が実行されること。
- [x] AC-5: Given テストスイートの実行 When テストを実行する Then `src/` 配下の依存関係（`NODE_PATH`）が自動的に解決され、全単体・結合・E2Eテストがパスすること。
