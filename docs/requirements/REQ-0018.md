## Content

### Statement
アプリケーションの決め事ドキュメント間において、アクター参照（`actor_refs`）、要件参照（`requirement_refs`）、設計リンク（`links`）、依存関係（`depends_on`）、検証関係（`verifies`）を相互に解決し、Web ダッシュボードおよび詳細モーダル上で双方向の関連ドキュメントリンクを表示して、決定事項の文脈を辿るナビゲーションを提供しなければならない。

### Acceptance Criteria
- AC-001: Given アクター（ACT）ドキュメントの表示 When ドキュメントを参照したとき Then そのアクターが関与しているユースケース（UC）の一覧および関連リンクが双方向で自動表示されること。
- AC-002: Given ユースケース（UC）ドキュメントの表示 When ドキュメントを参照したとき Then 関連するアクター（`actor_refs`）および対象要件（`requirement_refs`）へのリンクが明示され、ワンクリックで遷移できること。
- AC-003: Given 設計事項（DSN）または意思決定（ADR）の表示 When ドキュメントを参照したとき Then 相互に関連付けられた `links`（ADR ↔ DSN）や、その設計が実現する仕様（`depends_on: [SPEC-...]`）への双方向リンクが表示され、意思決定の根拠と設計構造をスムーズに行き来できること。
