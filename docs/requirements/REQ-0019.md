## Content

### Statement
CLI および Web ダッシュボードにおいて、全種別の決め事ドキュメント数（アクター数、ユースケース数、ADR数、設計数、仕様数、要件数等）の統計サマリーを提示するとともに、CLI の決め事カタログコマンドおよび意思決定一覧コマンド（契約は SPEC-0004）によってターミナル上でも決め事の一覧や種別指定フィルタリングを直感的に実行できなければならない。

### Acceptance Criteria
- AC-001: Given CLI 環境 When 決め事カタログコマンドを種別フィルタ付きで実行したとき Then リポジトリ内の決め事ドキュメントの一覧（ID、種別、タイトル、ステータス、タグ）がターミナルにフォーマット表示されること。
- AC-002: Given CLI 環境 When 意思決定一覧コマンドを実行したとき Then ADR（意思決定）および DSN（設計決定事項）の一覧と相互リンク関係がハイライト表示されること。
- AC-003: Given Web ダッシュボードの決め事カタログヘッダー When 画面を表示したとき Then 種別ごとの文書数バッジおよび全体ドキュメント統計サマリー（全ノード数、種別内訳、決定事項充足度）が一目で把握できること。
