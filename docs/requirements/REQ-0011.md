## Content

### Statement
リポジトリのトップレベル（Root）を製品ガバナンスと全体構成の可視化に特化したクリーンな状態に保つため、Web フロントエンド関連の個別資材およびビルド生成物をサブシステム配下にカプセル化し、ビルド成果物を統合された成果物ディレクトリに集約しなければならない。

### Acceptance Criteria
- AC-001: Given リポジトリのトップレベル Root When ルート直下のファイルを一覧したとき Then 個別の Web 開発資材やビルド生成物が存在せず、製品ガバナンスおよび全体共通定義ファイルのみが配置されていること。
- AC-002: Given Web フロントエンド開発資材 When 参照したとき Then Web UI 関連の資産一式がサブシステム配下に集約・カプセル化されていること。
- AC-003: Given Web ダッシュボードのビルドコマンドを実行したとき When 静的アセットが出力される Then 統合成果物ディレクトリ配下に静的アセットおよびデータ JSON が生成され、ルート直下に生成物ディレクトリが作成されないこと。
- AC-004: Given CLI コマンド（build, serve）を実行したとき When アセットの探索および出力が行われる Then 統合成果物ディレクトリがデフォルトの対象として解決・配信されること。
