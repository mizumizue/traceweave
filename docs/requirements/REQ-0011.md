## Content

### Statement
リポジトリのトップレベル（Root）から個別の Web 開発資材（HTML、Vite設定、スタイル設定等）およびルート直下の Web ビルド生成物（`dist-web/`）を排除し、`src/web/` 配下に完全カプセル化し、成果物出力先を `dist/web/` に統一しなければならない。

### Acceptance Criteria
- AC-001: Given リポジトリのトップレベル Root When ルート直下のファイルを一覧したとき Then 個別の Web 開発資材やビルド生成物が存在せず、製品ガバナンスおよび全体共通定義ファイルのみが配置されていること。
- AC-002: Given Web フロントエンド開発資材 When 参照したとき Then HTML・バンドル設定・スタイル設定一式が `src/web/` 配下に集約・カプセル化されていること。
- AC-003: Given Web ダッシュボードのビルドコマンドを実行したとき When 静的アセットが出力される Then `dist/web/` 配下に HTML および JS/CSS/データ JSON が生成され、ルート直下に生成物ディレクトリが作成されないこと。
- AC-004: Given CLI コマンド（build, serve）を実行したとき When アセットの探索および出力が行われる Then デフォルトで `dist/web/` が対象として解決・配信されること。
