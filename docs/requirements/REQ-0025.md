## Content

### Statement
Web ダッシュボードのヘッダーに配置されているプロダクトロゴ（TraceWeave アイコンおよびタイトル）は、利用者が任意の画面や詳細モーダル、フィルタ適用状態から即座に初期ルート画面（マトリクス表示、未選択状態、フィルタ全解除）へ復帰できるよう、ルート URL へのリンク（アンカーリンク）として機能しなければならない (SHALL)。

### Acceptance Criteria
1. ヘッダーのロゴ要素（アイコンおよび TraceWeave タイトル）がアンカー要素（`<a>` タグ）としてマークアップされ、リンク先（`href`）としてルートパスが設定されていること。
2. 利用者が通常クリック（修飾キーなしの左クリック）を行った際、ページ全体の強制リロードを伴わずに SPA 内のナビゲーションとして初期ルート状態（デフォルトタブ `matrix`、ノード未選択、検索クエリおよび全フィルタの初期化）へ復帰すること。
3. ロゴクリックによるルート復帰時、ブラウザの URL（クエリパラメータ）がクリーンなルート URL に同期され、ブラウザ履歴（History API）に新たな履歴エントリーが追加（`pushState`）されること。
4. 利用者が修飾キー（Cmd/Ctrl、Shift等）を押下しながらクリックした場合、または中クリック等のブラウザネイティブ操作を行った場合は、SPA 内のイベント抑止をスキップし、ブラウザ本来の新しいタブ/ウィンドウでのルート URL オープン動作を妨げないこと。
5. ロゴ要素にマウスホバーした際、ポインターカーソルおよび視覚的フィードバック（スケール変化や透明度変化等のホバーエフェクト）が提供され、アクセシビリティ向上のための適切なツールチップまたはタイトル属性が設定されていること。
6. ロゴ要素とバージョンバッジが重ならず十分な余白を保って独立して配置され、ヘッダーの説明文が見切れることなく全画面幅で完全に視認できること。
