## Content

### Statement
Web ダッシュボードのヘッダーに配置されているプロダクトロゴ（TraceWeave アイコンおよびタイトル）は、利用者が任意の画面や詳細モーダル、フィルタ適用状態から即座に初期ルート画面（マトリクス表示、未選択状態、フィルタ全解除）へ復帰できるよう、ホームへのリンクとして機能しなければならない。

### Acceptance Criteria
- AC-001: Given ヘッダーのロゴ要素 When 画面を表示したとき Then ルート画面へのハイパーリンクとして識別可能であること。
- AC-002: Given 任意のタブまたはモーダル展開状態 When 利用者がロゴを通常クリックしたとき Then ページ全体の強制再読み込みを伴わずに初期ルート状態（デフォルトタブ、未選択、全フィルタ初期化）へ即座に復帰すること。
- AC-003: Given ロゴクリックによるルート復帰時 When 状態が更新されたとき Then URL がクリーンなルート URL に同期され、ブラウザ履歴に新たな履歴が記録されること。
- AC-004: Given 修飾キー（Cmd/Ctrl、Shift等）の押下または中クリック時 When 利用者がロゴをクリックしたとき Then 新しいタブやウィンドウでのルート画面オープンというブラウザ標準のリンク動作が妨げられないこと。
- AC-005: Given ロゴ要素 When マウスホバーしたとき Then ポインター表示および視覚的フィードバックが提供され、アクセシビリティ用の適切な説明が付与されていること。
- AC-006: Given ヘッダー表示 When 画面幅が変動したとき Then ロゴ要素とバージョンバッジが重ならず十分な余白を保って配置され、説明文が欠損なく視認できること。
