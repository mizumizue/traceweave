## Content

### Statement
Web ダッシュボードは、現在のアクティブタブ、選択中のノードID、検索キーワード、および各種フィルタ条件（テスト工程、重要度、充足度スコア、カタログ種別、タグ、ステータス、グラフハイライト等）を URL クエリパラメータとして透過的に反映・表現し、指定されたパラメータを含む URL への直接アクセスやリロード時にその状態を完全かつ安全に復元しなければならない (SHALL)。

### Acceptance Criteria
1. アクティブタブが変更された際、URL のクエリパラメータ `tab`（例: `?tab=graph`, `?tab=decisions`）が更新されること。デフォルトタブ（`matrix`）時は可読性・クリーンさのためパラメータの省略を許容すること。
2. ノード詳細が開かれた際、URL クエリパラメータ `node`（例: `?node=REQ-0001`）が設定され、モーダルが閉じられた際には `node` パラメータが安全に削除されること。
3. 検索文字列（`q`）、テスト工程（`phase`）、重要度（`criticality`）、スコア（`score`）、カタログ種別（`kind`）、タグ（`tag`）、カタログステータス（`status`）、グラフハイライト（`highlight`）が設定された際、対応するクエリパラメータが URL に反映されること（初期値/全件指定時は省略）。
4. クエリパラメータ付き URL（例: `/?tab=graph&node=REQ-0001&highlight=upstream` や `/?tab=matrix&phase=unit&criticality=high`）への初回アクセスまたはリロード時、対応するタブが選択され、フィルタが適用され、該当ノードの詳細モーダルまたはフォーカスが自動的に復元・展開されること。
5. 不正なタブ名や存在しないノードID、異常なクエリ文字列が URL に与えられた場合でも、システムはクラッシュせずデフォルト値への安全なフォールバックを行うこと。
6. ヘッダーのアクションツールバーに「現在のURL（共有リンク）をコピー」ボタンを配置し、現在の画面状態を示す完全な URL をワンクリックでクリップボードに取得できること。
