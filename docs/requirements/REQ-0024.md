## Content

### Statement
Web ダッシュボードは、現在のアクティブタブ、選択中のノードID、検索キーワード、および各種フィルタ条件（テスト工程、重要度、充足度スコア、カタログ種別、タグ、ステータス、グラフハイライト等）を URL クエリパラメータとして透過的に反映・表現し、指定されたパラメータを含む URL への直接アクセスやリロード時にその状態を完全かつ安全に復元できなければならない。

### Acceptance Criteria
- AC-001: Given 画面表示中 When アクティブタブが変更されたとき Then URL のクエリパラメータに該当タブ（例: `tab=graph`）が反映され、デフォルトタブ時はパラメータが省略されること。
- AC-002: Given ドキュメント詳細表示 When ノード詳細モーダルが開閉されたとき Then URL クエリパラメータに選択ノードID（例: `node=REQ-0001`）が反映され、閉じられた際には安全にパラメータが除去されること。
- AC-003: Given フィルター・検索設定 When 検索文字列、工程、重要度、スコア、カタログ種別、タグ、ステータス、グラフハイライトが設定されたとき Then 対応するクエリパラメータが URL に反映されること。
- AC-004: Given クエリパラメータ付き URL When 初回アクセスまたはリロードが行われたとき Then 対応するタブの選択、フィルターの適用、ノード詳細モーダルの展開が自動的に復元されること。
- AC-005: Given 不正または存在しないパラメータを含む URL When アクセスされたとき Then システムがクラッシュせず安全にデフォルト値へとフォールバックすること。
- AC-006: Given 共有リンク操作 When クリップボードへの URL コピーを実行したとき Then 現在の表示状態を完全に表現する URL がワンクリックで取得できること。
