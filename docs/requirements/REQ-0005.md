## Content

### Statement
システムは、独立した CLI ツールとして文書整合性検証・マトリクス出力・レポート生成・静的ビルド・プレビューサーバー起動を提供し（契約は SPEC-0004）、CI 環境での自動判定およびローカル開発での迅速な確認をサポートしなければならない。

### Acceptance Criteria
- AC-001: Given 検査対象の docs ディレクトリが存在する環境において When 文書整合性検証コマンドを実行したとき Then 文書スキーマエラーや重要要件のテスト未充足がある場合は exit code 1、正常時は exit code 0 を返すこと。
- AC-002: Given 有効なトレーサビリティデータが存在する環境において When マトリクス出力コマンドを指定形式で実行したとき Then 指定された形式でマトリクス集計が標準出力に出力されること。
- AC-003: Given 有効なビルド済みダッシュボードが存在する環境において When プレビューサーバー起動コマンドを実行したとき Then ローカル HTTP プレビューサーバーが起動し、ブラウザでダッシュボードを即時閲覧できること。
- AC-004: Given 指定ポートが既に他のプロセスにより使用されている環境において When プレビューサーバー起動コマンドを実行したとき Then 既存プロセスを停止してポートを解放した上で、ローカルプレビューサーバーを再起動すること。
