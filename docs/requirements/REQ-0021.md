## Content

### Statement
トレーサビリティグラフ画面において、表示するドキュメント種別（NEED, REQ, SPEC, DSN, TC 等）のオン/オフ切り替えやキーワード検索による絞り込みを提供するとともに、任意のノードにフォーカスした際に、そのノードから上流へ至る祖先パス（Upstream / Depends-on）および下流へ至る子孫パス（Downstream / Dependents）を視覚的に強調ハイライトし、無関係なノードを減光（ディミング）表示できなければならない。

### Acceptance Criteria
- AC-001: Given グラフビュー上部のツールバー When グラフ初期表示時 Then 原則としてすべての種別（All）のノードが表示されること。各種別チップ（NEED, ACT, UC, REQ, SPEC, DSN, ADR, QA, TC）をクリックしたとき、クリックされた種別のノードのみが非表示（除外）となり、他の種別は表示され続けること（マルチ除外トグル）。
- AC-002: Given 非表示に除外された種別チップ When ユーザーが当該チップを再度クリックしたとき Then その種別のノードが即座に再表示されること。また「All」ボタンをクリックしたとき、すべての除外状態が解除されて全種別ノードが表示されること。
- AC-003: Given グラフ上の任意のノード When ユーザーがノードをクリックまたはホバーしてフォーカスしたとき Then そのノード自身、そこから上流（`depends_on` 方向）へ到達可能なすべてのノード・エッジ、および下流（依存されている方向）へ到達可能なすべてのノード・エッジが異なる色またはアクセントでハイライトされ、非関連ノードが半透明化されること。
- AC-004: Given トレースパス強調モード When 「上流のみ（Upstream Only）」「下流のみ（Downstream Only）」「全トレース（All Connected）」の切り替えボタンを操作したとき Then 意図した方向の影響波及パスのみが明確に色分け表示されること。
