## Content

### Statement
Web ダッシュボードのマトリクスおよび決め事カタログ、ならびに CLI カタログにおいて、利用者は機能要件と非機能要件を区分して一覧し、片方の区分だけに絞り込めるようにしなければならない。絞り込んだ状態は URL から再現できなければならない。

### Acceptance Criteria
- AC-001: Given 機能要件と非機能要件が混在するダッシュボード When 利用者が機能要件の区分を選んだ Then 表示される要件は機能要件のみとなり、非機能要件は一覧から除外されること。
- AC-002: Given 機能要件と非機能要件が混在するダッシュボード When 利用者が非機能要件の区分を選んだ Then 表示される要件は非機能要件のみとなり、機能要件は一覧から除外されること。
- AC-003: Given 区分フィルターが機能要件または非機能要件であるとき When その画面の URL を開いた Then 同じ区分で絞り込まれた状態が復元されること。
- AC-004: Given CLI カタログ When 区分を指定して実行した Then 指定区分の要件のみが一覧され、区分件数サマリーが出力されること。
