## Content

### Statement
システムは、リポジトリワークスペース直下の `.traceweave/config.json` を正本として、文書ディレクトリ・証跡出力先・複数テスト実行単位（suite）を解決できなければならない。複数 suite が存在しても、トレーサビリティ充足度およびダッシュボードが参照するテスト結果は、ワークスペース単一の集約レポート（既定 `reports/test-results.json`）にマージされたものでなければならない。利用者が任意の作業ディレクトリから CLI を実行した場合、上方向探索により同一ワークスペース設定が解決されなければならない。

### Acceptance Criteria
- AC-001: Given `.traceweave/config.json` に 2 件以上の suite が定義されているとき When ワークスペースのテスト実行コマンドを実行した Then 各 suite が実行され、TC ID キーでマージされた集約レポートが生成されること。
- AC-002: Given 子ディレクトリをカレントに CLI を起動したとき When ワークスペース解決が行われた Then 親ディレクトリの `.traceweave/config.json` が読み込まれること。
- AC-003: Given 集約レポートが生成されているとき When レポートまたはダッシュボードを構築した Then 充足度計算は集約レポートのみを入力とし、suite 別スコアを既定表示してはならないこと。
- AC-004: Given ワークスペースルートが CLI オプションまたは環境変数で明示指定されたとき When 任意の TraceWeave コマンドを実行した Then 指定ルートの設定がカレントディレクトリ探索より優先されること。
