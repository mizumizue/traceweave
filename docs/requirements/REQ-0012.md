## Content

### Statement
Web ダッシュボードにおいて、テスト実行・パラメータ整形・クリップボードコピー・エクスポート等のユーザー操作および非同期処理に対し、画面上に一時的なトースト通知を用いて視覚的なフィードバックを即座に提供し、処理中・成功・エラーの状態を明確に伝えなければならない。

### Acceptance Criteria
- AC-001: Given Web ダッシュボード画面 When アプリケーションを表示したとき Then ユーザー操作に対するトースト通知の表示機構が準備されていること。
- AC-002: Given 対話型テストランナー When テスト実行を開始したとき Then 処理中である旨の通知が表示され、実行完了後に成功またはエラーの通知へとスムーズに更新されること。
- AC-003: Given パラメータ入力欄やモーダル When 整形やワンクリックコピーを実行したとき Then 処理が成功した旨を示すトースト通知が表示されること。
