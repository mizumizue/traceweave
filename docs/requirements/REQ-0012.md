## Content

### Statement
Web ダッシュボードにおいて、テスト実行・パラメータフォーマット・クリップボードコピー・エクスポート等のユーザー操作に対し、`sonner` トースト通知機構を用いて視覚的かつリッチなフィードバックを即座に提供しなければならない。

### Acceptance Criteria
- AC-001: Given Web ダッシュボードの最上位コンポーネント（App.tsx） When アプリケーションを描画する Then `<Toaster />` がルートに配置され、通知の表示準備が整っていること。
- AC-002: Given 対話型テストランナー When テスト実行ボタンを押下したとき Then `toast.loading` で実行中通知が表示され、実行完了後に成功（`toast.success`）またはエラー通知へとスムーズに更新されること。
- AC-003: Given パラメータ入力欄やモーダル When JSON 整形やワンクリックコピーを実行したとき Then 処理成功を示すトースト通知が表示されること。
