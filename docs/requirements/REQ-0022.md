## Content

### Statement
トレーサビリティグラフ上で任意のノードカードを選択した際、即座にサイドパネルまたは詳細モーダルにおいて該当ドキュメントの全文、メタデータ、受入条件、パラメータデータ、および接続関係（直近の上流ノード・下流ノード一覧）を閲覧でき、詳細画面内の依存リンクをクリックしてグラフ側の選択状態を追従更新できなければならない。

### Acceptance Criteria
- AC-001: Given グラフ上のノードカード When ユーザーがノードの「詳細を開く」アクションまたはダブルクリックを実行したとき Then 既存のドキュメント詳細モーダル（REQ-0004 / NEED-0002 準拠のインスペクター）が開き、文書本文やセクション構造が即座に閲覧できること。
- AC-002: Given ドキュメント詳細モーダル When モーダル内の上流リンク（`depends_on`）や下流リンク（`verifies` 等）をクリックしたとき Then モーダルの表示対象が切り替わると同時に、グラフビュー側の選択ノードとハイライト対象も連動して更新されること。
- AC-003: Given ノード選択状態 When キーボードの ESC キーを押下するか、モーダルのクローズボタンをクリックしたとき Then グラフビューにスムーズに復帰し、選択状態の解除または維持が直感的に行えること。
