## Content

### Goal
利用者がトースト通知・モーダル履歴ナビゲーション・立体ピラミッド・多軸フィルター・データエクスポートを通じて、直感的かつ効率的に品質データを操作・抽出する。

### Trigger
利用者が Web ダッシュボード上でコピー、フィルター変更、ピラミッド層選択、エクスポート、モーダル内リンク探索などの操作を行う。

### Preconditions
ダッシュボードが正常にロードされ、トレーサビリティレポートが表示可能であること。

### Main Flow
1. 操作（テスト実行、コピー、エクスポート等）に応じてトースト通知で進捗・成否が即時に伝わる。
2. モーダル内で依存リンクを辿った後、戻る・進む・ESC・ワンクリックコピーが利用できる。
3. 立体ピラミッドで工程別ボリュームを視覚比較し、層クリックでマトリクスを絞り込む。
4. 重要度・工程・充足度・キーワードでマトリクスを絞り込み、CSV/JSON/Markdown をエクスポートする。

### Alternative Flows
- クイックチップ: 高重要度・要改善・単体テストなどのプリセット絞り込みをワンクリックで適用する。
- フィルター結果ゼロ件: 空状態が明示され、条件解除を促す。

### Postconditions
利用者は大量要件の中から目的データを素早く抽出し、共有用データを即座に取得できる。
