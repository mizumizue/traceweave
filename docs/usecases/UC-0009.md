## Content

### Goal
利用者が Web ダッシュボードのタブ・モーダル・フィルタ状態を URL で表現し、ブラウザの戻る・進む操作や URL 共有・ブックマーク・リロードで同一状態を復元できる。

### Trigger
利用者がタブ切替、ノード選択、フィルタ変更、ロゴクリック、ブラウザ戻る・進む、または URL 共有を行う。

### Preconditions
Web ダッシュボードが SPA として動作していること。

### Main Flow
1. タブ・モーダル・フィルタの変更が URL クエリパラメータへ反映される。
2. ブラウザの戻る・進むで直前の画面状態（タブ、モーダル、フィルタ）が復元される。
3. クエリ付き URL を直接開くかリロードすると、同じ表示状態が自動復元される。
4. 共有リンク操作で現在状態の完全 URL をクリップボードに取得できる。
5. ヘッダーロゴクリックでルート画面（初期タブ・全フィルタ解除）へ即座に復帰できる。

### Alternative Flows
- 不正パラメータ: デフォルト値へ安全にフォールバックし、クラッシュしない。
- 修飾キー付きロゴクリック: 新規タブでのルート画面オープンなどブラウザ標準動作が維持される。
- 検索入力: 履歴スタックを肥大化させず `replaceState` で現在状態を更新する。

### Postconditions
利用者は調査中の画面状態を同僚と共有し、ブラウザ操作で自然にナビゲートできる。
