## Content

### Goal
開発者・アーキテクト・新規参画者が、アクター・ユースケース・要件・仕様・設計・ADR・品質方針などの決め事を横断的に一覧・検索・相互参照できる。

### Trigger
利用者が Web ダッシュボードの決め事カタログタブを開く、または CLI でカタログコマンドを実行する。

### Preconditions
リポジトリ内に ACT/UC/REQ/SPEC/DSN/ADR/QA 等の文書が存在すること。

### Main Flow
1. 種別・タグ・ステータス・キーワードで決め事を絞り込む。
2. カード一覧から文書を選択し、詳細インスペクションで全文を閲覧する。
3. アクター参照・要件参照・設計リンクを辿り、関連決め事へ双方向にナビゲートする。
4. 統計サマリー（種別件数、タグ分布等）で全体像を把握する。

### Alternative Flows
- CLI 閲覧: ターミナル上で同種のカタログ出力と絞り込みを行う。
- リンク切れ: 参照先が存在しない場合、警告として識別できる。

### Postconditions
利用者は個別 Markdown を手動探索せず、システムの決め事全体を体系的に理解できる。
