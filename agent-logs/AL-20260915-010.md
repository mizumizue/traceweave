**Summary — スクリーンショット資産の追加**

`traceweave serve` で起動したダッシュボードから、マトリクス・グラフ・ピラミッド・決め事カタログ・ギャップ各タブを 1440×900 ビューポートで撮影。外部ホスティング不要のため `docs/assets/screenshots/` 配下に PNG 5 ファイルとしてコミット対象に含める。

**Summary — README デモセクション**
