## Content

### Objective
**課題:** TraceWeave が Node V8 カバレッジと正規表現関数スキャンを内製しており、TypeScript 専用・境界違反（serve 時の自動テスト実行）となっていた。

**対応:** ADR-0008 で計測を言語ツール（`c8`）に委譲し、TraceWeave は `reports/lcov.info` を消費して正規化・表示のみ行う構成へ移行する。

### Completion Criteria
- [x] ADR-0008 起票、SPEC-0026 / DSN-0021 改訂
- [x] `LcovParser` + `build-coverage-artifacts` 実装
- [x] V8/regex 層削除、`npm run test:coverage` 追加
- [x] `ensureUnitCoverageReport` は存在確認のみ
- [x] `npm run lint` / `npm test` 成功

### Changes
**ADR と仕様改訂。** カバレッジ計測の Out-of-Scope 化と LCOV 境界契約を ADR-0008 で固定し、SPEC-0026 / DSN-0021 の入力・データフローを LCOV 前提に更新した。

**LCOV 消費パイプライン。** `LcovParser.ts` で `lcov.info` をパースし、`build-coverage-artifacts.ts` が `coverage-summary.json` と `coverage-files/` を生成する。`run-test-coverage.ts` は `c8` 実行後にアーティファクト生成を必ず行う。

**内製計測の削除。** `V8CoverageAggregator`、`SourceFunctionScanner`、TAP 表パース、`run-test-suite` のカバレッジ生成を除去。`npm test` は `test-results.json` のみ、`test:coverage` でカバレッジを明示生成する。

**UI・serve 境界の整理。** `ensureUnitCoverageReport` は `present` / `missing` のみ返し、テストスイートを起動しない。`UnitCoverageView` の案内文言を `test:coverage` に更新。

### Outcome
利用者は `npm --prefix src run test:coverage` でカバレッジを生成し、ダッシュボードの単体タブで LCOV 由来の行・分岐詳細を閲覧できる。`serve` はカバレッジ未生成時に pending を表示するだけで、テストを自動実行しない。
