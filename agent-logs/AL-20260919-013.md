## Content

### Objective

**課題:** バックエンドは退役親 TC をカタログから除外済みだが、ダッシュボードが data.json 内の古い `testStratumCatalog` を優先し、分割前 ID が一覧に残って見えた。

**対応:** `TestBooksView` で `nodes` がある場合は常に `buildTestStratumCatalog` で再構築し、`isActiveTestCase` による除外を UI でも確実にする。

### Completion Criteria

- [x] TestBooksView が nodes からカタログを再生成
- [x] 古いペイロード想定の回帰テスト追加
- [x] `npm --prefix src run lint` 成功
- [x] 退役関連テスト成功

### Changes

**UI:** 埋め込み `testStratumCatalog` より `nodes` 正本を優先。nodes 空のときのみ従来のフォールバック。

**テスト:** 退役親が nodes に残るケースで再構築後 1 件になることを検証。

### Outcome

古い data.json を読み込んでもテスト仕様・結果タブに退役分割親は出ない。serve の最新レポートと表示が一致する。
