## Content

### Objective

**課題:** 単体実装カバレッジタブは集計メトリクスとモジュール一覧までしか見えず、未実行分岐や関連テストコードをファイル単位で追えなかった。

**対応:** V8 カバレッジからファイル別アーティファクトを生成し、Web API とモーダル UI で実装・テストを並列表示する導線を追加する。

### Completion Criteria

- [x] テスト実行後に reports/coverage-files/ が生成される
- [x] serve / build でカバレッジアーティファクトが Web に配布される
- [x] 単体タブのファイル行クリックでモーダルが開き、分岐の実行状態が色分けされる
- [x] ucfile クエリでモーダル状態が URL と同期する
- [x] npm --prefix src run lint と npm --prefix src test が成功する

### Changes

**カバレッジ詳細ビルド.** CoverageDetailBuilder と SourceTestFileResolver を追加し、V8 出力からファイル単位の関数・分岐・関連テストを決定論的に構築する。テストスイート完了時に JSON アーティファクトを書き出す。

**配布経路.** run-test-suite.ts・build-web-dashboard.ts・serve-dashboard.ts にカバレッジファイルの生成・コピー・API を接続した。

**Web UI.** UnitCoverageFileModal と UnitCoverageView の行クリック導線を追加。urlState に unitCoverageFile / ucfile を追加し、モーダル状態を URL と双方向同期する。

### Outcome

単体タブでモジュール行を開くと、実装コードと関連テストを並べて未実行分岐を確認できる。テスト実行後のレポートがそのままダッシュボードに反映される。

- npm --prefix src test — 160 pass, 0 fail
