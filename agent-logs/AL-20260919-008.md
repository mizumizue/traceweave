## Content

### Objective
**課題:** UI 向け TC が Node のソース検査やタイトル中の `TC-` 参照だけで `test-results.json` に載り、ブラウザ工程のオラクルと混同されていた。`tests/web` も formal とみなされやすかった。

**対応:** formal / supplementary のスイート境界とタイトル行頭宣言行をコードと ADR で固定し、`tests/support` を証跡非マージの補助層へ移し、Playwright E2E を formal 正本として足す。エージェント向けスキル・ルールで配置判断を再利用可能にする。

### Completion Criteria
- [x] ADR-0011 / REQ-0035 / SPEC-0030 / DSN-0025 起票と lint 通過
- [x] `.traceweave/config.json` に node / support / e2e / newman スイート
- [x] `formalTestCaseIdFromTitle` と Playwright 変換、マージは formal のみ
- [x] TC-ST-0003 + `tests/e2e`、関連 TC 文書の役割分担更新
- [x] `traceweave-verification-tiers` スキルと `verification-evidence-tiers` ルール
- [x] `npm --prefix src run lint` および `npm --prefix src test` 成功

### Changes
**ガバナンスと契約** — ADR-0011 で formal（行頭 `TC-…:` + `evidenceTier: formal`）と supplementary（`support:`、非マージ）を定義。REQ/SPEC/DSN でワークスペース設定・マージ・Playwright 変換を仕様化した。

**ランタイムとスイート** — `run-workspace-tests` / TAP 解析 / `run-node-test-tap-suite` を title-prefix 規則に揃え、support・e2e を既定 Node 走査から除外。`run-e2e-suite` と `playwrightReportToTraceWeaveV1` で E2E fragment を生成。node 完了後と E2E 前の `data.json` 同期で support / プレビュー依存を安定化。

**テスト配置と E2E** — 契約 UT を `tests/core` に、旧 `tests/web` を `tests/support/web-contract` に移しタイトルを `support:` 化。Playwright で TC-ST-0003 を formal 証跡化。`@playwright/test` を dev 依存に追加。

**エージェント運用** — `traceweave-verification-tiers`（TIER-MATRIX）と glob ルールで配置・宣言行の判断を共通化。DEVELOPER_GUIDE と test-writing-guidelines を更新。

### Outcome
ダッシュボードの TC 合否は formal スイートと行頭 TC 宣言行だけが更新する。UI の静的ハーネスは CI で走るが証跡に載らず、ブラウザスモークは E2E が形式証跡を担う。
