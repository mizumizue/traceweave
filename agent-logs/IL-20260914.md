## Content

### Objective

**課題:** TC 文書に実行結果が混在し仕様と証跡が分離できておらず、充足度スコアも文書件数で水増しされていた。UI でも実行状態が判別しづらかった。

**対応:** ADR-0006 分離と実行合格ベーススコアリングを一括改善（1 改善 1 サブエージェント）。本ログは分割前のレガシー集約記録。詳細は AL-20260914-003〜005 を参照。

### Completion Criteria

- [x] DocParser / TestReportLoader が ADR-0006 に沿って仕様と実行を分離
- [x] validate-docs に fence-lite 規則と TC 禁止セクション検査を追加
- [x] SufficiencyScorer / BalanceAnalyzer / MatrixBuilder が実行合格ベースに更新
- [x] Web UI / ConsoleReporter が実行ステータス観測を反映
- [x] V-model 文書（REQ/SPEC/DSN/QA/TC）を整合
- [x] lint / test 成功

### Changes

| Area | Summary |
|------|---------|
| TC 分離（AL-003） | **状況:** TC 文書に実行結果が混在し、仕様と証跡の正本が分離できていなかった。**対応:** DocParser / TestReportLoader で分離し、fence-lite を機械検証。**狙い:** 仕様は TC 文書、実行はレポートに一本化。 |
| スコアリング（AL-004） | **状況:** 充足度が文書件数で水増しされ、実行実態を反映していなかった。**対応:** passed のみ加算、文書/実行を別集計。**狙い:** スコアが「実際に通ったテスト」に基づく指標になる。 |
| UI 表示（AL-005） | **状況:** コンソール・Web が旧表記で、実行状態を区別できなかった。**対応:** 実行合格ベース表記と passed/pending/failed/skipped 内訳を表示。**狙い:** 利用者が件数内訳を一覧できる。 |

### Outcome

TC 文書と実行結果が分離され、充足度スコアは実行合格のみを反映する。コンソールと Web UI で文書件数と実行件数を別観測でき、各 TC の実行状態（passed/pending/failed/skipped）が正しく表示される。
