## Content

### Objective

**課題:** `./bin/traceweave test` は `npm test` と違い `data.json` を用意しないため ITb-0019 / support が落ちる。TC interface fence のバッククォート内 `Type.method` 検出とカタログ UC 期待値が実ドキュメントとずれていた。E2E spec は IDE で `@playwright/test` を解決できない。

**対応:** ワークスペーステスト実行前後の Web dist / `data.json` 同期を共通化し、ガバナンス・結合テスト期待値を更新。`tests/e2e/tsconfig.json` で Playwright 型を `src/node_modules` に向ける。

### Completion Criteria

- [x] `npm --prefix src run lint` 成功
- [x] `npm --prefix src test` 成功
- [x] `traceweave test` と `npm test` で同じ Web 準備が走る
- [x] E2E spec の `tsc -p tests/e2e` 成功

### Changes

**ワークスペーステストの Web 準備を一本化した。** `prepare-workspace-test-run.ts` に dist ビルドと `syncDashboardArtifacts` を集約し、CLI `test` と `run-test-suite.ts` の両方から呼ぶ。node スイート後と集約完了後も `data.json` を更新する。

**TC interface fence を補強した。** バッククォート内の `Class.method` を dotted implementation として報告し、ITa Steps の契約検査テストと整合させた。

**結合テストの UC 期待値を現行 docs に合わせた。** ACT-0001 逆引きと `matrix` クエリ結果に増えた UC を反映した。

**E2E 用 tsconfig を追加した。** 依存が `src/` カプセル内にあるため、`tests/e2e` だけ paths で `@playwright/test` を解決する。

### Outcome

`./bin/traceweave test` 単体でも `src/web/dist/data.json` が揃い、Web 契約テストと support スイートが安定する。エディタ上の Playwright import エラーが解消する。
