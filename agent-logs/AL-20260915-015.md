## Content

### Objective

**課題:** マトリクスとグラフが独立タブとして並び、ナビゲーションと URL 状態が冗長だった。

**対応:** 単一の「トレーサビリティ」タブ配下に matrix/graph ビュー切替を置き、URL は `view=` クエリで表現する。レガシー `tab=matrix|graph` は互換パースする。

### Completion Criteria

- [x] TabNav から matrix/graph 独立タブを除き traceability タブに集約する
- [x] `TraceabilityViewToggle` で matrix/graph を切り替えられる
- [x] urlState の parse/serialize が新形式とレガシー形式を両立する
- [x] 関連 urlState テストが更新され full test が成功する

### Changes

**URL 状態モデルの拡張**

`AppTab` に `traceability` を導入し、`TraceabilityView`（matrix | graph）を URL `view` パラメータで保持する。`tab=matrix|graph` は traceability + 対応 view へマップする。

**UI 統合**

`TraceabilityViewToggle` を追加し、トレーサビリティタブ内で MatrixView / TraceabilityGraphView を切替表示する。品質メトリクスやホーム遷移も新タブ体系に合わせた。

**テスト更新**

urlState およびヘッダーロゴ・高重要度 strata 連携テストの期待値を traceability タブ体系に合わせた。

### Outcome

利用者は一つのトレーサビリティ入口からマトリクスとグラフを切り替えられ、共有 URL は `view=graph` 形式で簡潔になる。旧リンク `?tab=graph` も引き続き開ける。
