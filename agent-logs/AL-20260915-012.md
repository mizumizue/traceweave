## Content

### Objective

**課題:** ドメインの決め事である用語集が `docs/` に存在せず、決め事カタログからも種別として参照できなかった。adopt 先にも TraceWeave プラットフォーム用語が渡らない状態だった。

**対応:** `glossary` 文書種別（GLO-）をスキーマ・パーサ・カタログ・Web UI・CLI に通し、本体に 14 用語を起票。adopt は `docs/glossary/` 全件を本体から決定論的にコピーする方式に統一した。

### Completion Criteria

- [x] `docs/glossary/` と GLO-0001〜0014 がスキーマ検証を通過
- [x] 決め事カタログ・詳細モーダル・グラフで glossary を閲覧可能
- [x] `traceweave adopt` が GLO 14 件を配備（テストで検証）
- [x] `npm --prefix src run lint` 成功
- [x] `npm --prefix src test` 成功（実行時点）

### Changes

**Summary 1 — 文書種別 `glossary` の追加**  
`validateDocs`、DocKind、DecisionsCatalog、TraceabilityGraph、URL 状態、MCP/CLI フィルタに tenth kind を追加。`depends_on: []` の独立文書として ACT/UC と同列に扱う。

**Summary 2 — 本体用語 14 件と NEED 横断リンク**  
トレーサビリティ・工程地層・V字モデル・充足度など TraceWeave プラットフォーム語彙を GLO として起票し、関連 NEED から `links` で相互参照可能にした。

**Summary 3 — Web 決め事カタログ UI**  
種別チップ・用語集ショートカット・GLO バッジ・詳細モーダルの用語専用レイアウトと relatedGlossary/relatedNeeds 表示を追加。10 種グリッド列数を修正。

**Summary 4 — adopt 全 GLO 配備**  
`loadAdoptGlossaryDocs()` で本体 `docs/glossary/` を読み込み日付のみ更新して overlay/restructure に配備。旧プロジェクト名プレースホルダ GLO-0001 テンプレートは廃止。

### Outcome

adopt 直後のプロジェクトでも TraceWeave 本体と同じ 14 用語が決め事カタログから検索・閲覧できる。本体 glossary を更新すれば次回 adopt から自動追随する。
