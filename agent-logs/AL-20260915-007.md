## Content

### Objective

**課題:** テストランナーは全件 npm test のみ表示され、個別 TC の再実行手順が不明確だった。マトリクス/ピラミッドのクイックフィルタは再クリックで解除できず、トーストも重複していた。

**対応:** TC ID から CLI コマンドを生成する共通モジュールを追加し、テストスイートに --tc フィルタとレポートマージを実装。ダッシュボードのフィルタボタンをトグル化した。

### Completion Criteria

- [x] formatTestRunCommand / parseTestCaseFilter が追加される
- [x] run-test-suite.ts が --tc で部分実行・レポートマージできる
- [x] InteractiveTestRunner が TC 別コマンドを表示する
- [x] マトリクス/ピラミッド/FR-NFR フィルタが再クリックで解除できる
- [x] 単体テストが PASS

### Changes

**TC 実行コマンド共通化。** formatTestRunCommand.ts で npm --prefix src test -- --tc TC-xxxx を整形。run-test-suite は TAP パース結果を既存 report にマージ。

**ダッシュボード UX。** MatrixView と App のクイックフィルタをトグル化。VisualTestPyramid の重複 toast を App 側に集約。

### Outcome

利用者は UI 上で TC 単位の実行コマンドをコピーでき、フィルタ操作が直感的になる。
