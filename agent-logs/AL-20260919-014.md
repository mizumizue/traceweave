## Content

### Objective

**課題:** 用語集が TraceWeave 固有語のみで、一般のシステム開発用語が不足していた。タグだけでは決め事カタログ上で境界を安定して切れなかった。

**対応:** 一般 GLO を大量追加し、`glossary_scope` と `glossary_domain` をスキーマ必須化。カタログ UI・URL 状態・lint で同じ分類軸を機械的に使う。

### Completion Criteria

- [x] 一般システム開発用語を GLO として追加（既存 TW 固有語と同居）
- [x] `glossary_scope` / `glossary_domain` を全 GLO に付与し validate-docs で検証
- [x] 決め事カタログでスコープ・ドメイン別フィルタとバッジ表示
- [x] `npm --prefix src run lint` および `npm --prefix src test` 成功

### Changes

TraceWeave 固有語と文脈別の一般語を `docs/glossary/` に整理し、各 GLO に taxonomy メタデータを付与した。`glossaryTaxonomy` で列挙・フィルタ・整合を一元化し、パーサ・lint・カタログビルダーと UI（チップフィルタ、バッジ、URL `gloscope`/`glodomain`）を接続した。adopt 期待と URL 契約テストを更新し、再付与用スタンプスクリプトを追加した。

### Outcome

決め事カタログで TraceWeave 固有語と一般語を切り替え、テスト・DB・PM など文脈で絞り込める。新規 GLO は taxonomy 必須で分類漏れを lint が防ぐ。
