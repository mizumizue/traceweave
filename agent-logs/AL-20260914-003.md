## Content

### Objective

**課題:** TC 文書に実行結果（Actual Results / Evidence）が混在しており、「仕様の正本」と「実行の証跡」が分離できていなかった。文書を読んだだけではテストが本当に通ったのか判断できず、古い実行結果が仕様と誤認されるリスクもあった。

**対応:** ADR-0006 に沿い、TC 文書は静的仕様のみを保持し、実行結果はテストレポートから取得する分離モデルへ移行する。あわせて fence-lite 規則を `validate-docs` で機械検証し、実行結果の再混入や verifies 対象の逸脱を lint 時に検出する。

### Completion Criteria

- [x] DocParser が test_case の実行結果セクションを無視し pending 既定とする
- [x] TestReportLoader がレポートの生出力のみを結合し合否作文を生成しない
- [x] validate-docs に fence-lite ルールと TC 禁止セクション検査を追加
- [x] 関連 TC・フィクスチャ・インフラテストを更新
- [x] lint / test 成功
