## Content

### Objective

**課題:** 決め事カタログでは Actor と UseCase の相互参照がバッジ列として混在しており、「誰がどのシナリオに関与するか」が一覧で把握しづらかった。マップ表示を足した後も、紐づき UC が ID のみで概要が見えず、結局何が繋がっているか分からないというフィードバックがあった。

**対応:** 新タブは増やさず、決め事カタログに第 3 表示モード（Actor ↔ UseCase マップ）を追加する。カタログ既存データの relatedActors / relatedUseCases を二部グラフとして可視化し、リンク先には ID に加えタイトルと Goal / Role 概要を表示する。

### Completion Criteria

- [x] 決め事カタログに Actor-UC マップ viewMode が追加されている
- [x] アクター起点・ユースケース起点の双方向表示と孤立検出がある
- [x] 紐づき先にタイトルと概要（Goal / Role）が表示される
- [x] buildActorUseCaseMap の単体テストが通る
- [x] npm --prefix src run lint が成功する

### Changes

**参加関係マップのデータ構築。** buildActorUseCaseMap を src/web/src/utils/actorUseCaseMap.ts に切り出した。カタログ items から Actor / UseCase を抽出し、双方向行・リンク数・孤立 Actor / UC を決定論的に組み立てる。種別フィルターが REQ 等の非互換値のときは表示ブロック用フラグを返す。

**DecisionsBrowser の第 3 表示モード。** grid / table に加え actor-uc-map を追加した。サマリー、表示起点切替、カードクリックで既存 NodeDetailModal へ遷移する UI を実装した。

**リンクカードの可読性改善。** マップ内の紐づき先を ID バッジから renderParticipationLink カードに変更した。UC は Goal、Actor は Role を 2 行まで表示する。

### Outcome

決め事カタログの ↔ ボタンから、Actor と UseCase の参加関係を一覧で追える。各リンクにタイトルと概要が載るため、ID を覚えなくても何が紐づいているかをその場で判断できる。
