## Content

### Objective

**課題:** TraceWeave の V字モデル文書がルール（スキーマ・抽象度・境界・トレーサビリティ）に沿って管理されているかを、エージェントが決定的な手順で監査する手段がなく、付属 Cursor スキルを別環境へ配備する仕組みも未整備だった。

**対応:** 機械検証（sweep）と意味論監査（fence-deep）を分離した `traceweave-docs-audit` スキルを新設し、統合ガバナンス lint とスキル配備スクリプト・インストーラスキルを追加して、監査と配備を一貫したワークフローにした。

### Completion Criteria

- [x] `traceweave-docs-audit` スキル（SKILL.md + FENCE-CHECKS.md）が作成されている
- [x] `traceweave-install-skills` スキルと `install-cursor-skills.ts` が作成されている
- [x] `npm --prefix src run lint` が validate-docs / no-local-paths / clean-root を統合実行する
- [x] 新規テストが通過する
- [x] `npm --prefix src run lint` が exit 0

### Changes

**ドキュメント監査スキル:** `traceweave-docs-audit` を追加。sweep（統合 lint + `traceweave check`）→ fence-deep（8 項目の意味論チェック）→ adjudicate（PASS/FAIL レポート）の 3 段階で、quick / full ブランチを使い分けられる。FENCE-CHECKS.md に document-authoring の監査観点を単一正本として集約。

**スキル配備:** `install-cursor-skills.ts` と `traceweave-install-skills` スキルを追加。`personal`（`~/.cursor/skills/`）と `project` ターゲット、`--with-rules`、`--dry-run` をサポート。POSIX / PowerShell ラッパー付き。

**統合 lint:** `run-governance-lint.ts` を新設し `npm run lint` の正本に変更。implementation-workflow が要求する 3 検証を一括実行するよう実装とルール記述を整合。

**ドキュメント連携:** INSTALL_GUIDE にスキル配備・監査の手順を追記。document-authoring の audit ステップから新スキルを参照。

### Outcome

エージェントは「ドキュメント管理を audit して」と指示されるだけで、機械検証と意味論監査を同じ手順で実行できる。別マシンや外部プロジェクトへ `npm run install-skills` で TraceWeave スキル群を配備できる。
