## Content

### Objective

**課題:** ピラミッド・地層ビューで単体層の指標が「要件カバー率」と表示され、実装カバレッジ（関数カバー率）と混同されていた。あわせて単体カバレッジ詳細モーダルでは関連テストが複数あるときボタン横並びでヘッダーが崩れていた。

**対応:** `metricSource` に応じてラベルを分岐し、詳細モーダルでは複数テストファイルをドロップダウン選択に置き換える。

### Completion Criteria

- [x] ピラミッド・地層・CLI で単体層が関数カバー率、他層が要件カバー率と表示される
- [x] カバレッジ詳細モーダルで複数関連テストをドロップダウンで選択できる
- [x] `npm --prefix src run lint` 成功
- [x] `npm --prefix src test` 成功

### Changes

**ピラミッド・地層ラベルの metricSource 分岐**

単体層は `code_coverage`、内結以降は `traceability` という既存データモデルに UI ラベルを揃えた。ピラミッドの見出し・ゲージ・件数単位（関数/件）を層ごとに切り替え、地層カードの円形ゲージ aria ラベルと CLI 地層テーブル見出しも同趣旨で更新した。

**カバレッジ詳細モーダルのテストファイル選択**

関連テストが 2 件以上のとき、折り返しボタン群を `<select>` に変更し、パネルヘッダーを縦積みレイアウトにして幅溢れを防いだ。フルパス表示で同名ファイルの区別も可能にした。

### Outcome

ダッシュボード利用者は単体層の指標を実装カバレッジとして正しく読める。カバレッジ詳細で複数テストに関わる実装ファイルを開いても UI が崩れず、テストコードを切り替えて確認できる。
