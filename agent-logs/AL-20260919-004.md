### Objective

**課題:** serve の HTTP API を Node テスト以外のエンジンで証跡化する具体例がなく、fragment ベースのマルチ suite が dogfood されていなかった。

**対応:** Postman コレクションと Newman ランナーを追加し、serve 起動から traceweave-v1 fragment 生成までを workspace の `newman-api` suite に接続する。

### Completion Criteria

### Changes

**ワークスペースと依存** — `newman` を src の devDependency に追加し、suite `run` が serve 待機・Newman 実行・`reports/suites/newman.json` 出力まで担う。

**契約と fixture** — TC-0063 で `/api/data` と `/api/test/run` のスモークを定義し、Postman リクエスト名から TC ID を集約する変換器を core に置いた。
