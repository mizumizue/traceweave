## Content

### Objective

**課題:** コミット後にログ frontmatter へ OID を書き、同じコミットへ amend する運用では、amend 直後にハッシュが変わりログと Git が必ず不整合になった（AL-006 / AL-007 で実害）。

**対応:** 追跡の正本をコミット件名の `AL-YYYYMMDD-NNN` に一本化し、`commit:` フィールドと amend によるハッシュ埋めを廃止する。ルール・README・テンプレートを更新し、既存 AL-* / IL-* から `commit:` を除去して `git log --grep` ベースの閲覧コマンドへ統一する。
