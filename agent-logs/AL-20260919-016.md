## Content

### Objective

**課題:** adopt 先で「各工程に何を・どのツールでテストするか」が散在し、Newman 等のツール名だけが先行しやすかった。またガイド正本が `src/application/` 配下にあり発見しづらかった。

**対応:** 一般的な Web 3 層を場面に固定した strata ガイドを adopt 品質キットへ組み込み、正本を `.traceweave/adoption/` に置き、INSTALL と ADOPT_QUALITY_SETUP から誘導する。

- [x] `.traceweave/adoption/ADOPT_TEST_STRATA_GUIDE.md` が正本として存在する
- [x] `traceweave adopt` が `docs/ADOPT_TEST_STRATA_GUIDE.md` をコピー配備する

- [x] `npm --prefix src run lint` が成功する

### Changes

**工程別テスト構成ガイド（正本と adopt 配備）**  
5 大工程ごとの検証目的、典型ハーネス、TraceWeave TC/スイート映射、Web サンプル構成、ピラミッド・充足度、アンチパターンを1本の Markdown にまとめた。adopt 時は `quality-kit` が正本を読み、先プロジェクトの `docs/` へコピーする。

**置き場所の整理**  
正本を `.traceweave/adoption/` に移し、`examples/` と同じ TraceWeave 運用ゾーンで見つかるようにした。索引用 `README.md` と `ADOPT_TEST_STRATA_GUIDE_REPO_REL` 定数で adopt エンジンの読み取りパスを固定した。

**ドキュメント・スキル接続**  
`INSTALL_GUIDE.md` に品質キット表・小節を追加し、生成される `ADOPT_QUALITY_SETUP` から strata ガイドを先読みするよう案内した。`traceweave-adopt` スキルの verify チェックリストにも配備物を追記した。

### Outcome

導入プロジェクトは adopt 直後から `docs/ADOPT_TEST_STRATA_GUIDE.md` で工程別テスト方針を共有でき、TraceWeave 本体側は `.traceweave/adoption/` を編集するだけで全 adopt 先に同内容を配れます。
