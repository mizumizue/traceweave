## Content

### Objective

**課題:** `--tc TC-xxxx` 指定時、Node の `--test-name-pattern` だけでは `tests/**/*.test.ts` 全ファイルが import され、50 件以上のファイルがコンソールに流れて単体実行の体感と乖離していた。

**対応:** `test('TC-xxxx:` 宣言を含むファイルだけを解決して実行し、名前パターンを `^TC-xxxx:` に厳格化する。

### Completion Criteria

- [x] `resolveTestFilesForCase` が test() 宣言行のみを対象にファイルを解決する
- [x] `run-test-suite.ts` が個別 TC 実行時に該当ファイルのみを Node test に渡す
- [x] 宣言が無い TC ID は exit 1 で明示エラーになる
- [x] `npm --prefix src run lint` / `test` が成功する

### Changes

**Summary 1 — ファイル解決ヘルパー**

`formatTestRunCommand.ts` に `testFileDeclaresCase` / `resolveTestFilesForCase` / `testNamePatternForCase` を追加した。行頭の `test('TC-xxxx:` 宣言だけを拾い、文字列リテラル内の TC ID 参照は除外する。

**Summary 2 — ランナー絞り込み**

`run-test-suite.ts` で `--tc` 時に解決したファイルパスのみを spawn 引数に渡す。対象ファイル数をログ出力し、未宣言 TC は即失敗する。

**Summary 3 — テスト**

`resolveTestFilesForCase` の単体テストを追加し、TC-0033 が port-manager テスト 1 ファイルに限定されることを固定した。

### Outcome

`npm --prefix src test -- --tc TC-0033` は該当 1 ファイル・1 テストだけを実行し、全スイートロードの待ち時間がなくなる。

### Improvements

N/A

### Verification

- `npm --prefix src run lint` — exit 0
- `npm --prefix src test` — exit 0（152 tests pass）
- `npm --prefix src test -- --tc TC-0033` — 1 test file, 1 test pass

### Notes

`test.describe` 内の子テスト名が TC ID 先頭の場合は、宣言行が `test(` で始まらないため別途拡張が必要。現行リポジトリの命名規約では行頭 `test('TC-xxxx:` が正本。
