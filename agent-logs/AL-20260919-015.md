## Content

### Objective

**課題:** トレーサビリティマトリクスは ITa〜UAT の契約充足を見る画面なのに、UT の工程フィルタが残っており、常に空結果になるか誤解を招く。

**対応:** UI から UT 絞り込みを外し、URL・行フィルタで legacy `phase=unit` を無効化。地層タブのマトリクス連動の死んだ経路も整理する。

### Completion Criteria

- [x] マトリクス UI に UT 工程フィルタ（ドロップダウン・クイック条件）がない
- [x] `?phase=unit` は `all` に正規化される
- [x] `filterMatrixRows` が正規化後の工程のみで絞り込む
- [x] `npm --prefix src run lint` 成功
- [x] urlState 契約テスト（support ITb-0015）が legacy UT 正規化を含み成功

### Changes

マトリクス画面から UT 用の工程選択とクイックピルを削除し、ユーザーが契約トレーサビリティ以外の層で絞り込もうとする導線をなくした。

`matrixData` と urlState の正規化（HEAD に既に入っていた `normalizeMatrixPhaseFilter`）を接続し、メモリ内・URL 経由の `unit` 指定がマトリクス行フィルタに効かないようにした。

工程地層ビューからマトリクスへ UT を渡す未使用の `onFilterPhase` プロップを削除し、ピラミッドはテストブック開く経路だけに揃えた。

web-contract の urlState テストを ITa 工程パースと legacy `phase=unit` → `all` の断言に更新した。

### Outcome

マトリクスは ITa〜UAT の契約充足の見方に UI が一致し、UT は工程地層・テスト仕様・カバレッジ側で見る流れがぶれなくなる。旧リンクの `?phase=unit` は全工程表示に落ちる。
