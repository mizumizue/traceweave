## Content

### Objective

**課題:** 内部結合（ITa）層の複数 TC が ADR-0010 の原子性・単一オラクルに反し、1 文書に複数の独立検証が混在していた。親 ID のままでは形式証跡のタイトル宣言行とも整合しない。

**対応:** レビュー推奨の枝番子ケースを起票し、親を `deprecated` + `supersedes` スタブに置き換える。Node テストの `TC-…:` タイトルを子 ID に揃え、QA・移行マップ・エクスポート表の参照を更新する。

### Changes

**ITa 文書分割:** 0001（4 子）、0002（2）、0003（2）、0005（2）、0011（2）、0012（2）を新規起票。各親は退役スタブと `supersedes` 配列で子へ誘導。0009 はブラウザ検証を ITb/E2E 側に寄せる旨を objective に明記し、検証リンクを SPEC-0019 に限定。

**証跡と参照:** 充足度・カタログ・InputAnalyzer・API・高重要度地層・件名レポート・ユースケース充足の統合テストを、1 テスト（または論理ブロック）あたり 1 子 TC ID のタイトル宣言行に再配置。QA-0003 と consolidated エクスポート、レガシー ID 移行マップの ITa 親キーは第一子 `-01` を指すよう更新。

### Outcome

ITa 層の主要 mega-TC は子 ID 単位で追跡・ダッシュボード集計・形式証跡マージが可能になる。退役親は履歴参照用に残り、ガバナンス lint の `supersedes` 要件を満たす。
