## Content

### Objective

**課題:** `traceweave adopt` は V字ドキュメントと一部 Cursor 資材だけを配備し、TC 監査・文書起票・証跡層・サブエージェントが製品リポに無いと、エージェント運用でトレーサビリティが途切れる。

**対応:** `install-cursor-skills` を正本エンジンとして adopt に統合し、全 `traceweave-*` スキル（`references/` 含む）、全 `.mdc` ルール、`traceweave-*` サブエージェントを一括配備。品質ゲートとスキル文書を同期し、`.traceweave` 設定の読み物ガイドを導入文書から参照可能にする。

### Completion Criteria

- [x] adopt が `deployAdoptCursorBundle` 経由で skills / rules / agents を配備する
- [x] `installCursorSkills` がスキルディレクトリ全体と `--with-agents` をサポートする
- [x] `adopt-quality-check` がバンドル欠落を検出する
- [x] 関連テストと `npm --prefix src run lint` が成功する

### Changes

**Cursor 配備の単一化.** 部分コピーを廃止し、`src/infrastructure/cursor/installCursorSkills.ts` を adopt と CLI の共通実装にした。スキルはディレクトリ丸ごとコピーするため `references/` も欠けない。

**adopt 実行経路.** `executor` は品質キット生成の前にバンドルを配備する。関連スキルと `ADOPT_QUALITY_SETUP` テンプレを更新した。

**品質ゲートとテスト.** `checkAdoptQuality` はプラットフォーム版と突合して bundled 資材を要求する。adopt / install-skills テストを拡張した。

**運用ドキュメント.** `.traceweave/README.md` を追加し、導入ガイドからスイートと config の読み物としてリンクした。

### Outcome

製品リポで adopt 後、Cursor 上で TraceWeave 本体と同等の V字・TC・証跡運用が可能になる。
