### Changes

**High 重要度要件のテスト地層充足。** TC-0043〜0056 を 14 件起票し、`tests/core/high-criticality-strata.test.ts` に unit / ITa / ITb の実行テストを集約。各 High REQ に不足していた工程（主に unit と ITa）を補い、`traceweave check --strict` の未充足エラーを解消した。

**SPEC-0018 の契約分離。** Web ビューポート・スクロール・Fit Width 等の UI シェル契約を SPEC-0024（external タグ付き）へ抽出。SPEC-0018 は Core グラフ構築・レイアウトに限定し、DSN-0009 が両 SPEC に依存する形へ更新した。

**QA 横断被覆の拡充。** CLI 終了コード・catalog JSON（QA-0004）と MCP ツール API（QA-0005）の品質方針を起票。既存 TC-0005 / TC-0054 / TC-0042 とリンクした。

**ガバナンス・実装整備。** validateDocs の fence-lite（REQ/NEED 実装漏れ検出）を強化し、複数 REQ の Statement を観測成果表現へ修正。CLI から application 層へ docs 解決・catalog 整形・serve 等を抽出。`.github/workflows/docs-governance.yml` を追加し clean-root 登録を更新した。

### Outcome

High 重要度要件は strict モードで全件充足となり、トレーサビリティグラフの Core/UI 契約が仕様層で分離される。CLI と MCP 向けの QA 方針が文書化され、CI で docs ガバナンスが自動検証される。
